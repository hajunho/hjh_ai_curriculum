# Lecture 07 · Level 07 — 불균형 데이터 다루기

> 5,000건 중 사기가 1.5%뿐인 데이터에서 사기를 잡는 법 — class_weight, 리샘플링, 임계값 조정, 그리고 PR 곡선으로 트레이드오프를 읽는 법을 배웁니다.
**난이도** ⭐⭐⭐⭐ / **선행** level01, level06 / **예상 시간** 45분

## 1. 왜 배우나 — 비즈니스 관점

실무에서 진짜 돈이 걸린 분류 문제는 거의 다 불균형(imbalanced)입니다. 사기 거래 1.5%, 장비 고장 0.5%, 심각 불량 2%, 부정 청구 1% — 잡아야 할 대상일수록 드뭅니다. 그런데 드문 것을 잡는 문제에 표준 설정을 그대로 쓰면, 모델은 "전부 정상"이라고 답하는 게으른 최적해에 안착합니다. 정확도 98.5%, 사기 검출 0건 — 숫자는 화려한데 아무 일도 안 하는 모델이 탄생합니다.

이 레벨의 목표는 두 가지입니다. 첫째, 게으른 모델을 깨우는 세 가지 기법(가중치, 리샘플링, 임계값)을 손에 넣는 것. 둘째, 재현율과 정밀도가 **맞바꾸기 관계**라는 사실을 표와 곡선으로 체득하는 것. "재현율 90% 만들어 주세요"라는 요구에 "그러면 정밀도가 이만큼 떨어져 조사팀 업무가 몇 배가 됩니다"라고 답할 수 있어야, 실현 가능한 목표 협상이 시작됩니다.

## 2. 비유로 이해하기

건초 더미에서 바늘 찾기입니다. 건초 5,000줌에 바늘이 75개. 조사관(모델)에게 "틀린 개수를 줄여라"라고만 지시하면, 가장 편한 전략은 **아무것도 안 집는 것**입니다(오답 75개뿐, 정답률 98.5%). 조사관을 움직이게 하는 방법이 세 가지 있습니다.

- **가중치(class_weight)**: "바늘 하나 놓치면 벌점 65배"라고 벌점표를 고칩니다. 조사관은 이제 바늘을 놓치는 것이 무서워 의심스러우면 집습니다.
- **리샘플링(resampling)**: 훈련용 건초 더미를 조작합니다. 바늘을 복사해 늘리거나(오버샘플링) 건초를 덜어내(언더샘플링) 바늘이 흔한 세상에서 연습시킵니다. 시험(테스트)은 원래 비율로 봅니다.
- **임계값(threshold) 조정**: 조사관의 "의심 점수"가 50점 이상일 때만 집던 것을 20점 이상이면 집도록 기준을 내립니다. 많이 집으니 바늘을 더 찾지만(재현율↑), 건초도 많이 집습니다(정밀도↓).

어느 방법이든 공짜는 없습니다. 더 많이 잡으면 헛다리도 늘어난다 — 이 맞바꾸기를 눈으로 보는 도구가 PR 곡선입니다.

## 3. 핵심 개념

### 3.1 왜 정확도가 무의미해지는가

양성 1.5%에서 "전부 음성" 예측의 정확도는 98.5%입니다. 그래서 불균형 문제의 기본 지표는 재현율·정밀도·PR-AUC입니다. ROC-AUC도 쓰이지만, 양성이 극히 드물면 ROC 곡선은 후하게 보이는 경향이 있어 **PR 곡선(precision-recall curve)**이 더 정직합니다.

### 3.2 세 가지 기법 비교

| 기법 | 하는 일 | 장점 | 주의점 |
|---|---|---|---|
| class_weight="balanced" | 손실 함수에서 소수 클래스 실수에 큰 벌점 | 한 줄로 끝, 데이터 불변 | 지원하는 모델에서만 |
| 오버샘플링 | 학습 데이터의 소수 클래스 복제 | 모든 모델에 적용 가능 | **분할 후, 학습 데이터에만!** 같은 표본 반복으로 과적합 위험 |
| 임계값 조정 | predict_proba 기준선 이동 | 모델 재학습 불필요, 운영 중 조절 가능 | 검증 데이터로 정해야 함(테스트로 정하면 누설) |

SMOTE(소수 클래스를 보간해 합성 표본을 만드는 기법)라는 발전형도 널리 쓰입니다. 전용 패키지가 필요해 여기서는 개념만 알아 두고, 실습은 단순 복제 오버샘플링으로 원리를 확인합니다.

### 3.3 리샘플링의 황금률

리샘플링은 **반드시 학습/테스트 분할 후에, 학습 데이터에만** 적용합니다. 분할 전에 오버샘플링하면 같은 표본의 복사본이 학습과 테스트 양쪽에 들어가 성능이 크게 부풉니다(누설의 변종). 또 테스트 데이터의 비율은 절대 조작하지 않습니다 — 시험은 실제 세상의 비율로 봐야 합니다.

### 3.4 PR 곡선 읽는 법

임계값을 1.0에서 0.0까지 내리면서 (재현율, 정밀도) 점을 찍으면 PR 곡선이 됩니다. 오른쪽으로 갈수록(재현율↑) 곡선이 내려가는(정밀도↓) 모양이 맞바꾸기의 시각화입니다. 곡선 아래 면적(PR-AUC, 평균 정밀도)이 모델의 종합 점수이고, **어느 점에서 운영할지**는 모델이 아니라 비즈니스(조사 인력, 오탐 비용)가 정합니다. 이 "운영점 설계"는 level10~11의 주제입니다.

## 4. 실습 — main.py

```bash
python3 main.py
```

`fraud_table` 5,000건(사기 약 1.5%)으로 로지스틱 회귀를 네 가지 방식으로 훈련·평가합니다.

- [1] 기본 설정: 정확도 99%대라는 화려한 숫자 뒤에서 사기의 약 30%를 놓치고 있음을 확인합니다.
- [2] class_weight="balanced": 재현율이 뛰는 대신 정밀도가 내려가는 것을 관찰합니다.
- [3] 수동 오버샘플링(학습 데이터에만 소수 클래스 복제): 가중치와 비슷한 효과임을 확인합니다.
- [4] 임계값 조정: 같은 모델에서 임계값 0.9→0.1을 훑으며 재현율/정밀도/알람 건수 표를 출력합니다.
- [5] PR 곡선을 텍스트로 요약하고(PR-AUC), "조사팀이 하루 15건만 처리 가능"이라는 제약에서 어떤 임계값이 합리적인지 계산합니다.

관찰 포인트: [2]와 [3]의 결과가 비슷하다는 것(둘 다 "벌점표 고치기"의 변형), 그리고 [4]의 표에서 재현율과 정밀도가 반대로 움직이는 것. 표의 어느 행을 고를지는 기술이 아니라 경영의 문제라는 감각을 가져가세요.

3. **(도전)** 분할 **전에** 오버샘플링하는 잘못된 코드를 일부러 만들어 성능이 얼마나 부푸는지 확인해 보세요. 힌트: 전체 df에서 사기 행을 복제한 뒤 train_test_split — 테스트에 복사본이 섞이며 재현율·정밀도가 비현실적으로 올라갑니다.

## 6. 자주 하는 실수

- **정확도로 성과 보고**: 불균형 문제에서 정확도는 기본적으로 금지어입니다. 재현율/정밀도/PR-AUC로 말하세요.
- **분할 전 리샘플링**: 가장 흔하고 가장 티 안 나는 누설. 리샘플링은 파이프라인 관점에서 "학습 시에만" 적용되어야 합니다.
- **임계값을 테스트 데이터로 튜닝**: 임계값도 하이퍼파라미터입니다. 검증 데이터로 정하고 테스트는 봉인하세요.
- **재현율 100% 요구를 그대로 수락**: 재현율 100%는 "전 거래 차단"으로도 달성됩니다. 반드시 정밀도(또는 알람 건수) 조건과 함께 목표를 정하세요.
- **불균형 = 무조건 리샘플링이라는 공식**: 임계값 조정만으로 충분한 경우가 많습니다. 단순한 방법부터 시도하세요.
