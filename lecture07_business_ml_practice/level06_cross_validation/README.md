# Lecture 07 · Level 06 — 교차검증: 믿을 수 있는 성능

> 단일 분할 점수가 얼마나 "운빨"인지 실험으로 확인하고, 5-fold 교차검증으로 평균±표준편차의 성능 보고를 만드는 법, 그리고 시계열 데이터의 분할 주의점을 배웁니다.
**난이도** ⭐⭐⭐ / **선행** level05, lecture06 level04 / **예상 시간** 35분

## 1. 왜 배우나 — 비즈니스 관점

외주 업체가 "AUC 0.87 달성"이라고 보고했습니다. 이 숫자를 얼마나 믿어야 할까요? 데이터를 어떻게 잘랐느냐에 따라 같은 모델의 점수가 0.83이 되기도 0.90이 되기도 한다면, 소수점 둘째 자리 경쟁은 의미가 없습니다. 실제로 그렇게 흔들립니다. 특히 표본이 작을수록, 불균형이 심할수록 점수의 출렁임은 커집니다.

교차검증(cross-validation, CV)은 이 출렁임을 정면으로 측정하는 방법입니다. 결과 보고가 "0.87"에서 **"0.86 ± 0.02"**로 바뀌는 순간, 두 모델의 차이가 진짜인지 우연인지 판단할 수 있게 됩니다. 의사결정자 입장에서 이것은 "이 개선에 예산을 더 써야 하나"를 가르는 정보입니다. 그리고 검수자 입장에서는 단 하나의 질문 — "그 숫자, 몇 번 재신 건가요?" — 으로 보고서의 신뢰도를 가늠할 수 있습니다.

## 2. 비유로 이해하기

신제품 시식 평가를 생각해 보세요. 손님 **한 팀**에게만 물어보고 "만족도 90%!"라고 보고하면 어떨까요? 그 팀이 우연히 단 것을 좋아하는 팀이었다면 숫자는 완전히 왜곡됩니다. 상식적인 해법은 **여러 팀에게 돌아가며 물어보고 평균과 편차를 함께 보고**하는 것입니다.

5-fold 교차검증이 정확히 이 방식입니다. 데이터를 5조각으로 나누고, 매번 4조각으로 공부(학습)하고 남은 1조각으로 시험(검증)을 봅니다. 조각을 바꿔 가며 5번 시험 보면 점수 5개가 나오고, 그 **평균**이 실력 추정치, **표준편차**가 "운의 크기"입니다. 데이터 전부가 한 번씩 시험 문제로 쓰이므로, 어느 한 조각의 우연한 특성에 휘둘리지 않습니다.

단, 시계열 데이터는 예외적인 규칙이 하나 붙습니다. 모의고사(과거)로 공부해서 본고사(미래)를 봐야지, **본고사 문제로 공부해서 모의고사를 보면** 안 됩니다. 무작위로 섞어 나누면 미래 데이터로 과거를 예측하는 시험이 만들어집니다.

## 3. 핵심 개념

### 3.1 단일 분할의 분산 — 점수는 확률변수다

`train_test_split(random_state=n)`의 n만 바꿔도 점수가 달라집니다. 점수는 고정된 진리값이 아니라 **분할이라는 우연이 섞인 확률변수**입니다. main.py [1]에서 30개의 서로 다른 분할로 같은 모델을 평가해 점수의 분포(최소~최대 폭)를 직접 봅니다. 이 폭이 여러분이 지금까지 봐 온 "단일 점수"들의 숨은 오차 범위입니다.

### 3.2 k-fold 교차검증

- **k=5 또는 10**이 관례. 데이터가 아주 적으면 k를 키우고(극단은 LOO), 크면 5로 충분합니다.
- 분류 문제는 **StratifiedKFold**: 각 조각의 클래스 비율(이탈률 18%)을 원본과 같게 유지합니다. 불균형 데이터에서 특히 중요합니다.
- 보고 형식: `평균 ± 표준편차`. 두 모델 비교 시 평균 차이가 표준편차보다 작다면 "차이 없음"이 정직한 결론입니다.
- 비용: 학습을 k번 하므로 시간이 k배. 그 대가로 신뢰를 삽니다.

### 3.3 최종 모델과 최종 테스트

교차검증은 "이 방법(모델+전처리+하이퍼파라미터)이 평균적으로 얼마나 좋은가"를 재는 절차입니다. 방법이 결정되면 **최종 모델은 전체 학습 데이터로 다시 학습**합니다. 그리고 하이퍼파라미터 선택까지 CV로 했다면, 마지막 발표용 점수는 CV에 한 번도 안 쓴 **봉인된 테스트 세트**로 재는 것이 정석입니다(고르는 데 쓴 자로 재면 점수가 후해집니다).

### 3.4 시계열 분할 — TimeSeriesSplit

시간 순서가 있는 데이터(매출, 주가, 트래픽)에서 무작위 k-fold를 쓰면 "미래로 과거를 예측"하는 누설이 생깁니다. 특히 이동평균·전일 매출 같은 시차(lag) 피처가 있으면 검증 조각의 정보가 학습 조각의 피처에 직접 들어 있어 점수가 크게 부풉니다. 해법은 `TimeSeriesSplit`: 학습 구간이 항상 검증 구간보다 앞에 오도록 자릅니다(1~3월로 학습→4월 검증, 1~4월로 학습→5월 검증, ...). main.py [4]에서 같은 매출 예측 문제의 점수가 무작위 분할에서 얼마나 부풀어 보이는지 비교합니다.

## 4. 실습 — main.py

```bash
python3 main.py
```

- [1] 운빨 실험: `churn_table` + 로지스틱 회귀를 30가지 무작위 분할로 평가해 AUC의 최소·최대·표준편차를 출력하고 간이 히스토그램을 그립니다.
- [2] 5-fold StratifiedKFold 교차검증으로 `평균 ± 표준편차`를 계산합니다. 폴드별 점수도 출력합니다.
- [3] 두 모델(로지스틱 회귀 vs 랜덤포레스트)을 CV로 공정 비교하고, 평균 차이를 표준편차와 견줘 "의미 있는 차이인가"를 판정합니다.
- [4] 시계열 함정: `sales_table` 일별 매출에 전일 매출 피처를 넣고, 무작위 KFold vs TimeSeriesSplit의 R² 차이를 비교합니다.

핵심 코드는 `cross_val_score(pipe, X, y, cv=StratifiedKFold(...), scoring="roc_auc")` 한 줄입니다. 전 레벨에서 배운 파이프라인을 통째로 넣는다는 점(폴드마다 전처리 재-fit)을 눈여겨보세요.

3. **(도전)** [3]에 세 번째 선수로 `KNeighborsClassifier`(파이프라인에 StandardScaler 포함)를 추가해 3파전을 만들어 보세요. "평균 차이 < 표준편차"인 쌍이 있는지 판정해 보세요.

## 6. 자주 하는 실수

- **한 번 잰 점수로 모델을 선택**: 0.87 vs 0.86의 승부는 분할 운으로 뒤집힙니다. 비교는 반드시 CV로.
- **CV 점수를 "테스트 점수"라고 보고**: 하이퍼파라미터를 CV로 골랐다면 CV 점수는 이미 약간 후한 점수입니다. 최종 보고는 봉인 테스트로.
- **시계열에 shuffle=True**: 이동평균·시차 피처가 있는 데이터를 무작위로 섞으면 점수가 조용히 부풉니다. 시간 축이 있으면 무조건 TimeSeriesSplit부터 검토하세요.
- **불균형 데이터에 그냥 KFold**: 어떤 폴드엔 이탈자가 거의 없을 수 있습니다. 분류는 StratifiedKFold가 기본값입니다.
- **CV로 전처리 누설을 방치**: 스케일링·인코딩을 CV 밖에서 미리 해 두면 폴드가 서로를 훔쳐봅니다. 파이프라인째 넣으세요(level05).
