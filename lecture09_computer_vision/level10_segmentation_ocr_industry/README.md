# Lecture 09 · Level 10 — 세그멘테이션·OCR·산업 검사

> 픽셀 하나하나에 소속을 정해 주는 세그멘테이션을 임계값과 연결 요소만으로 구현하고, 불량 얼룩 검출까지 완주합니다. OCR 과 산업 검사의 뼈대가 같음을 확인합니다.
**난이도** ⭐⭐⭐⭐ / **선행** level09 / **예상 시간** 45분

## 1. 왜 배우나 — 비즈니스 관점

바운딩 박스(level09)는 "대략 어디"까지만 답합니다. 그런데 현장 질문은 자주 더 정밀합니다 — "흠집의 **면적**이 몇 ㎟인가?"(면적 기준으로 불량 등급이 갈립니다), "종양의 **경계**가 어디까지인가?", "문서에서 글자 영역과 도장 영역을 **분리**해 달라". 픽셀 단위의 답이 필요한 순간, 필요한 기술이 **세그멘테이션(segmentation)** 입니다.

또 하나의 실무 감각: 모든 문제에 딥러닝이 필요한 것은 아닙니다. 조명이 통제된 검사 라인처럼 조건이 일정한 환경에서는, 오늘 배우는 **고전 3종 세트(임계값 → 연결 요소 → 면적 규칙)** 가 딥러닝 없이 초당 수천 장을 처리하며 수십 년째 현역입니다. "이 과제, 룰 기반 비전으로 되나요, 딥러닝이 필요한가요?"라는 질문에 답할 기준이 오늘 생깁니다.

## 2. 비유로 이해하기

**색칠 공부와 양동이 채우기**입니다.

- **임계값(thresholding)**: 흑백 스케치에서 "일정 이상 진한 곳만 남기기". 기준 하나로 전경(물체)과 배경을 가르는 가장 단순한 픽셀 분류입니다. 밝기 기준선은 조명이 일정하면 놀랄 만큼 잘 작동합니다.
- **연결 요소(connected components)**: 그림판의 **페인트 통(양동이) 도구**입니다. 한 픽셀을 클릭하면 붙어 있는 같은 색 픽셀 전체로 색이 번지듯, 전경 픽셀에서 시작해 상하좌우로 번지며 "한 덩어리"에 같은 번호를 붙입니다. 덩어리 수를 세면 물체 개수가, 덩어리별 픽셀 수를 세면 면적이 나옵니다.
- **면적 규칙**: 덩어리들을 크기로 분류합니다. "부품은 100픽셀 이상, 얼룩은 12픽셀 미만" — 검사원의 "이 정도 크기면 스패터죠"라는 감각을 숫자로 옮긴 것입니다.

OCR(광학 문자 인식)도 같은 뼈대입니다: 문서를 이진화하고 → 글자 덩어리를 분리하고(세그멘테이션) → 각 덩어리를 "어느 글자인가"로 분류(인식). 앞 단계는 오늘 배우는 기술, 뒷 단계는 level05 의 분류기입니다.

## 3. 핵심 개념

### 3.1 세그멘테이션의 세 층위

| 층위 | 질문 | 예 |
|---|---|---|
| 이진(전경/배경) | 물체 픽셀인가? | 오늘의 임계값 방식 |
| 시맨틱(semantic) | 이 픽셀은 무슨 클래스인가? | 도로/차/사람 픽셀 구분 |
| 인스턴스(instance) | 같은 클래스라도 몇 번째 개체인가? | 사람1/사람2 구분 |

오늘의 "이진화 + 연결 요소"는 사실상 미니 인스턴스 세그멘테이션입니다 — 픽셀 소속(이진화)과 개체 구분(연결 요소 번호)을 모두 얻으니까요. 딥러닝 세그멘테이션(U-Net 류의 인코더-디코더 구조)은 임계값 대신 **학습된 CNN 이 픽셀별 클래스 확률을 출력**하는 것으로, "픽셀마다 소속 정하기"라는 문제 정의 자체는 동일합니다.

### 3.2 임계값이 통하는 조건과 무너지는 조건

임계값은 밝기 히스토그램이 **두 봉우리(배경/전경)로 갈릴 때** 잘 작동합니다. 무너지는 조건은 그 반대 — 조명이 불균일하거나(한쪽만 그늘), 전경과 배경의 밝기가 겹칠 때입니다. 실무 대응은 순서대로: ① 조명을 고친다(하드웨어가 최선), ② 지역별로 다른 임계값을 쓴다(적응형), ③ 그래도 안 되면 학습 기반으로 갑니다. 이 에스컬레이션 순서가 산업 비전 컨설팅의 정석입니다.

### 3.3 연결 요소 = 그래프 탐색

"붙어 있는 픽셀끼리 한 덩어리"는 그래프 문제입니다. 픽셀이 노드, 상하좌우 인접이 간선이고, 한 덩어리는 연결된 부분 그래프입니다. main.py 는 BFS(너비 우선 탐색)를 스택으로 구현합니다 — 시작 픽셀을 칠하고, 이웃 중 아직 안 칠한 전경 픽셀로 번져 나가는 15줄. 대각선도 이웃으로 칠지(8-연결) 말지(4-연결)는 과제에 따라 정하는 설계 선택입니다.

### 3.4 영역 속성 — 측정이 곧 가치

라벨링이 끝나면 영역별로 **면적, 바운딩 박스, 중심 좌표**를 잽니다. 이 숫자들이 곧 비즈니스 답입니다: 면적 → 불량 등급, 중심 → 로봇 픽업 좌표, 개수 → 재고 카운트. "이미지 → 숫자 표"로 끝나는 이 변환이 산업 비전의 최종 산출물입니다.

### 3.5 산업 응용 지도

- **표면 검사**: 금속·필름·디스플레이의 흠집/얼룩 검출 — 오늘 데모 그 자체.
- **문서 처리(OCR)**: 이진화 → 줄/글자 분리 → 글자 분류 → 텍스트 조립. 최근에는 분리·인식을 한 번에 하는 딥러닝 OCR 이 대세지만, 전처리 이진화는 여전히 품질을 좌우합니다.
- **의료·바이오**: 세포 카운팅(연결 요소 개수), 병변 면적 측정.
- **로보틱스·물류**: 집을 물체의 픽셀 영역과 중심 산출.

## 4. 실습 — main.py

실행:

```bash
python3 main.py
```

- **[1]** 검사 장면을 numpy 로 직접 그립니다: 정상 부품 3개(사각형/원/삼각형) + 몰래 뿌린 작은 얼룩 4개 + 촬영 잡음. 검출기는 얼룩 위치를 모릅니다.
- **[2]** 임계값 0.45로 이진화합니다. 잡음(표준편차 0.06)은 기준을 못 넘어 배경으로 깨끗이 떨어집니다.
- **[3]** BFS 연결 요소 라벨링으로 덩어리 7개를 찾습니다.
- **[4]** 영역별 면적·중심을 표로 출력하고, "면적 12 미만 = 얼룩" 규칙으로 판정합니다. 정답과 대조하면 얼룩 4/4 검출.
- **[5]** 원본 → 이진화 → 컬러 라벨 맵 → 판정 오버레이(초록=부품, 빨강=불량)의 4단 비교판을 `outputs/segmentation.png` 로 저장합니다.

코드 핵심부는 `connected_components()` — 스택 기반 BFS 15줄입니다. lecture02 의 반복문·리스트 지식만으로 산업 검사 알고리즘이 만들어진다는 것을 확인하세요.

## 5. 직접 해보기

1. **(쉬움)** `THRESH` 를 0.45 → 0.80 으로 올려 보세요. 얼룩(밝기 0.85)은 남지만 부품 경계가 흔들리고, 0.9 로 올리면 얼룩도 사라집니다. 임계값이 검출 민감도를 정하는 것을 확인하세요. (힌트: 상수 하나)
2. **(보통)** 4-연결을 8-연결(대각선 포함)로 바꿔 보세요. 요소 개수가 달라지는 경우를 만들려면 어떤 배치가 필요할까요? (힌트: 이웃 목록에 대각선 4방향 추가, 대각으로만 닿은 두 픽셀)
3. **(도전)** 잡음 표준편차를 0.06 → 0.20 으로 올리면 이진화에 소금 알갱이 같은 가짜 전경이 생깁니다. "면적 2 이하 요소는 잡음으로 무시"하는 정리 단계를 추가해 검출을 복구해 보세요. (힌트: 판정 전에 요소 필터링 — 이것이 모폴로지 연산의 정신입니다)

## 6. 자주 하는 실수

- **임계값을 이미지마다 고정**: 조명이 변하는 환경에서 고정 임계값은 반드시 무너집니다. 히스토그램을 먼저 보고, 필요하면 적응형으로.
- **연결성(4 vs 8) 무신경**: 가는 사선이 4-연결에서는 조각조각 끊어집니다. 개수 세기 과제에서 치명적입니다.
- **면적 규칙의 단위 혼동**: 픽셀 면적은 해상도에 종속됩니다. 카메라·거리가 바뀌면 "12픽셀 미만" 규칙도 다시 캘리브레이션해야 합니다.
- **딥러닝부터 꺼내 들기**: 통제된 조명에서 고전 기법으로 충분한 과제에 학습 기반을 쓰면 데이터 수집·라벨링 비용만 늘어납니다. 에스컬레이션 순서(3.2)를 기억하세요.

## 다음 레벨 예고

CNN 은 이미지를 "이웃부터 차근차근" 봤습니다. 그런데 최신 비전 AI 는 다른 독법을 씁니다 — 이미지를 패치(조각) 단어들의 문장으로 읽고, 어떤 패치가 어떤 패치를 참고할지 스스로 정하는 **비전 트랜스포머(ViT)**, 그리고 이미지와 텍스트를 같은 공간에서 만나게 하는 **멀티모달(CLIP 식)**. 마지막 레벨에서 패치 임베딩과 셀프 어텐션을 직접 구현하며 강의를 마무리합니다.
