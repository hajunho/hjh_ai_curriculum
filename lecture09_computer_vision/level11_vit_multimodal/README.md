# Lecture 09 · Level 11 — 비전 트랜스포머와 멀티모달

> 이미지를 "패치 단어"의 문장으로 읽는 ViT 를 미니 버전으로 직접 만들고, 이미지와 텍스트가 한 공간에서 만나는 CLIP 식 멀티모달의 개념까지 정리합니다.
**난이도** ⭐⭐⭐⭐⭐ / **선행** level03~05 (lecture10 의 어텐션을 먼저 봤다면 더 좋습니다) / **예상 시간** 55분

## 1. 왜 배우나 — 비즈니스 관점

요즘 비전 AI 뉴스와 제안서에는 CNN 대신 다른 단어들이 등장합니다 — "트랜스포머 기반 비전 모델", "멀티모달", "이미지-텍스트 검색", "제로샷 분류". 사진을 던지면 설명문을 쓰고, "찢어진 포장"이라고 검색하면 그런 사진을 찾아 주는 기능들의 뿌리가 **비전 트랜스포머(ViT, Vision Transformer)** 와 **CLIP 식 이미지-텍스트 정렬**입니다.

이 기술 용어들을 개념 수준에서 정확히 알아 두면 두 가지가 가능해집니다. 첫째, "우리 불량 검사에 멀티모달이 필요한가?"(대부분 아니오 — 분류·탐지로 충분)와 "라벨 없이 텍스트 검색으로 이미지 자산을 뒤지고 싶다"(예 — 정확히 멀티모달의 용도) 같은 판단. 둘째, 공급 업체가 "최신 트랜스포머 기반"을 내세울 때, 그것이 과제에 주는 실익이 무엇인지 따져 묻는 질문력. 이 강의의 마지막 레벨로서, 픽셀에서 시작한 여정을 최신 문법까지 연결합니다.

## 2. 비유로 이해하기

**이미지를 문장처럼 읽기**. lecture10 에서 (배우게 될) 트랜스포머는 문장을 "단어 토큰들의 나열"로 읽습니다. ViT 의 발상은 대담할 만큼 단순합니다 — **이미지를 잘게 썰어 조각(패치)들을 단어처럼 나열하면, 문장 읽는 기계에 그대로 넣을 수 있지 않을까?** 16×16 이미지를 4×4 조각 16개로 썰면, "단어 16개짜리 문장"이 됩니다.

**셀프 어텐션은 전원 참석 회의**입니다. CNN 은 "옆집부터 차근차근" — 각 픽셀이 이웃만 보고, 층을 쌓아야 시야가 넓어집니다(level04). 어텐션은 첫 층부터 **모든 패치가 한 회의실에 모여, 누구의 발언을 얼마나 참고할지 각자 정합니다.** 왼쪽 위 패치가 "나랑 관련 깊은 건 오른쪽 아래 패치네"라고 판단하면 거리와 무관하게 바로 참고합니다. 멀리 떨어진 부분들의 관계(긴 의존성)를 단번에 잡는 것이 어텐션의 힘입니다.

**CLIP 식 멀티모달은 만국 공용 좌표계**입니다. 이미지 담당 부서와 텍스트 담당 부서가 각자 보고서를 쓰되, **같은 좌표계의 벡터로 요약해 제출**하기로 약속합니다. "고양이 사진"의 벡터와 "a photo of a cat"이라는 문장의 벡터가 가깝도록 수억 쌍으로 훈련하면 — 이후엔 텍스트로 이미지를 검색하고, 라벨 없이도 "이 사진은 어떤 문장과 가장 가까운가?"로 분류(제로샷)할 수 있게 됩니다.

## 3. 핵심 개념

### 3.1 ViT 의 조립 순서

1. **패치 토큰화**: H×W 이미지를 P×P 조각으로 자름. (16×16, P=4 → 토큰 16개. 실제 ViT 는 224×224, P=16 → 토큰 196개)
2. **패치 임베딩**: 각 조각의 픽셀값을 한 줄로 펴서 Linear 로 d차원 벡터화. "단어 임베딩"의 이미지판.
3. **위치 인코딩**: 어텐션은 순서를 모르므로("가방 속 단어들"), 각 토큰에 위치 벡터를 더해 자리를 새깁니다.
4. **셀프 어텐션 층 × N**: 아래 3.2.
5. **요약 → 분류 head**: 토큰들을 평균(또는 전용 요약 토큰)해 클래스 점수로.

### 3.2 셀프 어텐션 — Q·K·V 세 개의 안경

각 토큰이 세 벡터를 만듭니다. **Query**("내가 찾는 것"), **Key**("내가 가진 것"), **Value**("내가 전달할 내용"). 모든 토큰 쌍에 대해 Q·K 내적으로 관련도를 재고, softmax 로 "주목 배분표"(각 행의 합=1)를 만든 뒤, 그 비율대로 V 를 섞어 가져옵니다.

```
attn = softmax(Q Kᵀ / √d),   출력 = attn V
```

이 배분표(어텐션 맵)가 부산물로 나오는 덕분에 "모델이 어디를 보고 판단했나"를 들여다볼 수 있습니다 — main.py 의 시각화가 그것입니다.

### 3.3 CNN vs ViT — 사전 지식의 유무

CNN 은 지역성·위치 불변성이라는 사전 지식을 구조에 내장했습니다(level05 에서 이것이 "공짜 데이터"임을 봤습니다). ViT 는 그 사전 지식을 거의 넣지 않는 대신, **데이터가 아주 많으면 이미지에 맞는 보는 법 자체를 스스로 찾아냅니다**. 그래서 경험칙은: 데이터가 적으면 CNN(또는 사전학습 ViT 의 전이학습, level07), 데이터·계산이 크면 ViT 계열이 우세. 오늘 우리 실습(600장)에서 미니 ViT 가 CNN 을 압도하지 못하는 것은 이 원리의 정직한 반영입니다.

### 3.4 CLIP 식 정렬과 제로샷 (개념만)

이미지 인코더(ViT 등)와 텍스트 인코더가 각각 벡터를 내고, "짝인 이미지-문장은 가깝게, 아닌 쌍은 멀게"라는 대조 학습(contrastive learning)으로 함께 훈련됩니다. 결과물의 실무 활용:

- **텍스트 → 이미지 검색**: 라벨링 안 된 사진 창고를 문장으로 검색.
- **제로샷 분류**: 후보 문장들("찢어진 포장", "정상 포장")의 벡터와 이미지 벡터의 유사도 비교만으로, 그 클래스용 학습 없이 분류.
- **생성·이해 모델의 눈**: 이미지 설명 생성, 문서 이해 등 멀티모달 LLM 의 시각 입력부가 이런 정렬된 인코더 위에 세워집니다.

한계도 함께: 미세한 결함처럼 언어로 잘 안 갈라지는 구분, 도메인 특수 이미지에서는 제로샷 성능이 급락합니다. "제로샷 데모가 그럴듯해도 반드시 우리 데이터로 평가"가 실무 수칙입니다.

## 4. 실습 — main.py

실행:

```bash
python3 main.py
```

- **[1]** 도형 이미지를 4×4 패치 16개로 토큰화합니다. 패치별 평균 밝기를 4×4 로 찍어 "조각들에도 도형의 위치가 남아 있음"을 확인합니다.
- **[2]** 패치 임베딩(Linear 16→32)과 학습형 위치 인코딩을 설명·구성합니다.
- **[3]** 셀프 어텐션을 `Q @ Kᵀ / √d → softmax → @ V` 행렬 연산으로 직접 구현합니다 (`MiniViT.forward` 6줄).
- **[4]** 미니 ViT(파라미터 5,283개)를 도형 분류로 80에폭 학습합니다. 테스트 정확도 약 0.92 — level05 CNN(0.97)에 못 미치는 것도 배움입니다(3.3절).
- **[5]** 클래스별 이미지 하나씩에 대해 **평균 어텐션 맵**을 뽑아 원본 위에 겹쳐 `outputs/vit_attention.png` 로 저장합니다. 밝은 패치 = 판단에 많이 참고된 곳. 도형 위에 몰려 있는 것을 눈으로 확인하세요 — 누구도 "도형을 봐라"라고 가르치지 않았는데, 분류를 잘하려다 보니 어텐션이 도형으로 향한 것입니다.

## 6. 자주 하는 실수

- **어텐션 맵 = 완전한 설명이라는 과신**: 어텐션은 "어디를 참고했나"의 단서일 뿐, 인과적 설명이 아닙니다. 보조 자료로만 쓰세요.
- **작은 데이터에 ViT 강행**: 사전학습 없이 소규모 데이터로 ViT 를 처음부터 학습하면 CNN 보다 못한 경우가 많습니다. 전이학습(level07)이 전제입니다.
- **"멀티모달 = 무조건 최신·우월"**: 고정 클래스 분류·탐지 과제라면 전용 모델이 더 싸고 정확합니다. 멀티모달의 값어치는 언어 인터페이스가 필요할 때 나옵니다.
- **√d 나누기 누락**: 어텐션 점수를 차원 제곱근으로 안 나누면 softmax 가 한 곳에 몰려 학습이 불안정해집니다. 직접 구현할 때 단골 버그입니다.
