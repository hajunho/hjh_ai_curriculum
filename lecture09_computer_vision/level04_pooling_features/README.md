# Lecture 09 · Level 04 — 풀링과 특징의 계층

> "어디쯤에 있었는지"만 남기고 세부 위치를 버리는 요약 연산 — 풀링이 왜 CNN 을 튼튼하게 만드는지 feature map 으로 확인합니다.
**난이도** ⭐⭐⭐ / **선행** level03 / **예상 시간** 35분

## 1. 왜 배우나 — 비즈니스 관점

불량 검사 카메라 앞에서 제품이 매번 1~2mm 씩 어긋나게 놓입니다. 문서 스캔은 살짝 기울고, 매장 진열 사진 속 상품은 조금씩 다른 자리에 있습니다. 픽셀 좌표에 민감한 시스템이라면 이 "약간의 어긋남"마다 오작동할 것입니다. 실세계 비전 시스템의 필수 덕목은 **위치가 조금 달라져도 같은 판단을 내리는 것**이고, CNN 에서 이 덕목을 담당하는 부품이 풀링(pooling)입니다.

또 하나. "딥러닝은 층이 깊을수록 좋다"는 말의 실제 의미 — **앞 층은 점·선 같은 저수준 특징을, 뒷 층은 부품·형태 같은 고수준 특징을 본다** — 를 이해하면, "우리 과제엔 몇 층짜리가 필요한가?"라는 질문에 감이 생깁니다. 미세한 흠집 검출은 앞 층 특징이 중요하고, 제품 종류 분류는 뒷 층 특징이 중요합니다.

## 2. 비유로 이해하기

**지역별 요약 보고**를 떠올려 보세요. 전국 200개 매장의 일일 지표를 본사가 전부 볼 수는 없으니, 권역별로 묶어 "수도권 최고 매출 매장: 5,200만 원" 식으로 **구역당 대표값 하나**만 올립니다. 개별 매장의 세세한 순위는 사라지지만, "수도권 어딘가에 대박 매장이 있다"는 핵심은 남습니다.

**맥스 풀링(max pooling)** 이 정확히 이것입니다. 특징 맵을 2×2 구역으로 나누고, 구역마다 **최댓값 하나**만 남깁니다. "이 구역 안 어딘가에서 세로 엣지가 강하게 검출됐다"는 정보는 유지되고, "정확히 어느 픽셀이었는지"는 버려집니다. 그래서 물체가 1~2픽셀 이동해도 풀링 후 결과는 거의 같습니다 — 요약 보고는 매장이 옆 블록으로 이사해도 바뀌지 않으니까요.

특징의 계층은 **회사 보고 체계**와 같습니다. 현장 직원(1층)은 원자료의 세부(픽셀의 명암 변화 = 엣지)를 보고, 팀장(2층)은 직원 보고의 조합(엣지들의 배열 = 모서리·곡선)을 보고, 임원(3층)은 팀장 보고의 조합(부품들의 배치 = "둥근 외곽선을 가진 물체")을 봅니다. 위로 갈수록 **추상적이고, 넓은 범위를 대표**합니다.

## 3. 핵심 개념

### 3.1 맥스 풀링의 연산

`MaxPool2d(kernel_size=2, stride=2)`: 2×2 창을 겹치지 않게 밀며 창 안의 최댓값을 취합니다. 출력은 가로세로 절반, 채널 수는 그대로. **파라미터가 0개**라는 점이 중요합니다 — 배우는 것이 없는 고정 요약 규칙입니다.

평균 풀링(average pooling)은 최댓값 대신 평균을 취합니다. "가장 강한 증거"(max) vs "전반적 경향"(mean)의 차이로, 분류 CNN 중간층에는 max 가, 마지막 요약(글로벌 평균 풀링)에는 mean 이 자주 쓰입니다.

### 3.2 풀링이 주는 세 가지 효과

1. **이동 강건성(translation robustness)**: 입력이 1~2픽셀 이동해도 구역 최댓값은 거의 유지됩니다. main.py 에서 실험으로 확인합니다.
2. **계산량·크기 절감**: 가로세로 절반 = 다음 층 계산 1/4. Flatten 크기도 줄어 뒷단 Linear 파라미터가 급감합니다.
3. **시야(receptive field) 확대**: 풀링 후의 한 픽셀은 원본의 더 넓은 영역을 대표하므로, 같은 3×3 커널이라도 뒷 층에서는 더 큰 패턴을 보게 됩니다.

### 3.3 stride 합성곱 vs 풀링

level03 의 TinyCNN 은 stride=2 합성곱으로 크기를 줄였습니다. 풀링과 stride 합성곱은 모두 "공간 축소" 수단이며, 전자는 고정 규칙·파라미터 0, 후자는 학습되는 축소입니다. 고전 구조(예: VGG 계열 설계 관행)는 `Conv-Conv-MaxPool` 블록을, 근래 구조는 stride 합성곱을 즐겨 씁니다. 둘 다 읽을 수 있으면 됩니다.

### 3.4 특징의 계층 — 왜 생기는가

설계자가 "1층은 엣지를 봐라"라고 지시한 적이 없습니다. 구조가 그렇게 만듭니다. 1층 커널은 원본 픽셀 3×3 만 볼 수 있으니 명암 변화(엣지) 이상을 볼 수 없고, 2층은 1층 결과의 3×3 — 즉 원본 기준 더 넓은 영역의 엣지 조합 — 을 보게 되고, 풀링을 거치며 이 시야가 기하급수로 넓어집니다. **저수준→고수준 계층은 지역성+쌓기+풀링의 필연적 결과**입니다.

### 3.5 잃는 것도 있다

풀링은 위치 정보를 버립니다. 분류("무엇인가")에는 유리하지만, 정확한 위치가 중요한 과제 — 객체 탐지(level09), 세그멘테이션(level10) — 에서는 이 손실이 문제가 되어, 위치를 복원하는 별도의 장치가 필요해집니다. "요약 보고만으로는 매장 주소를 모른다"는 한계를 기억해 두세요.

## 6. 자주 하는 실수

- **풀링에 파라미터가 있다고 생각하기**: MaxPool 은 배우는 것이 없는 고정 규칙입니다. 모델 크기 계산에서 0으로 칩니다.
- **풀링을 채널 방향에도 적용된다고 착각**: 풀링은 공간(H, W)만 줄입니다. 채널 수는 그대로입니다.
- **무조건 풀링을 많이 넣기**: 매층 풀링하면 위치 정보가 너무 빨리 사라져, 작은 물체·미세 결함은 아예 못 보게 됩니다. 축소는 과제가 허용하는 만큼만.
- **"뒷 층이 더 똑똑하다"는 오해**: 뒷 층은 더 추상적일 뿐입니다. 미세 흠집 검출처럼 저수준 특징이 답인 과제도 많습니다. 과제와 층 수준을 맞추는 것이 설계입니다.
