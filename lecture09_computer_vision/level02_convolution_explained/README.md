# Lecture 09 · Level 02 — 합성곱(Convolution) 이해

> CNN 의 심장인 합성곱을 numpy 로 밑바닥부터 구현하고, 3×3 커널이 도형의 엣지를 찾아내는 순간을 눈으로 봅니다.
**난이도** ⭐⭐⭐ / **선행** level01 / **예상 시간** 40분

## 1. 왜 배우나 — 비즈니스 관점

이미지 AI 관련 기술 문서·제안서·논문 요약에는 반드시 "합성곱(convolution)", "커널(kernel)", "필터(filter)"라는 단어가 나옵니다. 이 단어를 블랙박스로 두면 "CNN 이 특징을 추출한다"는 설명이 주문(呪文)처럼 들리고, 검증할 수 없는 이야기가 됩니다.

합성곱의 실체는 놀랄 만큼 작습니다. **작은 숫자판(커널)을 이미지 위에서 밀며, 겹친 자리끼리 곱해 더하는 것.** 이 한 가지 연산이 흐림·선명화·엣지 검출 같은 고전 이미지 처리와, 최신 CNN 의 특징 추출을 모두 담당합니다. 오늘 이것을 반복문으로 직접 짜 보면, 이후 어떤 CNN 구조를 만나도 "결국 저 곱셈-덧셈을 층층이 쌓은 것"으로 읽을 수 있게 됩니다.

## 2. 비유로 이해하기

**도장 찍으며 서류 검토하기**를 상상해 보세요. 3×3 칸짜리 투명한 검사 도장이 있습니다. 도장에는 칸마다 가중치 숫자가 적혀 있습니다. 이 도장을 큰 서류(이미지)의 왼쪽 위부터 오른쪽 아래까지 한 칸씩 밀며 찍어 갑니다. 한 번 찍을 때마다 하는 일은 단 하나 — **도장 칸의 숫자 × 서류 칸의 숫자를 9쌍 모두 곱해서 합산**하고, 그 합계를 새 서류의 해당 위치에 적는 것입니다.

핵심은 도장에 **어떤 숫자를 새기느냐**입니다.

- 모든 칸이 1/9 인 도장 → 주변 9칸의 평균 = **흐림(blur)**
- 왼쪽 열이 -1, 오른쪽 열이 +1 인 도장 → "오른쪽이 왼쪽보다 밝은가?"를 재는 검사 = **수직 엣지 검출**

즉 커널은 **"이 지역에서 무엇을 찾을지"가 새겨진 검사 도장**이고, 출력(특징 맵)은 **검사 결과 지도** — "찾는 패턴이 어디서 얼마나 강하게 나타났나"의 표입니다.

## 3. 핵심 개념

### 3.1 연산의 정의

입력 이미지 `I`, `k×k` 커널 `K` 에 대해, 출력의 (y, x) 값은 커널을 그 위치에 겹쳐 놓고 원소별 곱을 전부 더한 것입니다.

```
out[y, x] = Σ_i Σ_j  I[y+i, x+j] * K[i, j]
```

코드로는 반복문 두 개와 `(patch * K).sum()` 한 줄입니다. main.py 의 `conv2d()`가 정확히 이 모양입니다.

### 3.2 엣지 검출 커널 읽는 법

수직 엣지 커널(소벨 계열)을 읽어 봅시다.

```
-1  0  +1
-2  0  +2
-1  0  +1
```

이 커널의 출력값 = (오른쪽 3칸의 밝기 합) − (왼쪽 3칸의 밝기 합). 좌우 밝기가 같으면 0, **왼쪽은 어둡고 오른쪽이 밝은 세로 경계선**에서 큰 양수, 반대 방향 경계선에서 큰 음수가 나옵니다. 이것을 90도 돌리면 수평 엣지 커널이 됩니다. "커널 = 무엇에 반응할지가 적힌 패턴 감지기"라는 문장이 여기서 나옵니다.

### 3.3 출력 크기·패딩·스트라이드

- 도장이 서류 밖으로 나갈 수는 없으므로, `n×n` 이미지에 `k×k` 커널을 찍으면 출력은 `(n-k+1)×(n-k+1)` 로 **줄어듭니다**. 16×16 에 3×3 이면 14×14.
- 크기를 유지하고 싶으면 가장자리에 0 테두리를 두르고 찍습니다 — **패딩(padding)**.
- 한 칸씩이 아니라 두 칸씩 건너뛰며 찍으면 출력이 절반 크기가 됩니다 — **스트라이드(stride)**. 계산량 절약과 요약 효과가 있습니다. (수식과 층 설계는 level03 에서 다룹니다.)

### 3.4 왜 이미지에는 합성곱인가

이미지의 두 가지 성질과 정확히 맞물립니다.

1. **지역성**: "경계선인가?"는 주변 몇 픽셀만 보면 판단됩니다. 3×3 커널이면 충분한 질문이 많습니다.
2. **위치 불변성**: 왼쪽 위의 세로 경계선과 오른쪽 아래의 세로 경계선은 같은 패턴입니다. 커널 하나를 온 이미지에 재사용하는 합성곱은 "같은 검사를 모든 위치에서 실시"하므로, 위치마다 따로 배울 필요가 없습니다. 이것이 CNN 이 MLP 보다 파라미터가 압도적으로 적은 이유입니다 (level05 에서 성능으로 확인합니다).

### 3.5 손으로 새기던 커널, 이제는 학습으로

고전 이미지 처리에서는 전문가가 소벨·라플라시안 같은 커널을 **손으로 설계**했습니다. CNN 의 혁신은 단 하나 — **커널 속 숫자를 데이터가 정하게 한 것**입니다. lecture06 level00 의 "사람은 규칙의 모양만 정하고 숫자는 데이터가 정한다"가 이미지 세계에서 재현되는 셈입니다. 오늘은 손으로 새긴 커널로 원리를 확인하고, level03 부터 학습되는 커널로 넘어갑니다.

## 4. 실습 — main.py

실행:

```bash
python3 main.py
```

- **[1]** 6×6 미니 이미지와 3×3 커널로 합성곱 한 번을 **숫자 그대로** 추적합니다. 첫 위치에서 9쌍의 곱과 합을 낱낱이 출력하므로, 연산의 전부를 눈으로 검산할 수 있습니다.
- **[2]** `conv2d()` 를 반복문으로 구현하고, 출력 크기가 (n-k+1)로 줄어드는 것과 제로 패딩으로 크기가 유지되는 것을 확인합니다.
- **[3]** `shape_images()` 의 사각형·원·삼각형에 수직/수평 엣지 커널을 적용합니다. 사각형은 수직 커널에서 좌우 변만, 수평 커널에서 위아래 변만 밝게 남는 것 — "커널마다 다른 질문을 던진다"를 확인하세요.
- **[4]** 같은 이미지에 흐림(평균) 커널과 선명화 커널도 적용해, 커널 숫자만 바꾸면 전혀 다른 효과가 나는 것을 봅니다.
- **[5]** 도형 3종 × (원본, 수직 엣지, 수평 엣지, 엣지 강도) 격자를 `outputs/convolution_edges.png` 로 저장합니다. 엣지 강도는 `sqrt(수직² + 수평²)` — 방향 무관 "여기가 경계다" 지도입니다.

코드 핵심부는 `conv2d()` 딱 8줄입니다. 이 8줄이 이후 모든 레벨에서 `nn.Conv2d` 한 줄로 축약될 뿐, 하는 일은 같습니다.

## 6. 자주 하는 실수

- **곱한 뒤 더하는 것을 "평균"으로 착각**: 합성곱은 합(sum)입니다. 평균 커널은 커널 값 자체를 1/9 로 만들어서 구현하는 것이지, 연산이 평균인 것이 아닙니다.
- **음수 출력에 당황하기**: 엣지 커널의 출력은 음수가 정상입니다(방향 정보). 그대로 imshow 하면 시커멓게 보일 수 있으니 절대값이나 대칭 컬러맵으로 보세요.
- **출력 크기 줄어드는 것을 잊기**: 층을 쌓다 보면 3×3 커널이 매층 2픽셀씩 갉아먹어 어느새 이미지가 사라집니다. 패딩을 왜 쓰는지가 여기서 나옵니다.
- **커널이 클수록 좋다는 착각**: 7×7 하나보다 3×3 두 층이 같은 시야를 더 적은 파라미터로 커버합니다. 현대 CNN 이 3×3 을 표준으로 쓰는 이유입니다.
