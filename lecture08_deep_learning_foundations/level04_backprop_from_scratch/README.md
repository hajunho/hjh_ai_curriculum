# Lecture 08 · Level 04 — 역전파 밑바닥 구현

> 신경망 학습의 심장인 역전파(backpropagation)를 numpy 만으로 직접 구현해 XOR 을 풀고, 수치미분으로 "내 미분이 맞다"는 것까지 검증합니다.

**난이도** ⭐⭐⭐⭐ / **선행** level03 (손실 함수·경사하강법) / **예상 시간** 70분

## 1. 왜 배우나 — 비즈니스 관점

이 레벨은 이 강의 전체에서 가장 어렵고, 가장 가치 있습니다. 역전파를 한 번이라도 손으로 구현해 본 사람과 아닌 사람은 딥러닝을 대하는 태도가 다릅니다. 전자에게 딥러닝은 "미분을 자동으로 해 주는 기계"이고, 후자에게는 "알 수 없는 마법 상자"입니다. 실무에서 마법 상자는 위험합니다 — 학습이 안 될 때 원인을 추론할 수 없고, 벤더의 설명을 검증할 수 없기 때문입니다. 다행히 핵심은 고등학교 미분의 연쇄법칙 하나뿐이고, 다음 레벨부터는 PyTorch 가 이 모든 것을 자동으로 해 줍니다. 즉 **오늘 딱 한 번만 손으로 하고, 평생 자동으로 씁니다.**

## 2. 비유로 이해하기

**불량품 책임 소재 추적.** 공장에서 완제품 불량이 나왔다고 합시다(= 손실이 큼). 품질팀은 이렇게 역추적합니다.

1. 최종 검수 단계: "불량의 몇 %가 조립 공정 탓인가?"
2. 조립 공정: "그 책임 중 몇 %가 부품 A 탓, 몇 %가 부품 B 탓인가?"
3. 부품 공정: "그 책임 중 몇 %가 원자재 탓인가?"

각 단계는 **자기 바로 앞 단계에만** 책임을 나눠 주면 됩니다. 전체 공정을 다 알 필요가 없습니다. 이렇게 책임(오차)을 출력에서 입력 방향으로 거꾸로 흘려보내는 것이 역전파이고, "책임 배분 비율"을 계산하는 수학 도구가 연쇄법칙(chain rule)입니다: 전체 영향 = 각 단계 영향의 곱.

순전파(forward)는 "원자재 → 부품 → 조립 → 완제품"으로 값이 흐르는 것, 역전파(backward)는 같은 길을 거꾸로 "책임"이 흐르는 것입니다. 길이 같으므로, 순전파 때 중간값을 메모해 두면 역전파가 공짜에 가깝게 계산됩니다.

## 3. 핵심 개념

### 3-1. 우리가 만들 신경망: 2-8-1

- 입력 2개(XOR 의 두 좌표) → 은닉 뉴런 8개(tanh) → 출력 1개(sigmoid, 0~1 확률)
- 손실은 이진 크로스엔트로피(BCE). level03 의 채점표 그대로입니다.

### 3-2. 순전파 — 4줄이 전부

```
z1 = X @ W1 + b1      # 1층 가중합
h  = tanh(z1)         # 비선형 (level02 에서 배운 이유로 필수)
z2 = h @ W2 + b2      # 2층 가중합
p  = sigmoid(z2)      # 확률로 변환
```

### 3-3. 역전파 — 책임을 거꾸로 배분

연쇄법칙을 층별로 적으면 다음과 같습니다. 유도는 부록처럼 생각하고, "출력에서 입력으로 곱하며 내려온다"는 구조만 잡아도 충분합니다.

| 단계 | 수식 | 비유 |
|---|---|---|
| 출력층 오차 | dz2 = (p − y) / n | 완제품 불량의 크기. BCE+sigmoid 조합은 이렇게 깔끔히 정리됩니다 |
| W2 의 책임 | dW2 = hᵀ @ dz2 | "은닉 뉴런이 많이 기여했을수록 책임도 크다" |
| 은닉층으로 전달 | dh = dz2 @ W2ᵀ | 책임을 연결 강도 비율로 앞 단계에 배분 |
| tanh 통과 | dz1 = dh × (1 − h²) | tanh 가 포화된 뉴런은 책임이 거의 안 흘러감(기울기 소실의 정체) |
| W1 의 책임 | dW1 = Xᵀ @ dz1 | 입력이 기여한 만큼 책임 배분 |

마지막은 level03 그대로, 모든 가중치를 `W -= 학습률 × dW` 로 업데이트합니다.

### 3-4. 수치미분 검증 — 역전파의 단위 테스트

역전파 구현은 부호 하나, 전치(transpose) 하나 틀리기 쉽습니다. 검산법은 단순합니다. 가중치 하나를 ±0.000001 움직여 loss 변화량을 직접 재고(중앙차분), 역전파가 계산한 값과 비교합니다. 상대오차가 1e-4 미만이면 합격입니다. 느리지만 확실해서, 실제 프레임워크 개발자들도 같은 방식으로 자동미분을 테스트합니다.

## 6. 자주 하는 실수

- **전치·모양(shape) 실수.** `h.T @ dz2` 를 `dz2 @ h.T` 로 쓰는 류의 실수가 가장 흔합니다. 각 배열의 shape 을 주석으로 적으며 짜면 대부분 예방됩니다.
- **순전파 중간값을 저장하지 않음.** 역전파는 h, p 같은 중간값을 다시 씁니다. 저장 없이 재계산하면 느려지고, 다른 입력으로 재계산하면 미분이 틀립니다.
- **수치미분의 h(간격)를 너무 작게.** 1e-12 처럼 잡으면 부동소수점 반올림 오차가 미분값을 삼킵니다. 1e-5~1e-6 이 적당합니다.
- **loss 가 0.6931 에서 멈춤.** ln 2 ≈ 0.693 은 "동전 던지기 수준"이라는 뜻입니다. 학습률이 너무 작거나, 초기 가중치가 전부 0이어서 뉴런들이 똑같이 움직이는 경우(대칭 문제)입니다. 초기화는 반드시 작은 난수로 합니다.
