# Lecture 08 · Level 03 — 손실 함수와 경사하강법

> 모델 학습이란 "채점표(손실 함수) 점수가 낮아지는 방향으로 조금씩 이동하는 것"임을, 1변수 함수 위에서 눈으로 확인합니다.

**난이도** ⭐⭐⭐ / **선행** level02 (활성화 함수) / **예상 시간** 45분

## 1. 왜 배우나 — 비즈니스 관점

딥러닝 프로젝트 회의에서 가장 자주 나오는 말이 "loss 가 안 떨어져요", "학습률을 낮춰 보죠"입니다. 손실 함수(loss function)와 경사하강법(gradient descent)을 모르면 이 대화에 낄 수 없습니다. 반대로 이 둘만 알면, 개발사가 보내온 학습 로그를 보고 "loss 가 튀는 걸 보니 학습률이 큰 것 같은데요?"라고 말할 수 있습니다. 모델 종류가 무엇이든 — 이탈 예측 MLP든, 챗봇용 LLM 이든 — 학습의 뼈대는 전부 "손실을 정의하고, 경사를 따라 내려간다" 하나입니다. 여기서 배우는 원리는 이후 모든 레벨에서 단 한 번도 바뀌지 않고 재사용됩니다.

## 2. 비유로 이해하기

**안개 낀 산에서 하산하기.** 짙은 안개 속 산 중턱에 서 있다고 상상해 보세요. 지도도 없고 정상도 골짜기도 보이지 않습니다. 유일하게 알 수 있는 것은 **발밑의 경사** — 어느 쪽이 내리막인지뿐입니다. 합리적인 전략은 하나입니다. 내리막 방향으로 한 걸음 걷고, 다시 발밑을 확인하고, 또 한 걸음. 이것이 경사하강법의 전부입니다.

- **산의 높이** = 손실(loss). 모델이 얼마나 틀렸는지의 점수입니다. 낮을수록 좋습니다.
- **현재 위치** = 모델의 파라미터(가중치) 값.
- **발밑 경사** = 기울기(gradient). 미분이 알려 줍니다.
- **보폭** = 학습률(learning rate). 이번 레벨의 주인공입니다.

보폭이 너무 짧으면 해가 져도 골짜기에 못 갑니다. 보폭이 너무 크면 골짜기를 훌쩍 뛰어넘어 반대편 벼랑으로, 다시 더 높은 곳으로 — 오히려 산을 "올라가" 버립니다. 실습에서 이 세 경우를 전부 재현합니다.

## 3. 핵심 개념

### 3-1. 손실 함수 = 모델의 채점표

손실 함수는 "모델의 예측이 정답에서 얼마나 먼가"를 숫자 하나로 요약합니다. 문제 유형에 따라 표준 채점표가 다릅니다.

| 문제 | 손실 함수 | 직관 |
|---|---|---|
| 회귀 (매출 예측) | MSE(평균제곱오차) | 오차를 제곱해 평균. 큰 실수에 큰 벌점 |
| 이진 분류 (이탈 여부) | 이진 크로스엔트로피(binary cross-entropy) | "정답에 부여한 확률"이 낮을수록 큰 벌점 |
| 다중 분류 (도형 3종) | 크로스엔트로피 | 위와 같음, 클래스가 여러 개 |

왜 분류에 MSE 를 안 쓸까요? 확률 출력(0~1)에 MSE 를 쓰면 틀렸을 때의 벌점이 충분히 가파르지 않아 학습이 느려집니다. 크로스엔트로피는 "정답 확률을 0.01로 예측"한 경우에 벌점을 기하급수적으로 키워, 확신에 찬 오답을 강하게 교정합니다.

### 3-2. 기울기 = 발밑 경사 측정기

기울기(미분)는 "지금 위치에서 x 를 아주 조금 키우면 손실이 얼마나 변하나"입니다. 기울기가 양수면 오른쪽이 오르막이므로 왼쪽으로, 음수면 오른쪽으로 이동합니다. 업데이트 식은 이 한 줄입니다.

```
x_new = x_old - 학습률 × 기울기
```

마이너스가 붙는 이유: 기울기는 "오르막 방향"을 가리키므로, 하산하려면 반대로 가야 합니다.

### 3-3. 학습률 — 가장 중요한 다이얼

| 학습률 | 증상 | 로그에서 보이는 모습 |
|---|---|---|
| 너무 작음 | 수렴이 하세월 | loss 가 아주 천천히, 그러나 꾸준히 감소 |
| 적당함 | 몇 스텝 만에 골짜기 도착 | loss 가 빠르게 떨어진 뒤 평평해짐 |
| 너무 큼 | 골짜기를 계속 건너뜀 | loss 가 진동하거나 폭발(NaN) |

실무 팁: 처음엔 0.1, 0.01, 0.001 처럼 10배 간격으로 훑어 보고, 가장 빨리 안정적으로 떨어지는 값 근처를 씁니다.

### 3-4. 수치미분 — 미분 검산기

미분 공식을 손으로 구현하면 실수하기 쉽습니다. 그래서 `(f(x+h) - f(x-h)) / 2h` (중앙차분)로 "아주 조금 움직여 보고 실제 변화량을 재는" 검산을 합니다. 다음 레벨(역전파)에서 이 검산 기법이 핵심 도구가 됩니다.

## 4. 실습 — main.py

실행:

```bash
cd lecture08_deep_learning_foundations/level03_loss_gradient_descent
python3 main.py
```

출력 순서:

- **[1]~[2]** 손실 함수 f(x) = (x-3)² + 0.7·sin(3x) 를 소개하고, 해석적 미분과 수치미분이 일치함을 검산합니다 (둘 다 +6.849769).
- **[3]** 시작점 x=9 에서 학습률 0.01 / 0.15 / 1.05 로 각각 30스텝 경사하강을 돌리고, 스텝별 위치와 손실을 출력합니다.
  - 0.01: 30스텝 뒤에도 x≈6.3 — 아직 산 중턱입니다.
  - 0.15: 10스텝 만에 x≈3.5 골짜기 도착, 이후 제자리.
  - 1.05: x 가 −2.9 → 11.4 → … → 103 으로 널뛰며 손실이 10,000을 넘습니다. 발산입니다.
- **[5]** 세 궤적을 함수 곡선 위에 그린 `outputs/gd_learning_rates.png` 를 저장합니다. 파란 사각형이 시작점, 빨간 점들이 이동 경로입니다.

코드 핵심부는 `gradient_descent()` 함수의 단 한 줄, `x = x - lr * grad_f(x)` 입니다. 딥러닝 프레임워크의 옵티마이저도 본질은 이 한 줄의 고급 변형입니다.

## 5. 직접 해보기

1. **(쉬움)** 학습률을 0.15 대신 0.05, 0.3 으로 바꿔 실행해 보세요. 몇 스텝 만에 골짜기에 도착하는지 비교해 보세요. *힌트: `settings` 리스트의 숫자만 바꾸면 됩니다.*
2. **(보통)** 시작점 `x0` 를 9.0 에서 −1.0 으로 바꿔 보세요. 같은 학습률인데 도착 지점이 달라질 수 있습니다. 왜일까요? *힌트: sin 항 때문에 작은 웅덩이(지역 최솟값)가 여러 개 있습니다. 경사하강은 "가장 가까운" 골짜기로 갑니다.*
3. **(도전)** f(x) 를 f(x, y) = (x-1)² + 10·(y-2)² 같은 2변수 함수로 바꾸고, 기울기 벡터 (∂f/∂x, ∂f/∂y) 로 경사하강을 구현해 보세요. x 방향과 y 방향의 경사 가파름이 10배 다를 때 궤적이 지그재그가 되는 것을 관찰해 보세요. *힌트: grad 가 튜플을 반환하게 하고 x, y 를 각각 업데이트합니다.*

## 6. 자주 하는 실수

- **학습률을 한 번 정하고 끝까지 안 바꾸기.** 학습이 안 되면 모델 구조보다 학습률을 먼저 의심하세요. 10배 단위로 조절합니다.
- **부호 실수.** `x + lr * grad` 로 쓰면 산을 올라갑니다. loss 가 꾸준히 "증가"하면 십중팔구 부호나 학습률 문제입니다.
- **지역 최솟값 공포증.** "골짜기가 여러 개면 어쩌죠?"라는 걱정은 1~2차원 직관입니다. 실제 고차원 신경망에서는 지역 최솟값보다 안장점·평평한 구간이 문제이고, 대부분 "충분히 좋은" 골짜기에 도착합니다.
- **loss 값 자체를 성능으로 착각.** loss 는 하산 진행 상황일 뿐, 비즈니스 성능(정확도·재현율)은 별도로 재야 합니다.
