# Lecture 02 · Level 03 — 반복문: 지루한 일 맡기기

> for/while 반복문은 "목록의 모든 건에 대해 같은 절차를 수행하라"는 지시로, 자동화 효과가 가장 크게 체감되는 문법입니다.
**난이도** ⭐ / **선행** level02 / **예상 시간** 45분

## 1. 왜 배우나 — 비즈니스 관점

고객 100명의 구매액을 합산하고, 평균을 내고, 우수 고객을 골라내는 일을 상상해 보세요.
엑셀이라면 SUM·AVERAGE 함수를 쓰겠지만, 매일 파일이 새로 오고 형식이 조금씩 다르고
집계 기준이 복잡해지면 수작업이 늘어납니다. 사람이 100건을 처리하면 중간에 전화가 오고,
집중이 끊기고, 어딘가에서 한 건을 빠뜨립니다.

반복문(loop)은 "이 절차를 목록의 모든 항목에 적용하라"는 한 줄의 지시입니다.
100건이든 100만 건이든 코드는 같고, 품질도 같습니다. 프로그래밍을 배워서 얻는
실무 이득의 대부분 — 반복 업무 자동화 — 이 바로 이 문법에서 나옵니다.
이번 실습에서는 고객 100명 데이터를 "손계산 방식"과 "반복문 방식"으로 나란히 집계해
그 차이를 직접 확인합니다.

## 2. 비유로 이해하기

**우편물 발송 비유.** 신제품 안내문을 고객 100명에게 보내는 업무를 아르바이트생에게
맡긴다고 합시다. 지시서를 이렇게 쓰지는 않습니다.

> "김OO 님 주소를 봉투에 적고 안내문을 넣어라. 이OO 님 주소를 봉투에 적고 안내문을 넣어라. …" (100줄)

이렇게 씁니다.

> "**명단의 각 고객에 대해**: 주소를 봉투에 적고, 안내문을 넣고, 우표를 붙여라."

이 한 줄이 `for` 문입니다. "명단의 각 고객에 대해" = `for customer in customers:`,
그 아래 들여쓰기된 절차가 매번 실행되는 본문입니다.

`while` 문은 조금 다른 지시입니다. "우표가 떨어질 때까지 계속 붙여라"처럼
**몇 번인지는 모르지만 조건이 유지되는 동안 반복**하라는 지시입니다.
횟수가 정해져 있으면 for, 조건으로 끝이 정해지면 while — 이 감각만 있으면 됩니다.

## 3. 핵심 개념

### 3.1 for 문 — 목록을 순회한다

```python
purchases = [120000, 45000, 230000]
total = 0
for amount in purchases:      # 목록에서 한 건씩 꺼내 amount 에 담는다
    total = total + amount    # 매번 실행되는 본문
print(total)                  # 395000
```

`amount` 는 매 바퀴마다 다음 항목으로 바뀌는 **루프 변수**입니다.
합계를 담는 `total` 처럼 반복 전에 0으로 시작해 매 바퀴 쌓아 가는 변수를
**누적 변수(accumulator)** 라고 부릅니다. 집계의 기본 패턴이니 꼭 손에 익히세요.

### 3.2 range — 횟수로 반복하기

```python
for i in range(5):        # 0, 1, 2, 3, 4  (5는 포함 안 됨!)
for i in range(1, 6):     # 1, 2, 3, 4, 5
for i in range(0, 10, 2): # 0, 2, 4, 6, 8  (2씩 건너뛰기)
```

`range(시작, 끝, 간격)` 에서 **끝 값은 포함되지 않습니다**. "0부터 시작해서 끝 직전까지"가
파이썬 전반의 관례입니다. 항목과 순번이 같이 필요하면 `for i, item in enumerate(items):` 를 씁니다.

### 3.3 while 문 — 조건이 참인 동안

```python
budget = 1000000
day = 0
while budget > 0:          # 예산이 남아 있는 동안 반복
    budget -= 87000        # 하루 지출
    day += 1
```

while 은 반드시 **언젠가 조건이 거짓이 되도록** 본문에서 상태를 바꿔야 합니다.
바꾸지 않으면 무한 루프(infinite loop)에 빠집니다. (터미널에서 Ctrl+C 로 강제 종료합니다.)

### 3.4 break 와 continue — 흐름 제어

- `break` : 반복을 즉시 종료하고 빠져나옵니다. "찾았으면 더 볼 필요 없다."
- `continue` : 이번 바퀴만 건너뛰고 다음 항목으로 넘어갑니다. "결측치는 건너뛰고 계속."

```python
for row in rows:
    if row is None:
        continue          # 깨진 데이터는 건너뛰기
    if row == target:
        break             # 찾았으니 반복 종료
```

실무 데이터에는 항상 빈 값·오염 값이 섞여 있어서 continue 로 걸러내는 패턴을 자주 씁니다.

### 3.5 중첩 반복문

반복문 안에 반복문을 넣으면 "모든 지점 x 모든 월" 같은 격자 순회가 됩니다.
바깥 루프 1바퀴마다 안쪽 루프가 전부 도니, 100 x 100 이면 본문이 1만 번 실행됩니다.
편리하지만 데이터가 커지면 느려지는 지점이기도 합니다(lecture03 에서 벡터 연산으로 개선합니다).

## 6. 자주 하는 실수

- **누적 변수 초기화를 반복문 안에 쓰기** — `total = 0` 이 for 안에 들어가면
  매 바퀴 0으로 리셋되어 마지막 1건만 남습니다. 초기화는 반드시 반복문 **앞**에.
- **range 끝 값 착각** — `range(1, 100)` 은 99까지입니다. 100명을 돌려면
  `range(1, 101)` 또는 `range(100)`.
- **무한 루프** — while 본문에서 조건 변수를 갱신하지 않으면 영원히 돕니다.
  while 을 쓸 때는 "이 조건이 언제 거짓이 되지?"를 먼저 자문하세요.
- **반복 중인 목록을 수정** — 순회하면서 그 목록에서 항목을 삭제하면 건너뛰는 항목이
  생깁니다. 결과를 새 목록에 모으는 방식(level04, level10)을 쓰세요.
- **들여쓰기로 소속 착각** — 반복문 안에 있어야 할 print 가 밖에 있으면 마지막 값만
  한 번 출력됩니다. "이 줄은 매 바퀴 실행되는가?"를 들여쓰기로 확인하세요.
