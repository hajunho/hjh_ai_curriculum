# Lecture 02 — 파이썬 프로그래밍 기초

엑셀은 다루지만 코딩은 처음인 비즈니스 직장인을 위한 파이썬(Python) 입문 강의입니다.
"프로그래밍이 대체 뭔가"라는 질문에서 출발해, 12개 레벨을 마치면
데이터 파일을 읽고, 규칙에 따라 판단·집계하고, 결과 리포트를 자동으로 만들어 내는
작은 업무 자동화 프로그램을 스스로 작성할 수 있게 됩니다.

## 무엇을 배우나

- 프로그램이 움직이는 세 가지 원리 — 순차·분기·반복
- 변수, 자료형, 조건문, 반복문, 컬렉션, 함수 등 파이썬의 뼈대 문법
- 파일 입출력, 예외 처리, 모듈화 등 "실무에서 안 깨지는 코드"의 기본기
- 클래스와 객체지향, 컴프리헨션·제너레이터 같은 파이썬다운 표현
- 타입 힌트와 테스트로 코드 품질을 지키는 습관

## 선행 강의

- lecture01 (컴퓨터와 개발 환경) — 터미널에서 `python3 main.py` 를 실행할 수 있으면 충분합니다.

## 빠른 경로 (시간이 없다면)

핵심만 빠르게 훑고 싶다면 다음 5개 레벨을 순서대로 학습하세요.

1. **level01 변수와 자료형** — 모든 코드의 재료
2. **level02 조건문** — 판단 자동화의 시작
3. **level03 반복문** — 자동화 효과가 가장 크게 체감되는 문법
4. **level05 함수** — 코드를 업무 절차서처럼 정리하는 법
5. **level06 파일 읽고 쓰기** — 실제 데이터와 연결되는 관문

이후 필요할 때 level04(자료구조), level07(예외 처리)을 보충하면
lecture03(데이터 다루기)으로 넘어갈 준비가 끝납니다.

## 이 강의가 실무에서 쓰이는 장면

- 매일 아침 받는 거래내역 CSV 를 열어 항목별 합계·이상치 요약 리포트를 자동 생성할 때 (level03·04·06)
- "출장경비 15만 원 이하 자동 승인" 같은 사내 규정을 코드로 옮겨 반복 결재를 없앨 때 (level02)
- 세금·할인 계산 로직이 부서마다 제각각일 때 함수 하나로 통일해 실수를 막을 때 (level05)
- 깨진 데이터 한 줄 때문에 밤새 돌던 배치가 죽는 사고를 예외 처리로 방지할 때 (level07)
- 직원·매니저처럼 비슷하지만 조금 다른 규칙을 클래스 상속으로 깔끔하게 관리할 때 (level09)
- 남이 (혹은 미래의 내가) 봐도 믿고 쓸 수 있도록 타입 힌트와 테스트를 붙일 때 (level11)

모든 실습은 표준 라이브러리만 사용하며, 인터넷 연결 없이
`python3 main.py` 한 줄로 실행됩니다.
