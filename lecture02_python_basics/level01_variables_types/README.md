# Lecture 02 · Level 01 — 변수와 자료형

> 변수는 데이터에 이름표를 붙여 두는 상자이고, 자료형은 그 상자에 담긴 데이터의 종류(정수·실수·문자열·불리언)입니다.
**난이도** ⭐ / **선행** level00 / **예상 시간** 40분

## 1. 왜 배우나 — 비즈니스 관점

엑셀에서 `=B2*C2` 라는 수식을 쓸 때, B2와 C2는 "단가"와 "수량"이 들어 있는 칸의 주소입니다.
그런데 시간이 지나면 B2가 뭐였는지 잊어버리죠. 파이썬에서는 칸에 주소 대신
`unit_price`, `quantity` 처럼 **의미 있는 이름**을 붙일 수 있습니다. 이것이 변수입니다.

변수와 자료형은 모든 코드의 재료입니다. 매출 계산, 고객 명단 정리, AI 모델 학습까지
전부 "값을 변수에 담고 → 가공하고 → 결과를 다른 변수에 담는" 일의 연속입니다.
특히 자료형을 정확히 이해하면 실무에서 흔한 사고 — 숫자 "1000"과 문자 "1000"을
헷갈려 합계가 이상해지는 사고 — 를 예방할 수 있습니다.

## 2. 비유로 이해하기

**이름표 붙은 상자 비유.** 사무실 창고에 상자가 여러 개 있다고 상상해 보세요.
상자마다 이름표가 붙어 있습니다: "3월매출", "고객명단", "부가세율".
필요할 때 이름표로 상자를 찾아 내용물을 꺼내 쓰고, 새 내용물로 갈아 넣을 수도 있습니다.

- `march_sales = 12000000` → "3월매출" 이름표가 붙은 상자에 1200만을 넣는다.
- `print(march_sales)` → 그 상자를 열어 내용물을 확인한다.
- `march_sales = 13000000` → 내용물을 새 값으로 교체한다. (그래서 "변할 수 있는 수", 변수입니다)

**자료형은 상자 속 내용물의 종류**입니다. 상자에 현금이 들었는지, 서류가 들었는지,
도장("승인"/"반려")이 들었는지에 따라 할 수 있는 일이 다릅니다. 현금끼리는 더할 수 있지만,
현금과 서류를 더하라고 하면 말이 안 되죠. 파이썬도 똑같이 "숫자 + 문자"를 시키면
에러를 냅니다.

## 3. 핵심 개념

### 3.1 변수 만들기 — 대입

```python
unit_price = 4500      # "unit_price 상자에 4500을 넣어라"
```

`=` 는 수학의 "같다"가 아니라 **"오른쪽 값을 왼쪽 이름의 상자에 넣어라"** 라는 명령입니다.
그래서 `count = count + 1` (지금 값에 1을 더해 다시 넣기)이 성립합니다.

이름 규칙: 영문 소문자와 밑줄로, 뜻이 드러나게 짓습니다. `a`, `x1` 보다
`total_revenue`, `vat_rate` 가 좋습니다. 코드는 쓰는 시간보다 읽는 시간이 깁니다.

### 3.2 네 가지 기본 자료형

| 자료형 | 이름 | 예 | 실무 용도 |
|---|---|---|---|
| `int` | 정수(integer) | `120`, `-3` | 수량, 인원, 건수 |
| `float` | 실수(floating point) | `0.1`, `4500.0` | 비율, 단가, 평균 |
| `str` | 문자열(string) | `"아메리카노"` | 이름, 주소, 메모 |
| `bool` | 불리언(boolean) | `True`, `False` | 승인 여부, 회원 여부 |

`type(값)` 으로 자료형을 확인할 수 있습니다. 헷갈리면 언제든 물어보세요.

### 3.3 자료형 변환

CSV 파일이나 사용자 입력에서 읽은 값은 전부 문자열입니다. 계산하려면 변환해야 합니다.

```python
int("1000")      # 문자열 -> 정수 1000
float("3.3")     # 문자열 -> 실수 3.3
str(4500)        # 정수 -> 문자열 "4500"
```

`"1000" + "500"` 은 `"1000500"`(문자열 이어붙이기)이 됩니다. 실무 사고 1순위이니
"이 값이 지금 숫자인가 문자인가"를 항상 의식하세요.

### 3.4 f-string — 보고서 문장 만들기

문자열 앞에 `f` 를 붙이면 중괄호 안에 변수를 끼워 넣을 수 있습니다.

```python
name = "아메리카노"
total = 9000
print(f"{name} 매출은 {total}원입니다")      # 아메리카노 매출은 9000원입니다
print(f"{total:,}원")                        # 9,000원  (천 단위 쉼표)
print(f"{0.0525:.1%}")                       # 5.2%     (백분율, 소수 1자리)
```

`{변수:서식}` 형태의 서식 지정은 숫자 보고서를 만들 때 계속 쓰게 됩니다.
`,` (천 단위 쉼표), `.2f` (소수 둘째 자리), `.1%` (백분율) 세 가지만 우선 기억하세요.

### 3.5 산술 연산자 한눈에 보기

계산에 쓰는 기호는 엑셀과 거의 같고, 두 가지만 새로 익히면 됩니다.

| 연산자 | 의미 | 예 | 결과 |
|---|---|---|---|
| `+` `-` `*` `/` | 사칙연산 | `7 / 2` | `3.5` |
| `//` | 몫 (버림 나눗셈) | `7 // 2` | `3` |
| `%` | 나머지 | `7 % 2` | `1` |
| `**` | 거듭제곱 | `2 ** 10` | `1024` |

`//` 와 `%` 는 "5인승 차로 17명을 옮기려면 몇 대가 필요하고 몇 명이 남나" 같은
배분 문제에서 자주 씁니다. `/` 의 결과는 항상 float 라는 점도 기억해 두세요.

### 3.6 실수(float)의 미세 오차

컴퓨터는 소수를 2진법으로 저장하기 때문에 `0.1 + 0.2` 가 정확히 0.3이 아니라
`0.30000000000000004` 가 됩니다. 고장이 아니라 저장 방식의 한계입니다.
금액 비교 시에는 반올림(`round`)을 활용하고, 정밀한 회계라면 정수(원 단위)로
계산하는 것이 안전합니다.

- **[2] 계산**: 매출 = 단가 x 수량, 부가세와 합계를 구합니다. `=` 가 "넣어라"임을 재확인합니다.

## 6. 자주 하는 실수

- **`=` 와 `==` 혼동** — `=` 는 대입(넣기), `==` 는 비교(같은가?)입니다. level02 에서
  비교가 나오면 다시 확인하세요.
- **문자열 숫자를 그대로 계산** — `"100" * 2` 는 200이 아니라 `"100100"` 입니다.
  외부에서 들어온 값은 `int()`/`float()` 변환부터.
- **변수 이름 오타** — `total_revenue` 를 `total_revenu` 로 쓰면
  `NameError: name 'total_revenu' is not defined` 가 납니다. 에러 메시지에 오타 이름이
  그대로 나오니 잘 읽으면 바로 잡을 수 있습니다.
- **의미 없는 이름** — `a`, `b`, `data2` 는 일주일 뒤의 나에게 암호입니다.
  길어도 뜻이 보이는 이름을 쓰세요.
