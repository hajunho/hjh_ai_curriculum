# Lecture 06 — 머신러닝 입문

> 규칙을 하드코딩하는 대신, 데이터에서 패턴을 학습시키는 방법을 처음부터 끝까지 배웁니다.
> 회귀·분류·군집화의 대표 모델을 직접 돌려 보고, "모델을 어떻게 믿을 것인가"(평가·과적합·해석)까지 다룹니다.

## 이 강의에서 배우는 것

- 머신러닝(Machine Learning)이 기존 프로그래밍과 무엇이 다른지, 언제 쓰고 언제 쓰지 말아야 하는지
- 비즈니스 질문("이탈을 줄이고 싶다")을 ML 문제 명세서로 바꾸는 방법
- 선형회귀·로지스틱 회귀·결정트리·랜덤포레스트·그래디언트 부스팅의 원리와 사용법
- 학습/검증/테스트 분리, 평가지표, 과적합과 규제 — 모델을 "제대로 믿는" 기술
- 군집화·차원축소로 정답 없는 데이터에서 구조를 찾는 방법
- 변수 중요도와 개별 예측 설명으로 모델을 비전공자에게 설명하는 방법

## 선행 강의

- **lecture03 — 데이터 다루기** (NumPy 배열, Pandas DataFrame, 결측치 처리)

수학은 고등학교 수준의 직관(직선의 기울기, 확률)만 있으면 충분합니다. 수식보다 비유와 실험으로 설명합니다.

## 이 강의가 실무에서 쓰이는 장면

- **구독/멤버십 운영**: 다음 달 해지할 것 같은 고객을 미리 찾아 쿠폰·상담을 집중 투입 (level05, 07, 11)
- **마케팅 예산 회의**: "광고비를 1천만 원 늘리면 매출이 얼마나 늘까?"에 근거 있는 숫자로 답하기 (level03)
- **이상거래·부정 사용 감시**: 사기 비율 1.5%짜리 데이터에서 정확도 대신 재현율·정밀도로 말하기 (level06)
- **고객 세분화**: 정답표 없이 구매 패턴만으로 고객을 그룹으로 나눠 그룹별 전략 세우기 (level10)
- **외부 업체·데이터팀과의 협업**: "AUC 0.85입니다"라는 보고를 스스로 검증할 수 있는 질문 던지기 (level04, 06, 09)
- **경영진 보고**: "모델이 왜 이 고객을 위험하다고 봤는가"를 변수 중요도와 개별 설명으로 전달 (level11)
