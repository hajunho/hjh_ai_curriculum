# Lecture 06 · Level 09 — 과적합·규제·하이퍼파라미터

> 다항 차수를 올리며 train/valid 오차가 갈라지는 순간을 그래프로 목격하고, 규제(L1/L2)라는 브레이크로 복잡한 모델을 다스리는 법을 배웁니다.
**난이도** ⭐⭐⭐⭐ / **선행** level04 / **예상 시간** 50분

## 1. 왜 배우나 — 비즈니스 관점

이 강의에서 과적합(overfitting)은 이미 세 번 등장했습니다. level04의 낙관 편향, level07의 깊이 무제한 트리, level08의 불안정성 — 전부 같은 병의 다른 증상입니다. 이 레벨에서는 그 병을 정면으로 다룹니다.

실무에서 이것이 중요한 이유는 **모델 선택의 언어**이기 때문입니다. "차수를 올릴까요 내릴까요", "알파를 얼마로 둘까요", "왜 검증 성적이 더 이상 안 오르죠?" — 데이터팀의 일상 대화는 대부분 과적합과 과소적합 사이 어딘가에서 벌어집니다. 이 축을 이해하면 "모델을 더 복잡하게 만들면 좋아지나요?"라는 질문에 "훈련 성적은 항상 좋아지고, 실전 성적은 어느 지점까지만 좋아집니다"라고 답할 수 있게 됩니다. 그 "어느 지점"을 찾는 절차가 하이퍼파라미터 튜닝이고, 지점을 지나쳤을 때 되돌리는 브레이크가 규제입니다.

## 2. 비유로 이해하기

**양복 맞추기**로 생각해 보세요. 손님(데이터)의 몸에는 본질적인 체형(패턴)과 그날의 우연 — 두꺼운 속옷, 방금 먹은 점심(잡음) — 이 섞여 있습니다.

- **과소적합(underfitting)**: 프리사이즈 비닐 우비. 누구에게나 대충 맞고 누구에게도 잘 맞지 않습니다. 모델이 너무 단순해 체형조차 못 담는 상태 — 1차 직선으로 곡선 패턴을 그리려는 격입니다.
- **적정합**: 체형은 따라가되 그날의 우연은 무시하는 좋은 맞춤복. 내일 입어도 잘 맞습니다.
- **과적합**: 오늘 그 순간의 몸에 한 치 오차 없이 밀착시킨 옷. 점심 먹은 배 모양까지 반영했으니 **오늘은 완벽, 내일은 못 입습니다.** 15차 곡선이 훈련 점들을 전부 통과하는 것이 정확히 이 상태입니다.

**규제(regularization)는 재단사에게 주는 지침**입니다: "몸을 따라가되, 굴곡 하나에 과민 반응하지 말 것." 수학적으로는 모델의 계수가 커지는 것에 벌금을 물려, 데이터를 조금 덜 맞추더라도 곡선을 완만하게 유지시킵니다. 벌금 세기(알파)를 조절하는 것이 하이퍼파라미터 튜닝입니다.

## 3. 핵심 개념

### 3.1 파라미터 vs 하이퍼파라미터

- **파라미터**: 학습이 데이터에서 찾아내는 값 (회귀 계수, 트리의 분기점). 기계 담당.
- **하이퍼파라미터(hyperparameter)**: 학습을 시작하기 전에 사람이 정하는 손잡이 (다항 차수, 트리 깊이, 규제 세기 알파, 포레스트 트리 수). 사람 담당 — 단, 감이 아니라 **검증 세트 성적**으로 고릅니다(level04의 모의고사가 정확히 이 용도였습니다).

### 3.2 검증곡선 — 갈라지는 두 선

복잡도(예: 다항 차수)를 x축, 오차를 y축에 놓고 훈련 오차와 검증 오차를 함께 그린 것이 검증곡선(validation curve)입니다. 전형적인 모양:

- 훈련 오차: 복잡도가 오를수록 **단조 감소** (외울 여력이 늘어나므로)
- 검증 오차: 내려가다가(패턴을 더 잘 담음) 어느 지점부터 **다시 올라감**(잡음까지 외우기 시작)

두 선이 갈라지기 시작하는 지점이 과적합의 시작이고, 검증 오차의 최저점이 고를 지점입니다. 오늘 실습의 PNG가 바로 이 그림입니다.

### 3.3 L2와 L1 — 두 종류의 벌금

규제는 손실 함수에 "계수 크기 벌금"을 더합니다.

- **L2 (Ridge)**: 벌금 = α × (계수 제곱의 합). 모든 계수를 **고르게 움츠러들게** 합니다. 계수를 0으로 만들지는 않습니다. 기본 선택지.
- **L1 (Lasso)**: 벌금 = α × (계수 절댓값의 합). 덜 중요한 계수를 **아예 0으로** 만들어 특징을 자동 선별합니다. "수백 개 특징 중 뭐가 진짜인지 추리고 싶을 때" 씁니다.

α(알파)가 0이면 규제 없음(원래 회귀), 너무 크면 모든 계수가 짓눌려 과소적합. α 역시 하이퍼파라미터라 검증으로 고릅니다. 한 가지 실무 규칙: **규제를 쓸 때는 특징 표준화가 사실상 필수**입니다. 단위가 큰 특징일수록 계수가 작아 벌금을 덜 내는 불공평이 생기기 때문입니다.

### 3.4 과적합의 다른 처방들

규제는 처방 중 하나일 뿐입니다. 데이터 늘리기(가장 확실), 특징 줄이기, 모델 단순화(차수·깊이 낮추기), 앙상블(level08), 조기 종료 — 공통 철학은 하나입니다. **모델의 자유를 데이터가 감당할 수 있는 만큼만 허락한다.**

## 4. 실습 — main.py

실행:

```bash
python3 main.py
```

합성 곡선 데이터(진짜 패턴 + 잡음, 훈련 30점)로 과적합의 전 과정을 시연합니다.

- **[1]** 진짜 패턴이 곡선인 데이터를 만들고 훈련/검증으로 나눕니다. 표본을 일부러 30점만 써서 과적합이 잘 보이게 했습니다.
- **[2] 검증곡선 실험**: 다항 차수 1~15를 돌며 훈련/검증 RMSE를 표로 출력합니다. 훈련 오차는 계속 줄고 검증 오차는 U자로 꺾이는 것, 그리고 고차에서 계수가 수십만 단위로 폭주하는 것을 확인하세요.
- **[3]** 차수별 곡선 3개(과소적합 1차, 적정 4차, 과적합 15차)와 검증곡선을 `outputs/overfitting.png`에 저장합니다. 이 그림 한 장이 이 레벨의 전부입니다.
- **[4] Ridge 규제 효과**: 폭주하던 15차 모델에 α를 0→0.001→0.1→10으로 올려 가며 검증 RMSE와 계수 크기가 어떻게 진정되는지 표로 봅니다. "복잡한 모델 + 적절한 벌금 ≈ 적정 모델"을 확인하세요.
- **[5] L1(Lasso) 맛보기**: 15차 특징 중 몇 개의 계수가 정확히 0이 되는지 세어 자동 특징 선별을 확인합니다.

코드 핵심부: `PolynomialFeatures(degree)`로 x, x², … 특징을 만들고 `Pipeline`으로 표준화 후 `LinearRegression`/`Ridge`/`Lasso`에 넣는 구조입니다. 차수와 α라는 두 하이퍼파라미터가 코드 어디에서 "사람의 결정"으로 들어가는지 눈여겨보세요.

## 6. 자주 하는 실수

- **훈련 오차가 줄었다고 좋아지는 중이라 착각**: 훈련 오차는 복잡도를 올리면 **무조건** 줄어듭니다. 정보량이 0인 신호입니다. 검증 오차만이 대답합니다.
- **검증 오차가 오르기 시작했는데 "더 복잡하게" 밀어붙이기**: 갈라진 뒤의 투자(차수, 파라미터, 학습 시간)는 전부 잡음 암기에 쓰입니다.
- **표준화 없이 규제 적용**: 단위 큰 특징이 벌금을 회피합니다. Pipeline으로 표준화를 묶으세요.
- **α를 테스트 세트로 고르기**: level04의 시험지 훔쳐보기가 규제에서도 똑같이 성립합니다. α는 검증(또는 교차검증)으로.
- **과소적합을 과적합으로 오진**: 훈련 오차조차 큰 상태에서 규제를 더 세게 걸면 악화됩니다. 훈련/검증 오차를 **둘 다** 보고 진단하세요.
