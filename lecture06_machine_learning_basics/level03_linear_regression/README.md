## 1. 왜 배우나 — 비즈니스 관점

마케팅 예산 회의에서 "광고비를 1천만 원 더 쓰면 매출이 얼마나 늘까요?"라는 질문이 나왔을 때, "대략 늘겠죠"와 "과거 데이터 기준으로 광고비 1만 원당 매출이 약 1.5만 원 늘었습니다"는 하늘과 땅 차이입니다. 선형회귀(linear regression)는 이런 "얼마나?"에 숫자로 답하는 가장 오래되고, 가장 많이 쓰이고, 가장 설명하기 쉬운 도구입니다.

또 하나의 이유: 선형회귀는 이 강의 전체의 기초 문법입니다. 로지스틱 회귀(level05)는 선형회귀에 확률 변환을 씌운 것이고, 규제(level09)는 선형회귀의 계수를 다스리는 기술이며, 신경망조차 선형회귀를 겹겹이 쌓은 구조입니다. 여기서 "계수", "절편", "오차 최소화"를 확실히 잡으면 이후가 전부 편해집니다.

## 2. 비유로 이해하기

**흩어진 점들 사이로 자를 대는 일**을 상상해 보세요. 일별 (광고비, 매출) 점 1,800여 개가 찍힌 산점도 위에 투명한 자를 올려놓고, "모든 점을 대표하는 직선"을 긋는다면 어디에 대시겠습니까? 어떤 점은 자 위에, 어떤 점은 아래에 있을 겁니다. 좋은 직선이란 **점들과 자 사이의 세로 간격(오차)이 전체적으로 가장 작은 직선**입니다.

최소제곱법(least squares)은 이 "전체적으로 가장 작은"을 정확히 정의한 것입니다. 각 점과 직선의 세로 거리를 제곱해서 다 더한 값(제곱합)이 최소가 되는 직선을 고릅니다. 제곱하는 이유는 두 가지 — 위/아래 오차가 상쇄되지 않게 하고, 큰 오차에 더 큰 벌점을 주기 위해서입니다. 놀라운 점은, 이 최적의 직선이 시행착오 없이 **공식 한 줄로 바로 계산된다**는 것입니다. level00의 "임계값을 전부 시험하는 탐색"과 달리, 선형회귀는 수학이 탐색을 대신 끝내 놓은 경우입니다.

## 3. 핵심 개념

### 3.1 모델의 모양: y = a·x + b

- **x**: 입력 특징 (광고비), **y**: 예측 대상 (매출)
- **a (기울기, 계수 coefficient)**: x가 1 늘 때 y가 느는 양. **비즈니스 해석의 핵심**입니다. "광고비 1만 원당 매출 +a만 원."
- **b (절편 intercept)**: x=0일 때의 y. "광고를 전혀 안 해도 나오는 기본 매출"로 읽되, 데이터 범위 밖 외삽이라 조심해서 해석합니다.

### 3.2 최소제곱 공식

기울기와 절편은 평균·분산·공분산으로 닫힌형(closed-form) 계산이 됩니다.

```
a = Cov(x, y) / Var(x)      (x와 y가 같이 움직이는 정도 ÷ x가 퍼진 정도)
b = mean(y) − a · mean(x)   (직선은 반드시 (x̄, ȳ) 점을 지난다)
```

오늘 실습에서 이 두 줄을 numpy로 직접 계산하고, sklearn의 `LinearRegression`이 내는 답과 소수점까지 일치함을 확인합니다. 라이브러리가 마법이 아니라 이 공식의 포장이라는 것을 눈으로 보는 것이 목적입니다.

### 3.3 얼마나 잘 맞나: R²

결정계수 R²(R-squared)는 "y의 출렁임 중 모델이 설명하는 비율"입니다. 0이면 평균으로 찍는 것과 같고, 1이면 완벽. 실무 데이터에서 R² 0.3~0.7이면 흔한 수준입니다. R²가 낮다고 쓸모없는 것도, 높다고 인과관계가 증명된 것도 아닙니다.

### 3.4 해석의 함정: 상관 ≠ 인과

회귀 계수는 "광고비가 높은 날에 매출도 높았다"는 **동행 관계**를 요약할 뿐입니다. 광고가 매출을 올렸을 수도 있지만, 성수기라 광고도 매출도 함께 늘었을 수도 있습니다. "광고비를 늘리면 매출이 는다"고 단정하려면 실험(A/B 테스트)이나 추가 분석이 필요합니다. 보고서에는 "광고비 1만 원당 매출 +1.5만 원의 **연관**이 관찰됨"처럼 쓰는 것이 안전합니다.

### 3.5 여러 특징을 쓰면: 다중회귀

y = a₁x₁ + a₂x₂ + … + b 형태로 특징을 여러 개 넣을 수 있습니다(다중 선형회귀). 이때 각 계수는 "다른 특징이 같다고 할 때"의 효과로 해석이 바뀌고, 특징 간 단위 차이 때문에 계수 크기 비교에는 표준화가 필요합니다. 오늘은 단순회귀에 집중하고, 다중회귀는 level05 이후 분류 모델들에서 자연스럽게 쓰게 됩니다.
