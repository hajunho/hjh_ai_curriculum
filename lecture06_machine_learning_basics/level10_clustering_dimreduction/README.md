# Lecture 06 · Level 10 — 군집화와 차원축소

> 정답표 없이 고객을 비슷한 그룹으로 묶고(k-means), 변수 여러 개를 2차원 지도로 압축해(PCA) 눈으로 확인하는 비지도학습 실습입니다.
**난이도** ⭐⭐⭐⭐ / **선행** level01, level04 / **예상 시간** 50분

## 1. 왜 배우나 — 비즈니스 관점

"우리 고객은 어떤 부류들로 이루어져 있나?"라는 질문에는 정답 레이블이 없습니다. 이탈 예측처럼 과거의 정답(해지 기록)이 있는 문제가 아니라, **구조 자체를 발견해야 하는** 문제이기 때문입니다. 고객 세분화(segmentation)는 마케팅의 오래된 숙제입니다 — 전 고객에게 같은 문자를 보내는 회사와, "가격 민감형에게는 할인 쿠폰, VIP에게는 전용 혜택, 휴면 위험군에게는 리마인드"를 보내는 회사의 성과는 다릅니다.

군집화(clustering)는 이 세분화를 데이터가 하게 만드는 도구이고, 차원축소(dimensionality reduction)는 변수 수십 개짜리 데이터를 사람 눈이 볼 수 있는 2차원 지도로 눌러 주는 도구입니다. 둘은 세트로 자주 쓰입니다: 군집화로 그룹을 만들고, 차원축소 지도 위에 색칠해서 "그룹이 정말 나뉘어 있는지" 눈으로 검증하는 식입니다.

## 2. 비유로 이해하기

**k-means는 푸드코트 테이블 배치 문제**입니다. 넓은 홀에 손님(데이터 점)들이 흩어져 앉아 있고, 이동식 안내 데스크(중심점) k개를 어디에 둘지 정해야 합니다. 좋은 배치란 모든 손님이 가장 가까운 데스크까지 걷는 거리가 전체적으로 짧은 배치입니다. k-means의 알고리즘은 단순 반복입니다. (1) 데스크를 아무 데나 놓는다 → (2) 각 손님을 가장 가까운 데스크에 배정한다 → (3) 각 데스크를 자기 손님들의 한가운데로 옮긴다 → (2)와 (3)을 더 움직이지 않을 때까지 반복. 이 단순한 왕복이 손님들을 k개의 자연스러운 무리로 나눕니다.

**PCA는 그림자 각도 고르기**입니다. 손에 든 복잡한 철사 조형물(고차원 데이터)을 벽에 그림자(2차원)로 비춘다고 합시다. 각도를 잘못 고르면 조형물이 한 줄로 뭉개져 보이고, 잘 고르면 구조가 살아 있는 그림자가 집니다. PCA(주성분 분석)는 **데이터가 가장 넓게 퍼져 보이는 각도** — 정보 손실이 가장 적은 투영 방향 — 를 수학으로 찾아 주는 도구입니다. "제1주성분"이 가장 넓게 퍼지는 축, "제2주성분"이 그다음 축입니다.

## 3. 핵심 개념

### 3.1 k-means 사용 시 알아야 할 것

- **k는 사람이 정한다**: 몇 그룹이 "정답"인지 데이터는 말해 주지 않습니다. 참고 도구로 엘보(elbow) 방법 — k를 늘려 가며 총 이동거리(inertia)를 그려, 감소가 급히 꺾이는 지점을 찾는 법 — 을 쓰지만, 최종 결정은 "그 그룹 수로 마케팅 액션이 나뉘는가"라는 업무 판단입니다.
- **표준화 필수**: 거리 기반이라 단위 큰 변수(연 구매액, 수백만 원)가 단위 작은 변수(방문 횟수)를 압도합니다.
- **초기 위치 운**: 시작 배치에 따라 결과가 달라질 수 있어 여러 번 시도해 최선을 취합니다(`n_init`).
- **한계**: 둥근 무리를 가정하므로 길쭉하거나 도넛형 무리에는 약합니다. 모든 점을 어딘가에 반드시 배정하므로 이상치도 어느 그룹에 끼어듭니다.

### 3.2 군집 해석 — 기계가 못 하는 절반

k-means가 주는 것은 "0번, 1번, 2번, 3번 그룹"이라는 번호뿐입니다. **각 그룹의 평균 프로필을 보고 "알뜰 신규형", "VIP 단골형" 같은 이름을 붙이는 것은 사람의 일**이며, 이름이 붙어야 액션이 나옵니다. level01에서 말한 "비지도학습의 해석 비용"이 바로 이 단계입니다. 프로필이 해석되지 않으면 k나 변수 선택을 바꿔 다시 — 이 왕복이 정상 과정입니다.

### 3.3 PCA 사용 시 알아야 할 것

- **설명 분산 비율**: 각 주성분이 원본 정보(분산)의 몇 %를 담는지 나옵니다. PC1+PC2가 70%라면 "2차원 그림자에 원본의 70%가 담겼다"는 뜻 — 지도를 얼마나 믿을지의 근거입니다.
- **축의 해석**: 각 주성분은 원본 변수들의 가중합입니다. 가중치(loading)를 보면 "PC1은 대체로 '소비 규모' 축, PC2는 '할인 민감도' 축"처럼 읽을 수 있습니다.
- **용도**: 시각화 외에도, 변수가 너무 많을 때 모델 입력을 압축하는 전처리로 씁니다(잡음 제거 효과도 있음).
- **역시 표준화 필수**: 분산 기준이라 단위 큰 변수가 축을 독점합니다.

### 3.4 비지도학습의 평가는 왜 애매한가

정답이 없으므로 정확도 같은 지표가 없습니다. 실루엣 점수(자기 군집과 가깝고 남의 군집과 먼 정도) 같은 내부 지표가 있지만 보조 수단이고, 궁극의 평가는 **"이 세분화로 한 캠페인이 성과를 냈는가"**라는 다운스트림 검증입니다.

## 4. 실습 — main.py

실행:

```bash
python3 main.py
```

합성 고객 데이터로 세분화 전 과정을 수행합니다.

- **[1]** `make_blobs`로 "숨은 4개 유형"을 가진 고객 800명을 만들고, 각 축을 구매액·방문수·할인사용률·가입개월의 현실적 척도로 변환합니다. (모델에게는 유형을 알려 주지 않습니다 — 비지도 상황 재현)
- **[2]** 표준화 후 k=2~8로 k-means를 돌려 엘보 표(inertia)와 실루엣 점수를 출력하고 k=4를 고릅니다.
- **[3]** k=4 군집의 **프로필 표**(군집별 평균 구매액·방문·할인율·가입개월·인원)를 출력하고, 각 군집에 이름("VIP 단골형" 등)을 자동 제안합니다 — 이름 규칙 코드를 읽고 여러분이라면 어떻게 명명할지 생각해 보세요.
- **[4]** PCA로 4개 변수를 2차원으로 눌러 설명 분산 비율과 각 축의 가중치(loading)를 출력합니다.
- **[5]** PCA 2D 지도 위에 군집을 색으로 칠한 산점도를 `outputs/segments_pca.png`로 저장합니다. 그림에서 군집들이 실제로 분리되어 보이는지 확인하세요.

코드 핵심부: `KMeans(n_clusters=k, n_init=10)`와 `PCA(n_components=2)`. 그리고 [3]의 프로필 집계(`groupby("cluster").mean()`)가 실무에서 가장 오래 들여다보게 되는 표입니다.

## 6. 자주 하는 실수

- **표준화 생략**: 군집도 PCA도 단위 큰 변수가 지배해 버립니다. 이 레벨 최대의 함정입니다.
- **k-means 결과를 "발견된 진실"로 격상**: k-means는 어떤 데이터든 k개로 **반드시** 나눕니다. 구조가 없어도 나눕니다. 실루엣·엘보·시각화로 구조의 실재를 교차 확인하세요.
- **군집 번호를 그대로 보고서에 쓰기**: "군집 2가 이탈률이 높습니다"는 전달력이 없습니다. 프로필 기반의 이름을 붙이세요. 또 군집 번호는 재실행하면 뒤바뀔 수 있는 임의 번호입니다.
- **PCA 축을 물리적 실체로 해석**: 주성분은 수학적 방향이지 "고객의 본성"이 아닙니다. loading을 보고 조심스럽게 이름 붙이되, 설명 분산이 낮으면 지도 자체를 과신하지 마세요.
- **세분화 후 액션 설계 생략**: 그룹만 나누고 끝나는 세분화 프로젝트가 부지기수입니다. level02의 명세서 원칙(액션 없는 분석은 장식품)은 비지도학습에도 그대로 적용됩니다.
