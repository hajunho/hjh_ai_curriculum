# Lecture 06 · Level 08 — 랜덤포레스트와 앙상블

> 불안정한 트리 한 그루 대신, 서로 조금씩 다른 트리 수백 그루를 길러 투표시키면 왜 더 강해지는지 — 집단지성의 원리를 실험으로 확인합니다.
**난이도** ⭐⭐⭐ / **선행** level07 / **예상 시간** 45분

## 1. 왜 배우나 — 비즈니스 관점

표 형태(tabular) 데이터의 실무 예측 문제 — 이탈, 연체, 수요, 전환 — 에서 "일단 돌려 보는 강력한 기본기"가 랜덤포레스트(random forest)입니다. 전처리에 까다롭지 않고, 하이퍼파라미터를 거의 안 만져도 준수한 성능이 나오고, 과적합에 상대적으로 강합니다. 데이터 분석 대회와 실제 기업 현장 모두에서 "첫 제출용 모델"의 왕좌를 오래 지킨 이유입니다.

비즈니스 관점에서 이 레벨의 또 다른 소득은 **안정성**이라는 평가축을 얻는 것입니다. 이번 달 데이터로 만든 모델과 다음 달 데이터로 만든 모델이 완전히 다른 소리를 하면, 성능이 좋아도 조직이 신뢰하지 않습니다. "성능이 얼마나 좋은가"만큼 "결과가 얼마나 요동치는가"를 따지는 습관을 여기서 만듭니다.

## 2. 비유로 이해하기

**소 무게 맞히기 대회** 이야기가 유명합니다. 축제에서 소 한 마리의 무게를 관중 수백 명이 각자 추측했는데, 개개인은 크게 틀렸지만 **모든 추측의 평균은 전문가보다 정확**했습니다. 각자의 실수가 서로 다른 방향이라 평균 내면 상쇄되기 때문입니다. 이것이 집단지성이고, 앙상블(ensemble)의 원리입니다.

단, 조건이 있습니다. **참가자들이 서로 독립적으로 생각해야** 합니다. 전원이 한 사람의 답을 베끼면 평균을 내도 그 사람의 오차가 그대로 남습니다. 랜덤포레스트는 트리들이 서로 닮지 않도록 두 가지 장치를 씁니다.

1. **배깅(bagging)**: 각 트리에게 원본과 같은 크기의 데이터를 **복원추출**로 다시 뽑아 줍니다(부트스트랩). 트리마다 조금씩 다른 "경험"을 하게 되는 셈입니다.
2. **특징 무작위 선택**: 각 분기에서 전체 특징 중 일부만 후보로 줍니다. 이게 없으면 모든 트리가 가장 강한 특징으로 첫 질문을 시작해 서로 닮아 버립니다. 회의로 치면 "목소리 큰 사람이 먼저 말하기 금지" 규칙입니다.

이렇게 기른 트리 수백 그루가 투표(분류) 또는 평균(회귀)으로 최종 답을 냅니다.

## 3. 핵심 개념

### 3.1 왜 평균이 분산을 줄이나

트리 한 그루의 오차는 "체계적 편향 + 그때그때의 출렁임(분산)"으로 나뉩니다. level07에서 본 트리의 불안정성이 바로 분산입니다. 서로 독립에 가까운 트리 T그루를 평균 내면 출렁임은 대략 1/√T로 줄어듭니다 — 동전을 많이 던질수록 앞면 비율이 50%에 붙는 것과 같은 통계 원리입니다. 편향은 평균으로 줄지 않으므로, 포레스트는 "깊은 트리(저편향·고분산)를 많이 평균 내는" 전략을 씁니다. 개별 트리는 과적합해도 평균은 과적합이 크게 완화됩니다.

### 3.2 랜덤포레스트의 주요 손잡이

- `n_estimators`(트리 수): 많을수록 안정. 성능은 어느 지점부터 수렴하므로 100~500이 통상.
- `max_features`(분기당 특징 후보 수): 작을수록 트리들이 서로 달라짐(다양성↑, 개별 실력↓).
- `max_depth`, `min_samples_leaf`: 트리 때와 같은 제동 장치. 포레스트에선 느슨하게 둬도 되는 편.

### 3.3 특징 중요도와 OOB

포레스트는 트리들의 불순도 감소 기여를 평균해 특징 중요도(feature importance)를 냅니다. 한 그루의 중요도보다 훨씬 안정적이라 실무 보고에 자주 쓰입니다(단, level07에서 말한 편향 주의는 여전히 유효 — 더 공정한 순열 중요도는 level11에서). 덤으로, 각 트리가 복원추출에서 못 본 데이터(OOB, out-of-bag)로 자체 검증 점수를 낼 수 있어 별도 검증 세트 없이도 대략의 성능 추정이 됩니다.

### 3.4 잃는 것: 해석력, 무게

트리 한 그루는 규칙을 소리 내어 읽을 수 있었지만, 트리 300그루의 투표는 그렇게 못 읽습니다. 또 모델 크기와 예측 시간이 커집니다. **"읽을 수 있는 한 그루"와 "강하고 안정적인 숲" 사이의 거래** — 무엇을 고를지는 용도(보고용 vs 운영용)가 정합니다. 둘 다 갖고 싶을 때의 해석 기법이 level11의 주제입니다.

## 6. 자주 하는 실수

- **"포레스트는 과적합 안 한다"는 과신**: 완화될 뿐 면역이 아닙니다. 특히 데이터가 적거나 누설 특징이 있으면 똑같이 속습니다.
- **안정성을 재지 않고 한 번의 분할로 결론**: 한 번의 측정값 차이(예: AUC 0.821 vs 0.815)는 분할 운일 수 있습니다. 반복 측정의 평균±표준편차로 말하세요.
- **특징 중요도를 인과·절대 순위로 보고**: 상관 높은 특징끼리 중요도를 나눠 갖는 현상(희석)이 있습니다. 중요도가 낮다고 "영향 없음"이 아닙니다.
- **해석이 필요한 자리에 포레스트만 내밀기**: 경영진에게는 깊이 3 트리 한 장이 포레스트 성적표보다 설득력 있을 때가 많습니다. 용도에 맞는 모델을 고르세요.
