# Lecture 06 · Level 01 — 지도·비지도·강화학습

> 머신러닝의 3대 학습 방식을 과외·자율스터디·강아지 훈련에 비유해 정리하고, 각각을 장난감 예제로 직접 돌려 봅니다.
**난이도** ⭐ / **선행** level00 / **예상 시간** 30분

## 1. 왜 배우나 — 비즈니스 관점

외부 업체가 "저희는 비지도학습 기반 이상 탐지 솔루션입니다"라고 제안하거나, 데이터팀이 "이건 지도학습으로 풀어야 해서 레이블 작업이 먼저 필요합니다"라고 말할 때, 이 세 단어를 모르면 대화 자체가 안 됩니다. 더 실질적인 이유도 있습니다. **어떤 방식을 쓰느냐에 따라 준비해야 할 데이터와 비용이 완전히 달라지기 때문입니다.** 지도학습은 정답 레이블을 만드는 비용이 들고, 비지도학습은 결과 해석에 사람 품이 들고, 강화학습은 시행착오를 허용할 환경이 필요합니다. 문제를 어느 방식으로 풀지 정하는 순간, 프로젝트 예산의 큰 그림이 정해집니다.

## 2. 비유로 이해하기

세 가지 공부 방식을 떠올려 보세요.

**지도학습(Supervised Learning) = 과외 수업.** 선생님이 문제와 정답지를 함께 줍니다. "이 문제의 답은 3번이야." 학생은 문제→정답의 대응을 반복해서 보며 패턴을 익히고, 나중에 정답지 없는 새 문제를 풉니다. 정답지(레이블)를 만들어 줄 사람이 반드시 필요합니다.

**비지도학습(Unsupervised Learning) = 자율 스터디.** 정답지가 없습니다. 대신 자료 더미를 받아 "비슷한 것끼리 묶어 보고, 구조를 찾아보라"는 과제를 받습니다. 도서관에서 책 1만 권을 아무 분류표 없이 받아 비슷한 책끼리 서가를 나누는 사서의 일과 같습니다. 묶음 자체는 기계가 만들지만, 각 묶음에 "이건 추리소설 코너네"라고 이름 붙이는 건 사람 몫입니다.

**강화학습(Reinforcement Learning) = 강아지 훈련.** 정답지도, 자료 더미도 없습니다. 강아지가 "앉아"에 앉으면 간식(보상), 딴짓하면 무반응(보상 없음). 강아지는 정답을 배운 적이 없지만, **시도→보상**의 반복으로 점점 간식을 많이 받는 행동을 찾아냅니다. 핵심은 "해 보기 전엔 뭐가 좋은지 모른다"는 것, 그리고 "이미 좋아 보이는 행동만 반복할지(활용), 새 행동을 시험할지(탐험)" 사이의 저울질입니다.

## 3. 핵심 개념

### 3.1 세 방식 한눈에 비교

| | 지도학습 | 비지도학습 | 강화학습 |
|---|---|---|---|
| 주어지는 것 | 입력 + 정답 레이블 | 입력만 | 환경 + 보상 신호 |
| 배우는 것 | 입력→정답 대응 | 데이터의 숨은 구조 | 보상을 극대화하는 행동 |
| 비유 | 과외 수업 | 자율 스터디 | 강아지 훈련 |
| 준비 비용 | 레이블링 작업 | 해석 작업 | 시행착오 가능한 환경 |

### 3.2 업무 사례 지도

- **지도학습**: 이탈 예측(고객→이탈 여부), 매출 예측(광고비→매출), 이상거래 분류, 서류 자동 분류, 수요 예측. **실무 ML 프로젝트의 8할 이상이 여기에 속합니다.** 이 강의도 level03~09, 11이 전부 지도학습입니다.
- **비지도학습**: 고객 세분화(누가 어떤 그룹인지 정답이 없음), 신종 이상 패턴 탐지(과거에 없던 사기라 레이블이 없음), 문서 주제 묶기, 변수 압축(차원축소). level10에서 다룹니다.
- **강화학습**: 광고 예산 실시간 배분, 추천 순서 최적화, 게임·로봇 제어, 그리고 최근에는 대화형 AI를 사람 선호에 맞게 다듬는 단계에도 쓰입니다. 일반 기업 실무에서 직접 구현할 일은 드물지만, 개념은 알아 둬야 합니다.

### 3.3 구분 기준은 "무엇이 주어져 있나"

같은 비즈니스 문제도 데이터 상황에 따라 방식이 달라집니다. 사기 탐지를 예로 들면 — 과거 사기 사례에 레이블이 잘 붙어 있다면 지도학습, 레이블은 없지만 "정상 거래 무리에서 동떨어진 것"을 찾고 싶다면 비지도학습, 차단/통과 결정에 따른 손실·이익이 실시간 피드백으로 돌아온다면 강화학습적 설계도 가능합니다. **문제의 종류가 아니라 데이터와 피드백의 형태가 방식을 결정합니다.**

### 3.4 지도학습의 두 갈래

지도학습은 정답의 형태에 따라 둘로 나뉩니다. 정답이 숫자(매출액, 수요량)면 **회귀(regression)**, 정답이 범주(이탈/유지, 사기/정상)면 **분류(classification)**입니다. level03이 회귀, level05부터가 분류입니다.

## 4. 실습 — main.py

실행:

```bash
python3 main.py
```

세 패러다임을 각각 초미니 예제로 체험합니다.

- **[1] 지도학습 — 과외**: 이탈 고객 데이터에서 정답 레이블을 보여 주며 로지스틱 회귀를 훈련하고, 처음 보는 고객 3명의 이탈 여부를 예측시킵니다. "정답지를 주고 가르쳤더니 새 문제를 푼다"를 확인합니다.
- **[2] 비지도학습 — 자율 스터디**: 같은 종류의 고객 데이터에서 **정답 열을 일부러 빼고** k-means에게 "3그룹으로 묶어 보라"고만 시킵니다. 기계가 만든 그룹별 평균 프로필이 출력되면, 여러분이 사람 몫의 일 — "이 그룹은 우량 고객이군" 하고 이름 붙이기 — 을 해 보세요.
- **[3] 강화학습 — 강아지 훈련**: 당첨 확률이 다른 쿠폰 3종을 어떤 고객에게 보낼지 모르는 상태에서, 에이전트가 쿠폰을 보내 보고(시도) 반응(보상)만으로 점점 최적 쿠폰을 찾아가는 과정을 시뮬레이션합니다(멀티암드 밴딧, epsilon-greedy를 직접 구현). 초반 100회와 마지막 100회의 평균 보상이 어떻게 달라지는지 보세요.
- **[4]** 세 실험을 표로 요약합니다.

코드에서 볼 것: [1]은 `fit(X, y)`처럼 **정답 y를 넘기고**, [2]는 `fit(X)`처럼 **y 없이** 부릅니다. 함수 시그니처 하나에 두 패러다임의 차이가 그대로 드러납니다. [3]은 라이브러리 없이 20줄로 짠 순수 파이썬 루프입니다 — 탐험률 `epsilon` 값이 학습 속도를 좌우합니다.

## 6. 자주 하는 실수

- **"비지도학습은 정답이 필요 없으니 공짜"라는 오해**: 레이블 비용 대신 해석 비용이 듭니다. 기계가 만든 그룹이 업무적으로 의미 있는지 판정하는 것은 여전히 사람 일입니다.
- **강화학습을 아무 데나 제안하기**: 시행착오 한 번의 비용이 큰 업무(대출 승인, 의료)에서는 "일단 해 보고 배우기"가 허용되지 않습니다.
- **회귀와 분류를 섞어 말하기**: "이탈률을 회귀로 예측"과 "이탈 여부를 분류로 예측"은 다른 문제 설계입니다. 정답의 형태부터 확인하세요.
- **패러다임을 먼저 정하고 데이터를 끼워 맞추기**: 순서가 반대입니다. 가진 데이터와 피드백의 형태가 패러다임을 정합니다.
