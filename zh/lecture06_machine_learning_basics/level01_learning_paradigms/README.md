# Lecture 06 · Level 01 — 监督、无监督与强化学习

> 用一对一辅导、自习小组、训练小狗三个比喻梳理机器学习的三大学习方式，并各用一个玩具例子亲手跑一遍。

**难度** ⭐ / **先修** level00 / **预计时间** 30分钟

## 1. 为什么要学 — 从业务视角出发

当外部供应商提案说"我们是基于无监督学习的异常检测方案"，或者数据团队说"这个得用监督学习来解，得先做标注"时，不认识这三个词，对话根本进行不下去。还有更实际的理由: **用哪种方式，决定了要准备的数据和成本完全不同。** 监督学习要花钱制作标注答案，无监督学习要花人力解释结果，强化学习则需要一个允许试错的环境。决定用哪种方式解题的那一刻，项目预算的大框架就定下来了。

## 2. 用比喻来理解

想想三种学习方法。

**监督学习 (Supervised Learning) = 一对一辅导。** 老师把题目和答案一起给你。"这道题的答案是 3。"学生反复看题目→答案的对应关系，掌握规律，之后去解没有答案的新题。必须有人来制作答案 (标签)。

**无监督学习 (Unsupervised Learning) = 自习小组。** 没有答案。你拿到一堆材料，任务是"把相似的归到一起，找出结构"。这就像图书管理员收到 1 万本没有任何分类标签的书，把相似的书归到同一书架。分组本身由机器完成，但给每组贴上"这是推理小说区"这样的名字，是人的活儿。

**强化学习 (Reinforcement Learning) = 训练小狗。** 既没有答案，也没有材料堆。小狗听到"坐下"坐下了，就给零食 (奖励)；做别的，就没有反应 (无奖励)。小狗从没学过什么是正确答案，却通过**尝试→奖励**的反复，逐渐找到能拿到更多零食的行为。关键在于"不试不知道什么是好的"，以及"是重复看起来已经不错的行为 (利用)，还是尝试新行为 (探索)"之间的权衡。

## 3. 核心概念

### 3-1. 三种方式一览

| | 监督学习 | 无监督学习 | 强化学习 |
|---|---|---|---|
| 给定的东西 | 输入 + 正确标签 | 只有输入 | 环境 + 奖励信号 |
| 学到的东西 | 输入→答案的对应 | 数据的隐藏结构 | 使奖励最大化的行为 |
| 比喻 | 一对一辅导 | 自习小组 | 训练小狗 |
| 准备成本 | 标注工作 | 解释工作 | 可试错的环境 |

### 3-2. 业务案例地图

- **监督学习**: 流失预测 (客户→是否流失)、销售预测 (广告费→销售额)、异常交易分类、文档自动分类、需求预测。**实战 ML 项目的八成以上属于这里。** 本课的 level03~09、11 也全是监督学习。
- **无监督学习**: 客户细分 (谁属于哪组没有标准答案)、新型异常模式检测 (过去没出现过的欺诈，所以没有标签)、文档主题归类、变量压缩 (降维)。level10 会讲。
- **强化学习**: 广告预算实时分配、推荐排序优化、游戏与机器人控制，最近还用在把对话式 AI 调教得更符合人类偏好的环节。普通企业实务中亲手实现的机会不多，但概念必须知道。

### 3-3. 区分标准是"手里有什么"

同一个业务问题，随数据情况不同，方式也会不同。以欺诈检测为例 —— 如果过去的欺诈案例标注齐全，用监督学习；没有标签但想找"偏离正常交易群体的异类"，用无监督学习；如果拦截/放行的决定会带来实时的损失/收益反馈，也可以做强化学习式的设计。**决定方式的不是问题的种类，而是数据与反馈的形态。**

### 3-4. 监督学习的两个分支

监督学习按答案的形态分成两支。答案是数字 (销售额、需求量) 就是**回归 (regression)**，答案是类别 (流失/留存、欺诈/正常) 就是**分类 (classification)**。level03 讲回归，level05 起讲分类。

## 4. 实战 — main.py

运行:

```bash
python3 main.py
```

用超迷你例子逐一体验三大范式。

- **[1] 监督学习 — 辅导**: 在客户流失数据上，把正确标签亮给逻辑回归看着训练，然后让它预测 3 位没见过的新客户会不会流失。确认"给了答案教出来的学生能解新题"。
- **[2] 无监督学习 — 自习**: 在同类客户数据里**故意去掉答案列**，只吩咐 k-means"分成 3 组"。机器输出各组的平均画像后，请你来做人该做的那一半 —— 给每组起名字，比如"这组是优质客户"。
- **[3] 强化学习 — 训练小狗**: 3 种优惠券的使用率各不相同，但事先不知道；智能体一边发券 (尝试)，一边只凭反应 (奖励) 逐渐锁定最优券 —— 亲手实现多臂老虎机 (multi-armed bandit) 的 epsilon-greedy 策略。看看前 100 次和最后 100 次的平均奖励差多少。
- **[4]** 把三个实验总结成表。

代码里要看的点: [1] 像 `fit(X, y)` 那样**把答案 y 传进去**，[2] 像 `fit(X)` 那样**没有 y**。一个函数签名就把两种范式的差异摆在明面上。[3] 是不用任何库、20 行写完的纯 Python 循环 —— 探索率 `epsilon` 的取值左右着学习速度。

## 5. 动手试试

1. **(简单)** 把 [3] 的 `EPSILON` 改成 0.0 再运行。完全不探索会怎样? 观察"被开头几次的运气锁死在差劲优惠券上"的现象。(提示: 换着 seed 多跑几次)
2. **(普通)** 把 [2] 的簇数从 3 改成 2、5。分组画像怎么变了? "几组才合适"没有标准答案，这正是无监督学习的特点。
3. **(挑战)** 把 [1] 的训练数据从 2000 人减到 50 人。预测变得多不稳定? 亲自确认"监督学习的力量 = 带标签数据的数量"。

## 6. 常见错误

- **"无监督学习不需要答案所以免费"的误解**: 省了标注成本，就得付解释成本。判断机器分出来的组在业务上有没有意义，依然是人的工作。
- **逢场合就提强化学习**: 在一次试错代价巨大的业务 (贷款审批、医疗) 里，"先试试再学"是不被允许的。
- **回归和分类混着说**: "用回归预测流失率"和"用分类预测是否流失"是两种不同的问题设计。先确认答案的形态。
- **先定范式再硬塞数据**: 顺序反了。是你手里的数据和反馈的形态决定范式。
