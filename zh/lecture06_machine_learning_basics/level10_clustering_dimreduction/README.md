# Lecture 06 · Level 10 — 聚类与降维

> 没有标准答案，也能把客户按相似度分组 (k-means)，再把多个变量压成一张 2 维地图 (PCA) 用眼睛确认 —— 一次完整的无监督学习实战。

**难度** ⭐⭐⭐⭐ / **先修** level01, level04 / **预计时间** 50分钟

## 1. 为什么要学 — 从业务视角出发

"我们的客户由哪几类人构成?"这个问题没有正确标签。它不像流失预测那样有过去的答案 (退订记录) 可查，而是要**发现结构本身**的问题。客户细分 (segmentation) 是营销的老功课 —— 给全体客户群发同一条短信的公司，和"对价格敏感型发折扣券、对 VIP 发专属权益、对休眠风险群发唤醒提醒"的公司，业绩不会一样。

聚类 (clustering) 是让数据自己完成这种细分的工具，降维 (dimensionality reduction) 是把几十个变量的数据压到人眼能看的 2 维地图上的工具。两者经常成套使用: 先用聚类分出组，再在降维地图上着色，用眼睛验证"这些组是不是真的分开了"。

## 2. 用比喻来理解

**k-means 是美食广场的服务台摆放问题**。大厅里散坐着顾客 (数据点)，要决定 k 个移动服务台 (中心点) 摆在哪。好的摆法，是让每位顾客走到最近服务台的距离整体最短。k-means 的算法是朴素的循环: (1) 服务台随便先放 → (2) 每位顾客划给离自己最近的服务台 → (3) 每个服务台挪到自己顾客群的正中央 → 重复 (2)(3) 直到不再移动。这个简单的往返，就把顾客分成了 k 个自然的群。

**PCA 是挑影子的角度**。手里举着一件复杂的铁丝雕塑 (高维数据)，要往墙上投影 (2 维)。角度挑错了，雕塑被压成一条线；挑对了，影子里结构依然鲜活。PCA (主成分分析) 就是用数学找出**数据摊得最开的角度** —— 信息损失最少的投影方向。"第一主成分"是摊得最开的轴，"第二主成分"是其次的轴。

## 3. 核心概念

### 3-1. 用 k-means 之前要知道的事

- **k 由人定**: 几个组才是"正确答案"，数据不会告诉你。参考工具有肘部 (elbow) 法 —— 逐步加大 k、画出总距离 (inertia)，找下降突然变缓的拐点 —— 但最终决定是"这个组数能不能拆出不同的营销动作"这个业务判断。
- **必须标准化**: 基于距离的算法，单位大的变量 (年消费额，几百万韩元) 会碾压单位小的变量 (到店次数)。
- **初始位置的运气**: 起始摆放不同结果可能不同，所以多试几次取最优 (`n_init`)。
- **局限**: 它假设圆形的群，对狭长或环形的群很弱。它必须把每个点都塞进某个组，所以离群点也会挤进某个群里。

### 3-2. 聚类解读 — 机器做不了的那一半

k-means 给你的只是"0 号、1 号、2 号、3 号组"这些编号。**看着各组的平均画像，给它们起"精打细算新客型"、"VIP 常客型"这样的名字，是人的工作**；名字起出来了，行动才跟得上。level01 说的"无监督学习的解释成本"就是这一步。画像解读不通，就换 k 或换变量重来 —— 这种往返是正常流程。

### 3-3. 用 PCA 之前要知道的事

- **解释方差比例**: 每个主成分能装下原始信息 (方差) 的百分之几。PC1+PC2 有 70% 就表示"2 维影子里装下了原件的 70%" —— 这是决定对地图信几分的依据。
- **轴的解读**: 每个主成分是原始变量的加权和。看权重 (loading) 可以读出"PC1 大体是'消费规模'轴、PC2 是'折扣敏感度'轴"之类。
- **用途**: 除了可视化，变量太多时还可以当模型输入的压缩预处理 (顺带有去噪效果)。
- **同样必须标准化**: 以方差为准，单位大的变量会独占轴。

### 3-4. 无监督学习的评估为什么模糊

没有正确答案，就没有准确率这类指标。有轮廓系数 (silhouette，衡量"离自家群近、离别家群远"的程度) 这样的内部指标，但只是辅助；终极评估是**"按这套细分做的营销活动有没有出成果"**这种下游验证。

## 4. 实战 — main.py

运行:

```bash
python3 main.py
```

在合成客户数据上跑完细分全流程。

- **[1]** 用 `make_blobs` 生成"暗藏 4 种类型"的 800 名客户，并把各轴换算成消费额、到店数、折扣使用率、入网月数这些现实量纲。(不把类型告诉模型 —— 复现无监督处境)
- **[2]** 标准化后用 k=2~8 跑 k-means，输出肘部表 (inertia) 和轮廓系数，选定 k=4。
- **[3]** 输出 k=4 各簇的**画像表** (簇平均消费额、到店、折扣率、入网月数、人数)，并给每簇自动提议名字 ("VIP 常客型"等) —— 读一读起名规则的代码，想想换成你会怎么命名。
- **[4]** 用 PCA 把 4 个变量压到 2 维，输出解释方差比例和各轴的权重 (loading)。
- **[5]** 在 PCA 2D 地图上给各簇着色，散点图保存为 `outputs/segments_pca.png`。看看图里簇是否真的分开了。

## 5. 动手试试

1. **(简单)** 在 [2] 里把最终聚类从 k=4 换成 k=3、k=6。画像表怎么变? 从"营销团队管得过来的组数"这个角度看，几个组合适?
2. **(普通)** 调大 [1] 的 `cluster_std` (让群更散) 再实验。观察肘部变钝、轮廓系数变低 —— 这是"聚类结构弱的数据"的信号。现实数据大多更接近这一边。
3. **(挑战)** 去掉标准化 (删掉缩放器) 跑 k-means，比较画像。确认消费额 (单位大的变量) 独占聚类的现象，并解释 3-1 为什么说标准化是必需的。

## 6. 常见错误

- **省略标准化**: 聚类和 PCA 都会被单位大的变量支配。这是本关最大的陷阱。
- **把 k-means 的结果捧成"被发现的真相"**: k-means 对任何数据都**必定**切成 k 块，没有结构也照切。用轮廓系数、肘部、可视化交叉确认结构是否真的存在。
- **把簇编号原样写进报告**: "2 号簇流失率高"没有传达力。要起基于画像的名字。而且簇编号重跑一次就可能对调，只是任意编号。
- **把 PCA 的轴当成物理实体**: 主成分是数学方向，不是"客户的本性"。看着 loading 谨慎起名，解释方差低时连地图本身都别过度相信。
- **细分完就收工、不设计行动**: 只分组不行动的细分项目一抓一大把。level02 的说明书原则 (没有行动的分析是摆设) 对无监督学习同样适用。
