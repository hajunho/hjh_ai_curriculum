## 1. 为什么要学 — 从业务视角出发

营销预算会议上有人问"广告费多花 1000 万韩元，销售额能涨多少?"。"应该会涨吧"和"按历史数据，广告费每多 1 万韩元，销售额大约多 1.5 万韩元"之间，是天壤之别。线性回归 (linear regression) 就是对这种"涨多少?"用数字作答的工具 —— 最古老、用得最多、也最容易讲清楚。

还有一个理由: 线性回归是这门课的基础语法。逻辑回归 (level05) 是给线性回归套上概率变换，正则化 (level09) 是管住线性回归系数的技术，连神经网络也是把线性回归层层叠起来的结构。在这里把"系数"、"截距"、"误差最小化"吃透，后面全都轻松。

## 2. 用比喻来理解

想象一下**往散落的点之间放一把直尺**。1,800 多个按天记录的 (广告费, 销售额) 点撒在散点图上，你把一把透明直尺放上去，要画一条"代表所有点的直线"，会放在哪里? 有的点会落在尺子上方，有的落在下方。好的直线，是**各点与尺子之间的纵向间距 (误差) 整体最小**的那条。

最小二乘法 (least squares) 就是把这个"整体最小"精确定义出来: 取每个点到直线的纵向距离的平方和，选让这个平方和最小的直线。取平方有两个理由 —— 让上方/下方的误差不相互抵消，并给大误差更重的罚分。神奇的是，这条最优直线不需要试错，**一行公式直接算出来**。和 level00"把阈值全试一遍"的搜索不同，线性回归是数学替你把搜索做完了的情形。

## 3. 核心概念

### 3-1. 模型的形状: y = a·x + b

- **x**: 输入特征 (广告费)，**y**: 预测对象 (销售额)
- **a (斜率, 系数 coefficient)**: x 每增加 1，y 增加的量。**业务解读的核心**。"广告费每多 1 万韩元，销售额 +a 万韩元。"
- **b (截距 intercept)**: x=0 时的 y。可以读作"完全不投广告也有的基础销售额"，但那是数据范围之外的外推，解读要谨慎。

### 3-2. 最小二乘公式

斜率和截距可以用均值、方差、协方差闭式 (closed-form) 求出。

```
a = Cov(x, y) / Var(x)      (x 和 y 联动的程度 ÷ x 的分散程度)
b = mean(y) − a · mean(x)   (直线必定经过 (x̄, ȳ) 这一点)
```

今天的实战里，我们先用 numpy 手算这两行，再和 sklearn `LinearRegression` 给出的答案对比，确认小数点后都一致。目的就是亲眼看到: 库不是魔法，只是这条公式的包装。

### 3-3. 拟合得怎么样: R²

决定系数 R² (R-squared) 是"y 的波动中被模型解释的比例"。0 等于拿平均值瞎猜，1 是完美。实际业务数据里 R² 0.3~0.7 都很常见。R² 低不代表没用，高也不代表证明了因果。

### 3-4. 解读的陷阱: 相关 ≠ 因果

回归系数只是总结了"广告费高的日子销售额也高"这种**同行关系**。可能是广告拉动了销售，也可能是旺季里广告和销售一起涨。要断言"加广告费销售额就涨"，需要实验 (A/B 测试) 或进一步分析。写报告时用"观察到广告费每 1 万韩元与销售额 +1.5 万韩元的**关联**"这种措辞才稳妥。

### 3-5. 用上多个特征: 多元回归

可以写成 y = a₁x₁ + a₂x₂ + … + b，放进多个特征 (多元线性回归)。此时每个系数的解读变成"其他特征不变时"的效应，而且特征间单位不同，直接比较系数大小需要先标准化。今天先专注一元回归，多元回归在 level05 之后的分类模型里自然会用到。

## 6. 常见错误

- **不清洗就直接跑回归**: 缺失和负数污染混在里面，系数会被扭曲。今天代码里的 [1] 写那么长不是没道理的。
- **把截距按字面解读**: "广告费 0 韩元时销售额是 b 韩元" —— 数据里没有广告费为 0 的日子，这就是外推。
- **R² 低就立刻扔掉 / 高就立刻笃信**: 低的时候系数的方向和大小仍可能对决策有用，高的时候也可能是泄漏或巧合。
- **把系数当因果来汇报**: 分清"观察到关联"和"加了就涨"。回头再读一遍 3-4。
- **用全部训练数据谈性能**: 这次也是故意用全量数据算的 R²。这个成绩有什么问题，正是下一关的主题。
