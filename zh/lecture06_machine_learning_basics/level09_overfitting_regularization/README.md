# Lecture 06 · Level 09 — 过拟合、正则化与超参数

> 一边升高多项式次数，一边在图上目击 train/valid 误差分道扬镳的瞬间，再学会用正则化 (L1/L2) 这脚刹车驯服复杂模型。

**难度** ⭐⭐⭐⭐ / **先修** level04 / **预计时间** 50分钟

## 1. 为什么要学 — 从业务视角出发

过拟合 (overfitting) 在这门课里已经出场三次: level04 的乐观偏差、level07 的深度无限制树、level08 的不稳定性 —— 全是同一种病的不同症状。这一关正面治这个病。

它在实战中之所以重要，是因为它是**模型选择的语言**。"次数是升还是降"、"alpha 定多少"、"验证成绩怎么不涨了" —— 数据团队的日常对话大多发生在过拟合与欠拟合之间的某个位置。理解了这条轴，面对"把模型弄得更复杂会更好吗?"这样的问题，你就能回答: "训练成绩永远会更好，实战成绩只好到某个点为止。"寻找那个"某个点"的流程叫超参数调优，越过那个点之后往回拉的刹车就是正则化。

## 2. 用比喻来理解

用**定制西装**来想。客人 (数据) 的身上，混着本质的体型 (规律) 和当天的偶然 —— 厚内衣、刚吃完的午餐 (噪声)。

- **欠拟合 (underfitting)**: 均码塑料雨衣。对谁都大致能穿，对谁都不合身。模型太简单，连体型都装不下 —— 相当于想用一次直线画出曲线规律。
- **恰好拟合**: 跟着体型走、无视当天偶然的好剪裁。明天穿也合身。
- **过拟合**: 把当天那一刻的身体分毫不差地贴身缝死的衣服。连午餐吃出来的肚子形状都缝进去了，**今天完美，明天穿不上**。15 次曲线穿过全部训练点，正是这个状态。

**正则化 (regularization) 是给裁缝的指示**: "跟着身体走，但别对每一处起伏过敏。"数学上，它对模型系数变大这件事收罚金，宁可数据贴得稍差一点，也要让曲线保持平缓。调节罚金力度 (alpha) 就是超参数调优。

## 3. 核心概念

### 3-1. 参数 vs 超参数

- **参数**: 学习过程从数据里找出的值 (回归系数、树的分叉点)。机器负责。
- **超参数 (hyperparameter)**: 开始学习之前由人设定的旋钮 (多项式次数、树深度、正则化强度 alpha、森林的树数)。人负责 —— 但不能靠感觉，要用**验证集成绩**来挑 (level04 的模拟考正是这个用途)。

### 3-2. 验证曲线 — 分道扬镳的两条线

以复杂度 (例: 多项式次数) 为 x 轴、误差为 y 轴，把训练误差和验证误差画在一起，就是验证曲线 (validation curve)。典型形状:

- 训练误差: 复杂度越高**单调下降** (背题的余力越来越足)
- 验证误差: 先降 (规律装得更全) 到某个点后**重新上升** (开始连噪声一起背)

两条线开始分岔的位置就是过拟合的起点，验证误差的最低点就是该选的位置。今天实战产出的 PNG 画的正是这张图。

### 3-3. L2 与 L1 — 两种罚金

正则化在损失函数上加"系数大小罚金"。

- **L2 (Ridge)**: 罚金 = α × (系数平方之和)。让所有系数**均匀地收缩**，但不会变成 0。默认选项。
- **L1 (Lasso)**: 罚金 = α × (系数绝对值之和)。把不重要的系数**干脆压成 0**，自动做特征筛选。"几百个特征里想筛出真信号"时用它。

α (alpha) 为 0 就是没有正则化 (原始回归)，太大则所有系数被压扁、欠拟合。α 同样是超参数，用验证来挑。一条实战规则: **用正则化时，特征标准化事实上是必需的** —— 否则单位大的特征系数天然偏小、罚金交得少，不公平。

### 3-4. 过拟合的其他处方

正则化只是处方之一。增加数据 (最可靠)、减少特征、简化模型 (降次数、降深度)、集成 (level08)、早停 —— 共同哲学只有一句: **模型的自由度，只放到数据养得起的程度。**

## 6. 常见错误

- **训练误差降了就以为在变好**: 训练误差只要加复杂度就**必然**下降，是信息量为零的信号。只有验证误差会回答问题。
- **验证误差已经开始上升还硬堆复杂度**: 分岔之后的投入 (次数、参数、训练时间) 全部花在背噪声上。
- **不标准化就上正则化**: 单位大的特征会逃掉罚金。用 Pipeline 把标准化捆在一起。
- **用测试集挑 α**: level04 的偷看考卷在正则化里同样成立。α 要用验证 (或交叉验证) 挑。
- **把欠拟合误诊为过拟合**: 训练误差本身就大的状态下把正则化加得更狠，只会恶化。**训练/验证误差两个都看**再下诊断。
