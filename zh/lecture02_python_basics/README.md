# Lecture 02 — Python 编程基础

这是一门为"会用 Excel、但从没写过代码"的商务职场人准备的 Python 入门课。
我们从"编程到底是什么"这个问题出发，走完 12 个关卡之后，你就能自己写出
一个小小的业务自动化程序 — 读取数据文件，按规则判断和汇总，再自动生成结果报表。

## 这门课你将学到

- 程序运转的三条原理 — 顺序、分支、循环
- 变量、数据类型、条件语句、循环语句、集合、函数等 Python 的骨架语法
- 文件读写、异常处理、模块化等"在实际工作中不会散架的代码"的基本功
- 类与面向对象，推导式、生成器这些真正"Python 味"的表达方式
- 用类型提示和测试守住代码质量的习惯

## 先修课程

- lecture01 (计算机与开发环境) — 只要能在终端里运行 `python3 main.py` 就足够了。

## 快速通道 (时间紧就只看这些)

只想快速抓住核心的话，按顺序学下面这 5 关。

1. **level01 变量与数据类型** — 所有代码的原材料
2. **level02 条件语句** — 判断自动化的起点
3. **level03 循环语句** — 自动化收益体感最强的语法
4. **level05 函数** — 把代码整理成业务流程手册的方法
5. **level06 文件的读取与写入** — 连接真实数据的那道关口

之后有需要时再补上 level04 (数据结构) 和 level07 (异常处理)，
你就做好了进入 lecture03 (数据处理) 的准备。

## 这门课在实际工作中的应用场景

- 打开每天早上收到的交易明细 CSV，自动生成分项合计与异常值摘要报表时 (level03·04·06)
- 把"出差费用 15 万韩元以下自动批准"这类公司内部规定写成代码，省掉重复审批时 (level02)
- 各部门的税额、折扣计算逻辑五花八门，用一个函数统一起来避免出错时 (level05)
- 用异常处理防止一行脏数据把跑了整夜的批处理搞崩的事故时 (level07)
- 把员工、经理这类"相似但略有不同"的规则用类的继承干净地管理起来时 (level09)
- 给代码加上类型提示和测试，让别人 (或者未来的自己) 看了也敢放心用时 (level11)

所有实战都只使用标准库，不需要联网，
一行 `python3 main.py` 就能运行。
