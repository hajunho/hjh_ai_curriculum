# Lecture 02 · Level 03 — 循环语句: 把枯燥的活交出去

> for/while 循环就是"对列表里的每一笔都执行同样的流程"这条指示，也是自动化效果体感最强的语法。
**难度** ⭐ / **先修** level02 / **预计时间** 45分钟

## 1. 为什么要学 — 从业务视角出发

想象一下要把 100 位客户的消费额加起来、算出平均值、再挑出优质客户。
在 Excel 里你会用 SUM、AVERAGE 函数，可一旦每天都来新文件、格式还略有不同、
汇总口径又越来越复杂，手工活就会越堆越多。人处理 100 笔，中间会有电话打进来，
注意力被打断，然后在某个地方漏掉一笔。

循环语句 (loop) 就是"把这套流程应用到列表的每一项上"这一行指示。
100 笔还是 100 万笔，代码一样，质量也一样。学编程能拿到的实际收益里，
绝大部分 — 也就是重复工作自动化 — 正是来自这个语法。
这一关的实战，我们把 100 位客户的数据用"手算方式"和"循环方式"并排汇总一遍，
亲自确认差距。

## 2. 用比喻来理解

**寄邮件比喻。** 假设你要把新产品介绍寄给 100 位客户，这活交给实习生。
你不会把指示写成这样。

> "在信封上写王××的地址，把介绍放进去。在信封上写李××的地址，把介绍放进去。…" (100 行)

你会这么写。

> "**对名单上的每一位客户**: 在信封上写地址，放进介绍，贴上邮票。"

这一行就是 `for` 语句。"对名单上的每一位客户" = `for customer in customers:`，
下面缩进的那些步骤就是每次都会执行的循环体。

`while` 语句是稍微不同的指示。像"一直贴，直到邮票用完"这样 —
**不知道要几次，但只要条件还成立就重复**。
次数定好了就用 for，靠条件决定结束就用 while — 有这个感觉就够了。

## 3. 核心概念

### 3.1 for 语句 — 遍历一个列表

```python
purchases = [120000, 45000, 230000]
total = 0
for amount in purchases:      # 从列表里一笔笔取出来装进 amount
    total = total + amount    # 每次都会执行的循环体
print(total)                  # 395000
```

`amount` 是每转一圈就换成下一项的**循环变量**。
像装合计的 `total` 这种循环前从 0 开始、每圈往上堆的变量，
叫作**累加变量 (accumulator)**。这是汇总的基本模式，一定要练熟。

### 3.2 range — 按次数重复

```python
for i in range(5):        # 0, 1, 2, 3, 4  (不含 5!)
for i in range(1, 6):     # 1, 2, 3, 4, 5
for i in range(0, 10, 2): # 0, 2, 4, 6, 8  (每次跳 2)
```

`range(起始, 结束, 步长)` 里**结束值是不包含的**。"从 0 开始，到结束值前一个为止"
是 Python 整体的惯例。如果同时需要项和序号，就用 `for i, item in enumerate(items):`。

### 3.3 while 语句 — 只要条件为真就继续

```python
budget = 1000000
day = 0
while budget > 0:          # 只要预算还有剩就继续
    budget -= 87000        # 每天的支出
    day += 1
```

用 while 一定要在循环体里改变状态，**让条件总有一天会变成假**。
不改的话就会掉进死循环 (infinite loop)。(在终端里用 Ctrl+C 强制结束。)

### 3.4 break 与 continue — 控制流程

- `break` : 立刻结束循环跳出去。"找到了就不用再看了。"
- `continue` : 只跳过这一圈，进入下一项。"缺失值跳过，继续。"

```python
for row in rows:
    if row is None:
        continue          # 脏数据跳过
    if row == target:
        break             # 找到了，结束循环
```

实际工作中的数据里总会混着空值和脏值，所以用 continue 过滤的模式会经常用到。

### 3.5 嵌套循环

循环里再套一个循环，就成了"所有门店 x 所有月份"这样的网格遍历。
外层循环每转一圈，内层循环就整个跑完一遍，所以 100 x 100 的话循环体会执行 1 万次。
方便，但也正是数据一大就变慢的地方 (lecture03 会用向量化运算来改进)。

## 6. 常见错误

- **把累加变量的初始化写进循环里** — `total = 0` 跑到 for 里面去，
  每圈都会被重置成 0，最后只剩最后一笔。初始化一定放在循环**之前**。
- **搞错 range 的结束值** — `range(1, 100)` 到 99 为止。要转 100 个人得用
  `range(1, 101)` 或 `range(100)`。
- **死循环** — while 的循环体里不更新条件变量，它就会永远转下去。
  用 while 之前先自问一句"这个条件什么时候会变成假?"。
- **修改正在遍历的列表** — 一边遍历一边从那个列表里删项，就会漏掉一些项。
  请改用把结果收集到新列表的做法 (level04、level10)。
- **被缩进骗了归属** — 本该在循环里的 print 跑到了外面，就只会打印最后一个值一次。
  用缩进确认一句"这一行是每圈都执行吗?"。
