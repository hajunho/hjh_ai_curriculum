# Lecture 02 · Level 01 — 变量与数据类型

> 变量是给数据贴上名签的盒子，数据类型则是盒子里装的那份数据的种类 (整数、浮点数、字符串、布尔值)。
**难度** ⭐ / **先修** level00 / **预计时间** 40分钟

## 1. 为什么要学 — 从业务视角出发

在 Excel 里写 `=B2*C2` 这个公式时，B2 和 C2 是装着"单价"和"数量"的格子的地址。
可是过一段时间，你就忘了 B2 到底是什么。在 Python 里，我们可以不用地址，
而给格子起 `unit_price`、`quantity` 这样**有含义的名字**。这就是变量。

变量和数据类型是所有代码的原材料。算营业额、整理客户名单，一直到训练 AI 模型，
全部都是"把值装进变量 → 加工 → 把结果装进另一个变量"的连续过程。
特别是把数据类型理解清楚，就能预防实际工作中最常见的事故 —
把数字 "1000" 和文字 "1000" 搞混，导致合计对不上。

## 2. 用比喻来理解

**贴名签的盒子比喻。** 想象办公室仓库里放着好几个盒子。
每个盒子上都贴着名签: "三月营业额"、"客户名单"、"增值税率"。
需要的时候按名签找到盒子，取出里面的东西来用，也可以换成新的东西放回去。

- `march_sales = 12000000` → 往贴着"三月营业额"名签的盒子里放进 1200 万。
- `print(march_sales)` → 打开那个盒子看看里面装的是什么。
- `march_sales = 13000000` → 把里面的东西换成新值。(所以叫"可以变的量" — 变量)

**数据类型就是盒子里装的东西的种类**。盒子里装的是现金、是文件，
还是一枚图章 ("批准"/"驳回")，能做的事情各不相同。现金和现金可以相加，
但让你把现金和文件相加就说不通了。Python 也一样，你让它算"数字 + 文字"，
它就会报错。

## 3. 核心概念

### 3.1 创建变量 — 赋值

```python
unit_price = 4500      # "把 4500 放进 unit_price 这个盒子"
```

`=` 不是数学里的"等于"，而是**"把右边的值放进左边这个名字的盒子里"**这条命令。
正因如此，`count = count + 1` (在当前值上加 1 再放回去) 才成立。

命名规则: 用英文小写字母和下划线，让含义一眼可见。比起 `a`、`x1`，
`total_revenue`、`vat_rate` 更好。代码被读的时间远比被写的时间长。

### 3.2 四种基本数据类型

| 数据类型 | 名称 | 例子 | 实际用途 |
|---|---|---|---|
| `int` | 整数 (integer) | `120`, `-3` | 数量、人数、笔数 |
| `float` | 浮点数 (floating point) | `0.1`, `4500.0` | 比率、单价、平均值 |
| `str` | 字符串 (string) | `"美式咖啡"` | 名称、地址、备注 |
| `bool` | 布尔值 (boolean) | `True`, `False` | 是否批准、是否会员 |

用 `type(值)` 就能确认数据类型。拿不准的时候随时问它一句。

### 3.3 数据类型转换

从 CSV 文件或用户输入里读到的值全都是字符串。要计算就必须先转换。

```python
int("1000")      # 字符串 -> 整数 1000
float("3.3")     # 字符串 -> 浮点数 3.3
str(4500)        # 整数 -> 字符串 "4500"
```

`"1000" + "500"` 的结果是 `"1000500"` (字符串拼接)。这是实际工作中的事故第一名，
所以请随时意识到"这个值现在是数字还是文字"。

### 3.4 f-string — 生成报告里的句子

在字符串前面加一个 `f`，就能把变量嵌进花括号里。

```python
name = "美式咖啡"
total = 9000
print(f"{name}的营业额是 {total} 韩元")      # 美式咖啡的营业额是 9000 韩元
print(f"{total:,}韩元")                      # 9,000韩元  (千位分隔逗号)
print(f"{0.0525:.1%}")                       # 5.2%       (百分比，1 位小数)
```

`{变量:格式}` 这种格式指定，在做数字报表时你会一直用到。
先记住 `,` (千位逗号)、`.2f` (小数两位)、`.1%` (百分比) 这三个就够了。

### 3.5 算术运算符一览

计算用的符号和 Excel 几乎一样，只有两个需要新学。

| 运算符 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `+` `-` `*` `/` | 四则运算 | `7 / 2` | `3.5` |
| `//` | 商 (向下取整的除法) | `7 // 2` | `3` |
| `%` | 余数 | `7 % 2` | `1` |
| `**` | 幂 | `2 ** 10` | `1024` |

`//` 和 `%` 在"用 5 座的车运 17 个人需要几辆、剩几个人"这类分配问题里经常用到。
另外也请记住: `/` 的结果永远是 float。

### 3.6 浮点数 (float) 的微小误差

计算机用二进制存小数，所以 `0.1 + 0.2` 并不正好是 0.3，而是
`0.30000000000000004`。这不是故障，而是存储方式的局限。
比较金额时可以用四舍五入 (`round`)，如果是精确的财务核算，
用整数 (以韩元为单位) 计算更安全。

## 6. 常见错误

- **混淆 `=` 和 `==`** — `=` 是赋值 (放进去)，`==` 是比较 (是否相等)。
  level02 讲到比较时再确认一遍。
- **直接拿字符串数字做计算** — `"100" * 2` 不是 200，而是 `"100100"`。
  外部进来的值，先做 `int()`/`float()` 转换。
- **变量名拼错** — 把 `total_revenue` 写成 `total_revenu`，就会看到
  `NameError: name 'total_revenu' is not defined`。报错信息里会原样打出那个拼错的名字，
  仔细读就能马上改掉。
- **没有含义的名字** — `a`、`b`、`data2` 对一周后的自己来说就是密码。
  哪怕长一点，也要用能看出含义的名字。
