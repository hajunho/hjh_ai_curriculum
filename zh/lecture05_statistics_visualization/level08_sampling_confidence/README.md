# Lecture 05 · Level 08 — 样本与置信区间

> 全量普查是不可能的。作为替代，我们为"撒网的方法"担保可信度。
**难度** ⭐⭐⭐ / **先修** level07 / **预计时间** 55分钟

## 1. 为什么要学 — 业务视角

不可能去问全部 50 万名客户满不满意。只能问 500 人，再推测全体。
这时必然跟来一个问题："500 人的结果能信到什么程度？"
民调新闻里的"支持率 42%，误差范围 ±3.1 个百分点 (95% 置信水平)"，
正是这个答案的标准格式。

会读、会做置信区间 (confidence interval)，实务水平就不一样了。
不写"新品满意度 78%"，而写"78% (95% CI: 74~82%)"，
听的人就知道这个数字可以信到哪一步、能不能拿来做决策。反过来，
你也能解释清楚：只有 20 人样本的调查得出"满意度 85%"，
为什么等于什么都没说。这一关是推断统计的第一件实战武器。

## 2. 用类比来理解

尝汤的咸淡不需要把整锅喝光。**一勺就够——前提是搅匀之后。**
抽样调查的关键不在勺子的大小，而在"搅没搅匀" (随机抽取)。
没搅的锅只舀上层 (有偏样本)，勺子再大也尝不出咸味。

置信区间 95% 的含义很微妙，比喻在这里格外重要。想想**套圈游戏**。
木桩 (真实值) 固定在一个位置，我们往外扔圈 (区间)。
"95% 置信水平"的意思是：**这种扔法 100 次里有 95 次套中木桩**。
盯着已经扔出去的某一个圈说"这个圈里有木桩的概率是 95%"，
是微妙地跑偏的说法——已经落地的圈要么套中要么没套中，
95% 是**扔法**的成绩单，不是圈的。实战里我们扔 100 次圈，
实际数一数套中几次。

## 3. 核心概念

### 3.1 总体与样本

- **总体 (population)**：想了解的全体 (全部客户、全部交易)
- **样本 (sample)**：实际观测到的一部分
- **参数 (parameter)**：总体的真实值 (真实平均 μ) — 永远未知
- **统计量 (statistic)**：从样本算出的值 (样本平均 x̄) — 手里有的

所谓推断，就是用 x̄ 去包抄 μ 的过程。

### 3.2 抽样误差与置信区间公式

level07 里看到，样本平均的抖动幅度是标准误 σ/√n。
正态分布 95% 落在 ±1.96σ 里，所以 95% 置信区间是：

x̄ ± 1.96 × (s / √n)

这里 s 是样本标准差 (不知道 σ 就用样本代替；n 小的时候用 t 分布的值
替换 1.96——scipy 会代劳)。

读法：区间窄说明信息多，区间宽说明"还不太清楚"。区间宽度与 √n
成反比，宽度想减半，样本得要 4 倍。

### 3.3 "95%" 的准确含义

按 3.2 的流程造区间，**无限重复抽样时，这些区间中的 95% 会包含
真实的 μ**。对单独某一个区间只有"包含了或没包含"，我们不知道是哪种。
这份微妙在实务上很重要：汇报说"有 95% 的概率销售额平均在这个范围里"
听着不算错，但准确的说法是"这个方法 100 次里对 95 次，
希望这一次落在那 95 次里"。(如果想给区间本身赋予概率——
那是 level11 贝叶斯的地盘。)

### 3.4 比误差范围更可怕的东西 — 偏倚

误差范围是**以随机抽取为前提**的计算。白天只打固定电话调查，
就只捞到在家的人；只有满意的客户留评价，评分就虚高；
只调查活下来的公司，成功秘诀就被歪曲 (幸存者偏差)。
偏倚 (bias) 不会因为样本增多而消失——没搅的锅，用大勺舀出来还是咸的。
先别问样本多大，先问"是怎么抽的"。

1. **(简单)** 把置信水平换成 90% (1.645)、99% (2.576) 重跑 [2]。
   覆盖率和区间宽度怎么变？"更有底气的汇报"代价是什么？
2. **(中等)** 把 [2] 的重复次数从 100 次加到 2,000 次，

3. **(挑战)** 做一个比例的置信区间：某问卷 500 人中 210 人回答"满意"。
   用公式 p̂ ± 1.96×√(p̂(1-p̂)/n) 计算满意比例的 95% 置信区间，
   再按"误差范围 ±几个百分点"的格式写一句汇报。
   (提示：从 p̂ = 0.42 开始。)

## 6. 常见错误

- **只看样本量判断可信度**：n=10,000 的有偏样本，比 n=100 的随机样本
  还糟。抽取方式先于规模。
- **只报点估计、不带置信区间**：只报"流失率 12.3%"，没人知道是
  12.3±0.2 还是 12.3±8。要拿来行动的数字，请配上区间。
- **两个区间一重叠就断定"没差异"**：区间轻微重叠时，两个值的差异
  仍可能显著。差异的检验下一关 (t 检验) 正式讲。
- **把误差范围当"最大误差"**：±3.1 个百分点只是 95% 置信水平下的宽度，
  20 次里有 1 次会跑到外面。而且偏倚根本是另一个问题。
