# Lecture 05 · Level 09 — 假设检验与 p 值

> 假设检验是一场审判。数据是证据，p 值是"无罪的话却冒出这种证据的可能性"。
**难度** ⭐⭐⭐⭐ / **先修** level08 / **预计时间** 60分钟

## 1. 为什么要学 — 业务视角

"改造后的门店销售额高了 8%"——听完汇报，高管问："那不会是碰巧吧？"
用程序而不是感觉回答这个问题的工具，就是假设检验 (hypothesis testing)。
新药审批、质量合格判定、论文评审、A/B 测试——世上无数正式裁决
都跑在这套程序上。

同时，p 值大概是世界上被误解最多的统计概念。"p < 0.05，
所以我们的假设有 95% 的概率是对的"——这种解读流传甚广，而且是错的。
这一关的目标有两个：**亲手 (用模拟) 造一个 p 值**，把它的定义刻进
身体里；再确认它和 scipy 一行检验的结果一致，从此放心使用工具。

## 2. 用类比来理解

刑事审判有无罪推定原则。被告在**罪名被证实之前视为无罪**。
检察官要做的，是拿出"要说无罪就太蹊跷了"的证据。

假设检验正是这个结构。

| 审判 | 假设检验 |
|---|---|
| 被告无罪 (默认前提) | 原假设 H₀: "没有差异，纯属偶然" |
| 检察官的主张 | 备择假设 H₁: "存在真实差异" |
| 证据 | 观测到的数据 (两家门店的销售额差异) |
| "无罪的话哪来这种证据" | p 值: H₀ 为真时，这么大的差异纯属偶然出现的概率 |
| 排除合理怀疑 | p < 0.05 → 拒绝 H₀ (显著性水平 5%) |
| 无罪判决 ≠ 证明清白 | 拒绝失败 ≠ "证明了没有差异" |

最后一行很重要。证据不足的无罪不等于清白的证明；
p = 0.3 也不是"没有差异"的证明，只是"用偶然也解释得通"而已。

## 3. 核心概念

### 3.1 检验的四步程序

1. **设定原假设 H₀**："两家门店的真实平均销售额相同。"
2. **计算检验统计量**：把观测差异除以标准误 (t 统计量)。
3. **计算 p 值**：在 H₀ 为真的世界里，出现这么大或更大差异的偶然概率。
4. **判定**：p 小于事先定好的显著性水平 (通常 0.05) 就拒绝 H₀。

显著性水平必须**开庭前**定好。看完结果再挪标准，
等于先射箭再画靶心。

### 3.2 p 值"不是什么"清单

- ❌ H₀ 为真的概率 (那是对假设而非数据的概率 — 贝叶斯的地盘)
- ❌ 备择假设成立的概率
- ❌ 效应的大小 (样本够大时，微不足道的差异 p 也会很小)
- ❌ 可复现的概率
- ⭕ **"在没有差异的世界里，偶然观测到这么大 (或更大) 差异的概率"**

p = 0.03 的正确汇报："如果两家门店真的一样，出现这么大差异的偶然概率
是 3%。很难认为是巧合，因此判断存在差异。"

### 3.3 两种错误 — 误报与漏报

| | 实际无差异 | 实际有差异 |
|---|---|---|
| 检验: 有差异 | **第一类错误(α)** 误报 | 正确检出 (检验力) |
| 检验: 保留判断 | 正确的无罪 | **第二类错误(β)** 漏报 |

显著性水平 0.05 是一份契约："就算没有差异，100 次里也认了 5 次误报"。
误报致命的领域 (新药) 调低 α；漏报致命的领域 (癌症筛查) 提高检验力。
天下没有免费的午餐。

### 3.4 置换检验 — 用模拟造出来的 p 值

没有 t 检验公式也能造 p 值。既然 H₀ 说"两家门店一样"，
那么贴在销售数据上的门店标签就应该毫无意义。于是**把标签随意打乱**
(置换, permutation) 再计算差异，重复一万次，就得到"仅凭偶然产生的差异"
的分布。数一数实际观测差异落在这个分布尾巴的什么位置，那就是 p 值。
不靠公式、按定义原样造出的 p 值——这是本次实战的核心。

- [5] **对照实验**：用真的没有差异的两个样本 (把同一家门店对半分)

## 5. 亲手试试

1. **(简单)** 把 [1] 的样本量减半。同样大小的差异，p 怎么变？
   验证"样本小的时候，真实差异也难以证明"。
2. **(中等)** 换成两家差异很小的门店 (相邻档位) 做检验。
   如果 p 超过 0.05，汇报的句子不能写"没有差异"，那应该怎么写？
   (提示：第 2 节类比的最后一行。)
3. **(挑战)** 扩展 [5]：把"无差异检验"重复 1,000 次，数 p < 0.05
   出现的比例。是不是在 5% 附近？这就是第一类错误率的真身。
   (提示：循环里每次重新对半分样本。)

## 6. 常见错误

- **把 p 汇报成"假设成立的概率"**：开会前把 3.2 的清单再读一遍。
  说错了，会在懂统计的人面前信誉扫地。
- **把 p = 0.049 和 0.051 当作天壤之别**：0.05 不是悬崖，是惯例线。
  请把效应大小、成本、可复现性一并汇报。
- **显著 = 重要**：样本上百万条时，0.1% 的销售额差异也会 p < 0.001。
  "统计显著"和"business 上有意义"是两个问题。
- **反复检验、只报好看的**：检验 20 个指标，即使毫无差异，
  平均也有 1 个会 p < 0.05 (多重比较问题)。隐瞒检验了几个的汇报
  就是歪曲。它和下一关的 peeking 问题是亲兄弟。
- **把拒绝失败汇报成"证明了相同"**：证据不足和证明清白是两回事。
