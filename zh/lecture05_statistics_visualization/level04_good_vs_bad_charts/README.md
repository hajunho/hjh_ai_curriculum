# Lecture 05 · Level 04 — 好图表 vs 坏图表

> 图表不会说谎，但画图表的人可以。
**难度** ⭐⭐ / **先修** level03 / **预计时间** 45分钟

## 1. 为什么要学 — 业务视角

篡改数字会被审计查出来，但"包装"图表却不触犯任何规定。所以会议室里
飘荡着截断坐标轴的柱状图、倾斜的 3D 饼图、被夸大的象形符号。
问题会从两个方向找上门：被别人的歪曲图表骗了、做出错误决策；
以及自己无意间做了歪曲图表、失去信任。

这一关的目标有两个。第一，亲手制作那些有代表性的歪曲手法，
练出**一眼看穿的眼力**；第二，把同一份数据的诚实版本画在旁边，
练出**诚实作图的手上功夫**。学骗术不是为了骗人，是为了不被骗。

## 2. 用类比来理解

歪曲图表就像**证件照的精修**。照片里的人真实存在，也不是合成的，
但灯光、角度、修图可以造出与本人不同的印象。截断坐标轴相当于
只把脸放大来拍，3D 效果相当于选一个显脸小的角度。问"照片是不是假的"？
不是假的。但只看这张照片来判断这个人，就会看走眼。

好图表的标准很简单：**图表给人的第一印象，与逐字细读数据后的结论
是否一致？** 被设计得让第一印象与细读结论不一致的图表，就是坏图表。

## 3. 核心概念

### 3.1 罪状 1 — 截断坐标轴 (truncated axis)

柱状图的 y 轴不从 0 而从某个值 (比如 90) 开始，92 和 95 的差距
(实际 3%) 在视觉上就像差了两三倍。因为这破坏了"柱子的**长度**
与数值成正比"的约定。

- 规则：**柱状图的 y 轴从 0 开始**。柱状图是靠长度说话的图。
- 例外：折线图看的是变化的"形状"，有时可以截轴。但必须明确标出
  截断的痕迹 (轴标签、波浪线)。

### 3.2 罪状 2 — 3D 与饼图的合谋

饼图本来就难以比较角度，再用 3D 一倾斜，**靠前的那块会显得比实际大**。
因为透视关系，同样是 25%，放在前面就膨胀，放在后面就缩水。
把自家市场份额放在前排的 3D 饼图，是经典的包装手法。
当切块超过 4 块或比例彼此接近时，正确答案是排好序的柱状图，
而不是饼图。

### 3.3 罪状 3 — 象形符号的面积歪曲

想表达"销售额翻倍"，把硬币图案的长宽各放大 2 倍，面积就变成了 4 倍。
人眼是按面积读图的，2 倍就被夸大成了 4 倍。用图标大小表示数值时，
要么用个数表示 (两枚硬币)，要么只放大一条边。

### 3.4 墨水比例 — 数据墨水 (data-ink)

好图表有一条实用标准："提高图中用于表达数据的墨水占比"。
滥用网格线、背景渐变、阴影、边框、3D 效果，都是花在装饰而非数据上的
墨水。装饰擦得越干净，数据越显眼。实务技巧：图画完后逐个元素自问
"删掉它信息会消失吗？"，答案是"不会"就删。

### 3.5 检查清单 — 收到别人的图表时

1. 柱状图的 y 轴从 0 开始吗？
2. 轴刻度间隔均匀吗？(中间没有跳档吗)
3. 有 3D 效果吗？有的话，为什么要用？
4. 各比较对象的时间段、单位、口径一致吗？
5. 写了 "n = 多少人/多少件" 吗？说不定是 3 条样本的平均。

### 3.6 歪曲大多不是恶意

现场遇到的歪曲图表，多数不是有意欺骗，而是工具的默认设置造成的。
电子表格会"为了好看"自动截断 y 轴，图表向导会推荐 3D。
所以连作者本人都不知道自己的图在夸大。用代码画图时，轴范围、颜色、
形态全都是显式声明的，无意识的歪曲就没那么容易钻进来。
这是分析师用代码画图的又一个理由。

- [3] `outputs/pie_vs_bar.png`：左边是 5 家门店份额彼此接近的饼图
  (角度没法比较)；右边是排好序的水平柱 (立刻能比较)。
- [4] `outputs/inflated_line.png`：左边收窄 y 轴范围，把微小起伏

三张图的核心都在于：左边 (歪曲) 和右边 (诚实) 出自**完全相同的数字**。
打开图确认第一印象后，再回头跟 [1] 的真实数值比较。

## 6. 常见错误

- **连折线图也一律从 0 开始**：汇率、股价这类绝对零点无意义的数据，
  从 0 画反而看不出变化。记住"柱从 0 起，线看上下文 + 标明截断"。
- **指出歪曲时攻击人**：比起"这图是造假吧"，"把 y 轴改成从 0 开始
  会是什么样？"在会议室里管用得多。
- **把强调本身当罪过**：颜色强调、结论式标题、注释不是歪曲，
  是好的编辑。歪曲是让数据说它没说过的话；编辑是让数据说过的话
  被听清楚。
- **全面封杀饼图**：切块只有 2~3 块、比例差距分明时，饼图也可以用。
  有问题的是切块太多的饼图和 3D 饼图。
