# Lecture 05 · Level 01 — 平均数、中位数与方差

> 代表值是数据的发言人。派哪位发言人上台，故事就会不一样。
**难度** ⭐ / **先修** level00 / **预计时间** 40分钟

## 1. 为什么要学 — 业务视角

"我们团队的平均年薪是 6,800 万韩元。" 听了这句话入职，结果发现团队 9 个人
拿的是 4,000 万档，只有主管一人拿 3 亿——你会怎么想？这不算撒谎，
平均数算得一点不差。但因为挑了**错误的代表值**，听的人脑中画出的
是一幅完全不同的图。

在实务中，代表值的选择每天都在发生。汇报人均购买额时、公告配送天数时、
比较门店业绩时。用平均数 (mean) 还是中位数 (median)，要不要把离散程度——
方差 (variance) 和标准差 (standard deviation)——一并汇报，都会改变决策。
学完这一关，你就能自己回答"什么时候用哪个代表值"。

## 2. 用类比来理解

代表值是**替大家进会议室的发言人**。几千条数据不可能都挤进会议室，
只能推举一位进去。

- **平均数**是"把每个人的意见都掺一点"的发言人。所有人的立场都有体现，
  但会被嗓门最大的那个极端值狠狠带偏。
- **中位数**是"排好队后恰好站在正中间"的发言人。两端的极端人物
  喊得再响，他的位置也几乎不动。
- **标准差**不是发言人，而是**批注**。它负责补一句："不过大家的意见分歧
  有这么大。" 没有这条批注，人们就会误以为发言人的话代表了全体意见。

年薪、房价、销售额这类朝大值方向拖着长尾的数据里，平均数这位发言人
会被几位富人的声音牵着走。所以统计部门公布家庭收入时，总会同时给出
中位数。

## 3. 核心概念

### 3.1 平均数 — 重心

平均数是把所有值加起来除以个数。公式是
x̄ = (x₁ + x₂ + … + xₙ) / n。从物理上看，它是把数据放上跷跷板时
恰好保持平衡的**重心**。正因为是重心，摆在极远处的一个值
(极端值, outlier) 会像杠杆一样把平均数拽向自己。

### 3.2 中位数 — 排队的正中间

把值从小到大排队，正中间的那个就是中位数 (偶数个则取中间两个的平均)。
极端值的**大小**不影响中位数——无论 3 亿还是 30 亿，它都只是"最大的
那一个"。这种性质叫**稳健 (robust)**。

### 3.3 方差与标准差 — 离散的幅度

把每个值离平均数多远 (偏差) 平方后再取平均，就是方差。因为平方过，
单位变得很怪 (比如 韩元²)，所以再开平方根还原成原始单位，
就是标准差。

| 概念 | 计算 | 单位 | 直觉 |
|---|---|---|---|
| 方差 | 偏差平方的平均 | 韩元² | 数学上便于处理 |
| 标准差 | 方差的平方根 | 韩元 | "通常偏离平均数这么多" |

标准差为 0 意味着所有值都相同；标准差跟平均数差不多大时，
是"平均数几乎当不了代表值"的警告。

### 3.4 什么时候用哪个

- 值左右对称地聚在一起 → 平均数 (配上标准差)
- 尾巴长 / 有极端值 (年薪·房价·销售额) → 中位数优先，平均数仅供参考
- 报告里最好**两个都写**；如果两者差得多，再加一行说明原因
  (极端值、偏斜)，这是好习惯。

### 3.5 加餐 — 变异系数

门店 A 平均销售额 1,000 万韩元、标准差 100 万韩元；门店 B 平均 100 万韩元、
标准差 50 万韩元。哪家店更"起伏"？绝对值上 A (100 万) 更大，
但相对于平均数，B (50%) 要不稳定得多。像这样用标准差除以平均数得到的值
叫变异系数 (coefficient of variation)，用于比较规模不同的对象的波动性。
实战 [3] 会按门店一起算出来。

## 6. 常见错误

- **平均数和中位数不一样却不问原因**：两者的差异不是错误，而是
  "存在偏斜"的信息。这个差异本身就值得写进报告。
- **只报平均数、不报标准差**：就算"平均 5 天送达"，若标准差是 3 天，
  意味着等 8 天以上的客户很常见。客诉不是从平均数里来的，
  是从尾巴里来的。
- **忘记方差的单位**：说方差是 2,500 万，单位是"韩元²"。报告里应写
  开根号后的标准差 (5,000 韩元) 才不会引起误解。
- **清洗前就算统计量**：把缺失填成 0 会歪曲平均数。None 和 0 不一样。
  计算之前先定好缺失值和异常值的处理方针。
