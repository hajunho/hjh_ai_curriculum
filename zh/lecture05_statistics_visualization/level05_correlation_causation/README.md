# Lecture 05 · Level 05 — 相关关系与因果关系

> "一起波动"和"因为它才波动"之间，隔着整整一个商业决策的距离。
**难度** ⭐⭐⭐ / **先修** level03 / **预计时间** 50分钟

## 1. 为什么要学 — 业务视角

"加大广告投入的那几个月销售额都高，咱们把广告预算翻倍吧。"
这是会议上常听到的逻辑。可如果只是因为旺季，广告加了、客人也多了呢？
那广告预算翻倍，淡季的销售额也纹丝不动，那笔预算就打了水漂。

相关关系 (correlation) 是"两个值倾向于一起波动"；因果关系 (causation)
是"改变一方，另一方随之改变"。数据分析找到的大多止步于相关。
可预算分配、招聘、定价这些**行动**都以因果为前提。把相关误当因果的
那一刻，数据驱动的决策就变成了用数据包装的赌博。这个区分，
恐怕是整门课里实务价值最高的一章。

## 2. 用类比来理解

看夏天海滨城市的统计，**冰淇淋销量和溺水事故**竟然惊人地同步波动。
是冰淇淋把人拖下水的吗？当然不是。是**炎热天气**这个第三变量，
既推高了冰淇淋销量，也增加了下水玩的人。像这样同时影响两个变量、
制造出假相关的变量，叫混杂变量 (confounder)。

混杂变量是**藏起身体的章鱼**。我们眼里只有露出水面的两条触手
(冰淇淋、溺水)。两条触手一起动，看着像互相连着，实际上是水下的身体
(天气) 在同时驱动它们。抓住一条触手摇 (禁售冰淇淋)，另一条也不会动——
因为身体还在原处。

## 3. 核心概念

### 3.1 怎么读相关系数

皮尔逊相关系数 (Pearson correlation coefficient) r 是 -1 ~ +1 之间的数字，
衡量**直线式**同步的程度。

| r | 解读 |
|---|---|
| +1.0 | 完美的正比例同步 |
| +0.7 ~ +0.9 | 强正相关 |
| +0.3 ~ +0.5 | 弱~中等正相关 |
| 0 附近 | 没有直线关系 |
| 负数 | 反向波动 (例: 价格↑ 销量↓) |

两个注意点。第一，r 只能捕捉直线关系。U 形关系 (温度适中时销售额最高)
可能算出 r ≈ 0。所以看相关系数之前一定先画散点图。第二，r 的大小不是
"斜率"，而是"点贴直线贴得多紧"。

### 3.2 相关出现的四条路径

观察到 X 与 Y 相关时，可能的解释至少有四种。

1. **X → Y**：X 真的是 Y 的原因 (广告 → 销售额)
2. **Y → X**：反过来 (销售好的月份加大了广告预算)
3. **Z → X, Z → Y**：混杂变量 (旺季同时推高了广告和销售额)
4. **巧合**：数据少的时候，毫无关系的值也经常一起波动

分析师的工作不是发现相关，而是把这四种可能一一**排除**。

### 3.3 控制混杂变量 — 分层来看

怀疑有混杂变量时，最容易上手的方法是**分层 (stratification)**：
只在混杂变量取值相近的组内重新计算相关。"只挑炎热的日子看"，
冰淇淋和溺水的相关就消失了。实战里我们用代码重现这一幕。
如果层内相关消失，原来的相关多半是混杂变量的作品。

### 3.4 确认因果的正规打法 — 实验

仅凭观察数据确定因果非常困难。正规打法是**随机实验**：
用抛硬币决定哪些地区投广告、哪些不投，旺季也好收入也好，
一切混杂变量都会均匀混进两边、相互抵消。这就是 level10 要学的
A/B 测试，也是"相关→因果"问题在实务上的终点站。

实战分两部分。

**第 1 部 — 观察真实的相关**：用 numpy (`np.corrcoef`) 计算 `hjh_data`

**第 2 部 — 制造并拆解假相关**：用合成数据亲手做混杂变量实验。

- [3] 造一个"炎热指数" (混杂变量 Z)，再生成冰淇淋销量 X = Z + 噪声、
  玩水事故 Y = Z + 噪声。X 和 Y 完全不引用彼此，
  却算出 r ≈ 0.7 的强相关。
- [4] **分层实验**：把炎热指数切成 5 个区间，在每个区间内部重新计算
  X·Y 相关。确认区间内部的相关塌到 0 附近。
- [5] `outputs/confounder.png`：左边是整体散点图 (看着像强相关)，
  右边是按炎热区间着色的散点图 (每团颜色内部一片无序)。

输出的核心对比是"整体 r = 0.7 对 区间内平均 r ≈ 0"。同一份数据里
相关出现又消失的这个瞬间，就是这一关想教的全部。

## 5. 亲手试试

1. **(简单)** 在第 2 部把噪声的大小 (`noise_scale`) 调大。整体相关 r
   怎么变？观察混杂变量的力度和噪声大小如何共同决定相关的强弱。
2. **(中等)** 把第 1 部的广告费-销售额相关按门店拆开 (分层) 计算。
   整体相关和门店内相关不一样吗？不一样的话，混杂变量的候选是什么？
   (提示：`df.groupby("store")` 后在每组里用 `np.corrcoef`)
3. **(挑战)** 按公式亲手实现相关系数，验证与 `np.corrcoef` 的值一致。
   (提示：r = 协方差 / (X 标准差 × Y 标准差)，
   协方差是 `((x - x.mean()) * (y - y.mean())).mean()`)

## 6. 常见错误

- **r 很大就断定是因果**：就算 r = 0.9，它是 3.2 四条路径中的哪一条，
  r 本身不会告诉你。相关的强度和因果的证据是两码事。
- **不画散点图只看相关系数**：U 形关系、一个极端值造出的假相关，
  只有散点图里才看得见。"先看数字、省略图"是大忌。
- **没有相关 = 没有关系**：r ≈ 0 只说明"没有直线关系"。
  曲线关系完全可能存在。
- **忽视反向因果**："评价多的商品卖得好"也可能是卖得好才评价多。
  掰一掰时间顺序 (谁先谁后)。
- **控制了一个混杂变量就安心**：分层排除了一个，可能还剩下另一个。
  观察数据得出的结论永远是暂定的。
