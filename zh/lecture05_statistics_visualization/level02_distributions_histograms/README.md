# Lecture 05 · Level 02 — 分布与直方图

> 如果说代表值是数据的简历，分布就是数据的长相。要见过脸，才不会误会人。
**难度** ⭐⭐ / **先修** level01 / **预计时间** 45分钟

## 1. 为什么要学 — 业务视角

平均数和中位数学过了，但几个数字仍然会漏掉一些东西。
拿客户等待时间的数据来说——平均 4 分钟，中位数 3 分钟，看起来不坏。
可把分布画出来一看：大多数是 2~3 分钟，但每天都有十几位客户等了
20 分钟以上。客诉和流失恰恰来自这条**尾巴**。改善平均数和缩短尾巴，
是两个完全不同的项目。

画分布 (distribution) 最基本的工具是直方图 (histogram)。
把值的范围切成区间 (bin)，用柱子画出每个区间的频次。
如果你在 Excel 里用数据透视表按区间做过 COUNTIF，
那你已经手工做过直方图了。这一关我们用 Python 一行画出它，
还要学一个陷阱："改变 bin 的大小，故事就会变"。

## 2. 用类比来理解

直方图是**小区的夜间亮灯照**。它展示每户人家 (值) 住在哪栋楼 (区间)：
哪栋楼灯最多 (频次最高)、小区是一整片还是分成两片 (峰的个数)、
有没有孤零零亮着灯的房子 (极端值)，一眼就能看清。

bin 的大小是**地图的比例尺**。用全国地图 (大 bin) 只能看出
"人口集中在大城市圈"；用街区地图 (小 bin) 连每条小巷都看得见，
但整体格局消失了。没有错误的比例尺，只有**不合目的的比例尺**。
直方图同理：分成几个 bin，同一份数据既可能显得平平无奇，
也可能显得坑坑洼洼。

## 3. 核心概念

### 3.1 怎么读直方图

看直方图要看四样东西。

1. **中心**：峰在哪一带 (联系代表值)
2. **离散**：横向铺得有多宽 (联系标准差)
3. **形状**：左右对称吗？哪边尾巴长？峰有几个？
4. **异常点**：离主体很远的孤立柱子 (极端值)、莫名空缺的区间

峰有两个 (bimodal) 是"混着两个不同群体"的强烈信号。
应该按工作日/周末、新客/老客这样把群体拆开重画。

### 3.2 偏度 — 尾巴的方向

偏度 (skewness) 是分布向一侧倾斜的程度。

- **右尾 (正偏度)**：销售额、年薪、等待时间。大多是小值 +
  偶尔的大值。此时平均数 > 中位数。
- **左尾 (负偏度)**：像挤在满分附近的考试成绩那样，大值多、
  小值少。此时平均数 < 中位数。

只比较平均数和中位数的大小，就能猜出尾巴的方向。
level01 里看到的"平均数 > 中位数"现象，真身就是右尾。

### 3.3 bin 大小的影响

| bin 个数 | 能看到什么 | 风险 |
|---|---|---|
| 太少 (5个) | 只有大趋势 | 两个峰被糊成一个 |
| 适中 (20~40个) | 中心·离散·形状 | — |
| 太多 (200个) | 细部的锯齿 | 把随机噪声误当成规律 |

没有标准答案公式，但惯例的起点是"根号 n 个"，或在 20~50 之间
画几种试试，找到故事稳定下来的位置。**只相信换了 bin 也活下来的
规律**——这是实务守则。

### 3.4 直方图 vs 柱状图

长得像，但不是一回事。直方图是**把连续数值切成区间**，
所以柱子相连、顺序有含义。柱状图比较的是门店、品类这类**类别**，
柱子彼此分开、顺序可以随意调换。报告里混淆这两者，
读的人就会误解坐标轴。

### 3.5 把分布浓缩成一个数 — 百分位数尝鲜

概括直方图的辅助数字是百分位数 (percentile)。第 90 百分位数是 8 分钟，
意思是"90% 的客户在 8 分钟内得到处理"。IT 服务把响应速度目标定在
p95、p99 而不是平均数，正是为了管理尾巴。实战 [1] 会同时输出销售额的
p50 (中位数) 和 p95，请用这两个数字的间距感受尾巴的长度。

## 6. 常见错误

- **只画一种 bin 就下结论**：峰的个数这类重要判断，务必换 2~3 种 bin
  再确认。
- **群体混在一起就解读分布**：不要把双峰当成"奇怪的分布"跳过去，
  拆开群体重画。多半藏着工作日/周末、门店、商品线这样的隐藏维度。
- **不说明 y 轴是频次还是比例**：比较样本量不同的两个分布时，
  要用 `density=True` (比例) 对齐才公平。
- **隐瞒剪掉极端值再画的事实**：为了可视化限制范围没问题，
  但"剔除前 1%"之类的说明必须留在图上。
