# Lecture 05 · Level 07 — 正态分布与中心极限定理

> 无论单个数据长成什么样，"平均数们"都会聚成钟形。这是统计学的万有引力。
**难度** ⭐⭐⭐ / **先修** level06 / **预计时间** 55分钟

## 1. 为什么要学 — 业务视角

民意调查的误差范围、质量管理的控制限、A/B 测试的显著性判定——
这些实务工具的底座都压着同一个事实：**样本平均数服从正态分布**。
不管原始数据是像销售额那样拖着右尾，还是像抛硬币那样只有两个值，
"取若干个求平均"得到的值，其分布都是钟形。这就是中心极限定理
(Central Limit Theorem, CLT)。

多亏这条定理，我们不必知道原始分布，也能对平均数作出概率陈述。
"本月样本平均超出这个范围的概率不到 5%" 这样的句子之所以成立，
全靠 CLT。下一关的置信区间、再下一关的 p 值都建在它上面，
这里是推断统计的奠基石。

## 2. 用类比来理解

想想餐馆里**一碗汤的味道**。汤锅里有偏咸的地方也有偏淡的地方
(原始分布参差不齐)。可用汤勺舀好几勺搅在一起的一碗汤，味道如何？
不管端到哪碗，味道都差不多。因为混合多个位置的过程 (取平均)
抵消了极端。记录几百碗的味道，"每碗味道"的分布与锅里的参差无关，
是一条窄窄的钟形曲线。勺子越大 (样本越大)，碗与碗的差异越小。

正态分布在世上如此常见，理由相同。身高是无数基因和环境因素之和，
测量误差是无数微小抖动之和。**"许多独立小因素之和"呈钟形**——
这是 CLT 的日常版。

## 3. 核心概念

### 3.1 正态分布 — 两个旋钮

正态分布 (normal distribution) 由平均数 μ 和标准差 σ 这两个旋钮
完全确定，是左右对称的钟形分布。著名的 68-95-99.7 规则：

| 范围 | 覆盖比例 |
|---|---|
| μ ± 1σ | 约 68% |
| μ ± 2σ | 约 95% |
| μ ± 3σ | 约 99.7% |

"质量管理中超出 ±3σ 即工序异常"的惯例，"±2σ ≈ 95%" 演化成
置信区间里的 1.96——全都出自这张表。

### 3.2 中心极限定理 — 精确的陈述

从任何平均数为 μ、标准差为 σ 的分布中 (只要尾巴不是病态地重)，
反复抽取大小为 n 的样本并求平均，则：

1. 样本平均数们的平均逼近 μ；
2. 样本平均数们的标准差是 **σ/√n** (称为标准误, standard error)；
3. 样本平均数们的分布形状随 n 增大越来越接近**正态分布**。

第三条是神奇之处。原始分布是均匀分布也好、挤在左边的指数分布也好，
n=30 左右时平均数的分布已经相当钟形了。

### 3.3 √n 的经济学

标准误等于 σ/√n，在实务上意味着"精度想提高 2 倍，样本得多收集 4 倍"。
问卷受访者从 1,000 人加到 2,000 人，误差也只缩小 1.4 倍。
数据收集成本线性上涨，精度却只按平方根改善，所以"收集多少样本"
永远是成本与精度的权衡问题 (延伸到 level10 的样本量设计)。

### 3.4 CLT 失灵的地方

CLT 不是万能的。在被极端值支配的分布里——比如一单爆款占全年销售额
一半的生意、保险的巨灾损失——平均数本身就不稳定，收敛极慢甚至不成立。
这就是为什么要先问"平均数对这份数据有意义吗" (呼应 level01 的教训)。

## 6. 常见错误

- **误以为"数据多了数据就变正态"**：CLT 讲的不是原始数据，
  而是**样本平均数的分布**。销售数据收集 100 万条，依然是右尾分布。
- **混淆 σ 和 σ/√n**：标准差是单个值的散布，标准误是样本平均数的散布。
  报告里 "±" 后面的数字是哪一个，务必写明。
- **把 n=30 背成魔法数字**：30 只是惯例。原始分布偏斜越重，
  需要的 n 越大。拿不准时，像今天这样跑模拟验证才是正解。
- **凡事都假设正态分布**：金融收益率、病毒式传播的播放量这类厚尾数据
  套上正态假设，"千年一遇"的事十年能来三回。
