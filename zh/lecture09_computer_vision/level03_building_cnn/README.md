## 1. 为什么要学 — 从业务视角出发

评估引入视觉模型时，你会听到"骨干网是 ○○Net，先上 3×3 卷积 32 通道，然后……"这样的话。读不懂结构说明书，你就没法自己估算模型的大小 (成本)、速度 (响应时间)、所需分辨率 (相机规格)，一切都只能听供应商说。

读 CNN 结构的核心技能只有两项。**(1) 过一层时数据形状 (shape) 怎么变，(2) 每层有多少参数。** 能算这两样，任何结构图在你眼里都像一张报价单。今天我们把这套算法学会，并用代码验算。

## 2. 用比喻来理解

CNN 的一层就是**拿着好几个审核章的审核小组**。

level02 里章 (核) 只有一个。真正的 Conv2d 层会拿**好几个**章。垂直边缘章、水平边缘章、圆角章…… 有 16 个章，审核结果地图 (特征图) 就出 16 张。这个"几张地图"就是**输出通道 (out_channels)**。

下一层的审核小组要审的不是原始图像，而是**上一组做出来的那 16 张地图**。所以下一层的章是能同时看穿 16 张的立体章 (3×3×16)。这就是**输入通道 (in_channels)** 的含义。层越深，审核内容就越高阶: "边缘地图的组合" → "角、曲线地图" → "图形零件地图"。

最后，看完所有地图之后还需要一条做最终裁定的**审批线**。把地图拉成一排 (Flatten) 交给普通神经网络 (Linear)，就能得出"这组证据的话就是圆形 (circle)"的结论。

## 3. 核心概念

### 3.1 Conv2d 的五大设置项

`nn.Conv2d(in_channels, out_channels, kernel_size, stride, padding)`

| 设置 | 比喻 | 效果 |
|---|---|---|
| in_channels | 要审的地图有几张 | 必须与输入通道数一致 |
| out_channels | 章 (问题) 的个数 | 输出地图数 = 表达力 |
| kernel_size | 章的大小 | 一次看多大的邻域 |
| stride | 章移动的步幅 | 设 2 则输出宽高各减半 |
| padding | 文件边缘的留白 | 设 1 时 3×3 核能保持尺寸 |

### 3.2 输出尺寸公式 — 本课程用得最多的式子

```
out = (in + 2*padding - kernel) / stride + 1
```

例: 输入 16、kernel 3、padding 1、stride 1 → (16+2-3)/1+1 = **16** (保持)。
改成 stride 2 → (16+2-3)/2+1 = **8** (减半)。每次设计层都要用这个式子追到底，才能知道 Flatten 之前的尺寸 (= Linear 层的输入尺寸)。

### 3.3 参数量计算 — 给模型报价

- **Conv2d**: `out_ch × (in_ch × k × k) + out_ch` (最后一项是偏置)。例: 1→8 通道的 3×3 就是 8×9+8 = **80 个**。
- **Linear**: `out × in + out`。例: 256→3 就是 3×256+3 = **771 个**。

要注意的点: Conv 层的参数**与图像大小无关**。因为图像再大，章还是同一个章。反过来，Flatten 之后的 Linear 与图像大小成正比。所以 CNN 的参数常常大部分都堆在后段的 Linear 上，而把它减下来 (池化、全局平均) 正好接上 level04 的主题。

### 3.4 激活函数与堆层

卷积只有乘法和加法，是线性运算，中间不夹非线性 (ReLU) 的话，堆多少层都等于一层 (lecture08 level02 的复习)。所以基本块是 `Conv → ReLU`，典型的小型 CNN 长这样。

```
输入 (1, 16, 16)
Conv(1→8, 3x3, pad 1) + ReLU     → (8, 16, 16)
Conv(8→16, 3x3, pad 1, stride 2) + ReLU → (16, 8, 8)
Conv(16→32, 3x3, pad 1, stride 2) + ReLU → (32, 4, 4)
Flatten                           → (512,)
Linear(512→3)                     → (3,)  # 类别得分
```

通道加多 (8→16→32)、空间缩小 (16→8→4) 的流向 —— "位置信息压缩掉，语义信息变丰富"就是 CNN 设计的基本节奏。

### 3.5 批次维度

PyTorch 的图像张量是 `(批, 通道, 高, 宽)` 四维。一次处理 32 张图像就是 `(32, 1, 16, 16)`。shape 报错的大部分原因都是违反了这个四维约定，所以请把 "B-C-H-W" 的顺序念熟。

## 6. 常见错误

- **Flatten 尺寸算错**: Linear 层的 in_features 对不上而报 `mat1 and mat2 shapes cannot be multiplied`，这是 CNN 入门第一大错。永远用公式一路追到底。
- **通道链条断掉**: 上一层的 out_channels ≠ 下一层的 in_channels，立刻报错。通道是接力棒。
- **违反四维约定**: 把 `(16,16)` 的图像原样送进去会失败。要用 `unsqueeze` 造出批和通道维，变成 `(1,1,16,16)` 再送。
- **把参数量和计算量搞混**: Conv 层参数少，但要在所有位置反复计算，所以计算量 (FLOPs) 可能很大。"轻"并不总等于"快"。
