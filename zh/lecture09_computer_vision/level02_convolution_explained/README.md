# Lecture 09 · Level 02 — 理解卷积 (Convolution)

> 用 numpy 从零实现 CNN 的心脏 —— 卷积，并亲眼看见 3×3 的核找出图形边缘的那一刻。
**难度** ⭐⭐⭐ / **先修** level01 / **预计时间** 40分钟

## 1. 为什么要学 — 从业务视角出发

图像 AI 相关的技术文档、方案书、论文摘要里，一定会出现"卷积 (convolution)"、"核 (kernel)"、"滤波器 (filter)"这几个词。把这些词当黑箱放着，"CNN 会提取特征"这种说法就像咒语一样，变成无法验证的故事。

而卷积的真身小得令人吃惊。**把一块小小的数字板 (核) 在图像上滑动，重叠的格子两两相乘再相加。** 就这一个运算，同时承担了模糊、锐化、边缘检测这类经典图像处理，以及最新 CNN 的特征提取。今天你亲手用循环写一遍，之后无论遇到什么 CNN 结构，都能把它读成"归根结底就是把那个乘-加层层堆起来"。

## 2. 用比喻来理解

想象**盖章审阅文件**。你有一个 3×3 格的透明审核章，章上每格写着一个权重数字。你把这个章从大文件 (图像) 的左上角一格一格挪到右下角，一路盖过去。每盖一次要做的事只有一件 —— **把章上格子的数字 × 文件上格子的数字，9 对全部乘起来求和**，再把这个合计写到新文件对应的位置上。

关键在于章上**刻的是什么数字**。

- 每格都是 1/9 的章 → 周围 9 格的平均 = **模糊 (blur)**
- 左列是 -1、右列是 +1 的章 → 衡量"右边是不是比左边亮?"的审核 = **垂直边缘检测**

也就是说，核是**刻着"要在这块区域找什么"的审核章**，输出 (特征图) 则是**审核结果地图** —— 一张"要找的模式在哪里、出现得有多强"的表。

## 3. 核心概念

### 3.1 运算的定义

对输入图像 `I` 和 `k×k` 的核 `K`，输出在 (y, x) 处的值就是把核叠在那个位置上、逐元素相乘再全部相加。

```
out[y, x] = Σ_i Σ_j  I[y+i, x+j] * K[i, j]
```

写成代码就是两个循环加 `(patch * K).sum()` 一行。main.py 的 `conv2d()` 正是这个样子。

### 3.2 边缘检测核的读法

我们来读一下垂直边缘核 (Sobel 系)。

```
-1  0  +1
-2  0  +2
-1  0  +1
```

这个核的输出值 = (右边 3 格的亮度和) − (左边 3 格的亮度和)。左右亮度相同就是 0，在**左暗右亮的竖向边界线**上出现大的正数，在反方向的边界线上出现大的负数。把它转 90 度就成了水平边缘核。"核 = 写明了要对什么起反应的模式探测器"这句话就是从这里来的。

### 3.3 输出尺寸、填充与步长

- 章不能盖出文件外面，所以在 `n×n` 图像上盖 `k×k` 的核，输出会**缩小**成 `(n-k+1)×(n-k+1)`。16×16 配 3×3 就是 14×14。
- 想保持尺寸，就在边缘围一圈 0 再盖 —— **填充 (padding)**。
- 不是一格一格而是隔两格盖一次，输出就变成一半大小 —— **步长 (stride)**。既省计算量又有汇总效果。(公式和层设计在 level03 讲。)

### 3.4 为什么图像就得用卷积

它和图像的两个性质严丝合缝。

1. **局部性**: "这里是边界吗?"只看周围几个像素就能判断。有很多问题 3×3 的核就够了。
2. **位置不变性**: 左上角的竖向边界和右下角的竖向边界是同一个模式。卷积把一个核在整张图像上反复使用，相当于"在所有位置做同一项审核"，不需要每个位置分别去学。这就是 CNN 的参数量比 MLP 少得压倒性的原因 (level05 会用性能来验证)。

### 3.5 曾经靠手刻的核，现在交给学习

在经典图像处理里，Sobel、拉普拉斯这类核是由专家**手工设计**的。CNN 的革新只有一点 —— **让数据来决定核里的数字**。lecture06 level00 说的"人只定规则的形状，数字由数据来定"，在图像世界里再一次重演。今天我们用手刻的核确认原理，从 level03 起转向被学出来的核。

## 6. 常见错误

- **把"相乘再相加"误当成"平均"**: 卷积是求和 (sum)。平均核是通过把核的值本身设成 1/9 来实现的，并不是运算本身是平均。
- **被负数输出吓到**: 边缘核的输出出现负数是正常的 (方向信息)。直接 imshow 可能一片漆黑，请用绝对值或对称的 colormap 来看。
- **忘了输出尺寸会缩小**: 层堆多了，3×3 的核每层啃掉 2 个像素，图像不知不觉就没了。为什么要用填充，答案就在这里。
- **以为核越大越好**: 两层 3×3 覆盖同样的视野，参数比一个 7×7 更少。这就是现代 CNN 把 3×3 当标准的原因。
