# Lecture 04 · Level 02 — SELECT 基础

> 学习 SQL 的第一句话，也是一切的起点 — SELECT。从想要的表里只挑出想要的列，给列名起别名，再造出计算出来的新列。

**难度** ⭐ / **先修** level01 / **预计时间** 35分钟

## 1. 为什么要学 — 业务视角

实际工作中，90% 以上的 SQL 使用都是**查询**。改数据的事交给系统，
人主要负责问"给我看看"。这句"给我看看"就是 SELECT。
光是把 SELECT 一句话用熟，以前"麻烦帮我导一份客户名单"要跨部门等两天的事，
就变成了 30 秒的自助服务。更妙的是，SELECT 只读数据、绝不修改，
所以新手怎么练都不会闯祸，是最安全的语句。

## 2. 打个比方

SELECT 语句就是**递给柜台职员的申请单**。接着文具店账本的比方说，
申请单上有两栏:

> **从哪本账本** (FROM customers — 从客户名册)
> **要哪些项目** (SELECT name, city — 只要姓名和城市两项)

唯一要注意的是它的阅读顺序和中文相反。SQL 写作 "SELECT 姓名, 城市
FROM 客户名册"，但柜台职员是按"从客户名册(FROM) → 取出姓名和城市(SELECT)"
的顺序处理的。读 SQL 时养成**先找 FROM 再读 SELECT** 的习惯，
再长的查询也不可怕。

别名 (alias) 是申请单上"报表里请用这个名字"那一栏。
写 `price AS 售价`，结果表的列标题就变成"售价"。
数据本身原封不动，改的只是**显示出来的名字**。

## 3. 核心概念

### 3-1. 基本形态

```sql
SELECT 列1, 列2      -- 要什么 (列清单)
FROM   表名;          -- 从哪里
```

- 大小写不区分，但按惯例保留字 (SELECT, FROM…) 用大写，
  表名、列名用小写，一眼就能分清。
- 句末的分号 (;) 表示"申请单到此为止"。
- `--` 后面是注释，不会被执行。

### 3-2. 所有列: `SELECT *`

`*` 的意思是"全部"。初次打量一张表时很方便，但正式查询里最好写明
需要的列。在几十列的大表上用 `*` 既浪费屏幕，将来表里加了新列，
结果的形状还会跟着变。"先用 * 扫一眼，正式查询写列名" — 这是实战的节奏。

### 3-3. 别名 (AS)

```sql
SELECT name AS 商品名, price AS 售价
FROM   products;
```

AS 可以省略 (`price 售价`)，但新手阶段写全更好读。
别名只改结果表的列标题，表里真正的列名不会变。

### 3-4. 计算列 (expression)

SELECT 清单里不仅能写列名，还能写**计算式**。

```sql
SELECT name,
       price,
       cost,
       price - cost AS 毛利
FROM   products;
```

每一行都会计算 `price - cost`，像新列一样出现在结果里。
这和在 Excel 的 D 列填 `=B2-C2` 公式一样，只是不需要往下拖动复制，
一句话就套用到所有行。拼接字符串的 `||` 运算符、四舍五入的
`ROUND()` 这类函数也写在同一个位置。

### 3-5. 提前见面的 LIMIT

结果动辄几百行会刷爆屏幕，所以从本关开始我们加上 `LIMIT 5`
(只看前 5 行) 来缩短输出。正式讲解在 level04，
现在只需要把它当成"预览装置"。

### 3-6. SELECT 不会改动原件

SELECT 的结果是原表的**只读快照**。不管加别名还是造计算列，
hjh_shop.db 里的数据一个字节都不会变。所以查询练习无论怎么失手都安全。
真正修改数据的语句 (INSERT, UPDATE, DELETE) 会在 level08
和事务一起小心翼翼地学。

## 4. 动手练习 — main.py

运行:

```bash
python3 main.py
```

main.py 每次都会重新生成 `hjh_shop.db`，先用 print 展示 SQL 语句，
紧接着输出运行结果表。**以 SQL> 开头的行才是主角**，
Python 代码只是传话的执行器。

- **[1] 扫一眼所有列**: `SELECT * FROM customers LIMIT 5` — 和表打个照面，
  确认列的构成和数据长相。
- **[2] 只要需要的列**: `SELECT name, city FROM customers LIMIT 5` —
  在申请单上写明项目的基本形。
- **[3] 起别名**: 把 products 打印成列标题为 `商品名/品类/售价`
  的报表式表格。
- **[4] 计算列**: `price - cost AS 毛利`，再用
  `ROUND(100.0*(price-cost)/price, 1) AS 毛利率` 逐行计算。
- **[5] 字符串拼接**: 用 `name || ' (' || grade || ')'` 造出
  "王志明 (VIP)" 这种展示用的列。邮件合并等场景的常用套路。

每一步读 SQL 时，请练习先找 FROM → 再读 SELECT 清单。
也留意结果表的列标题正是别名。

## 6. 常见误区

- **字符串用双引号**: SQL 里文字数据用单引号包 (`'北京'`)。
  双引号是留给列名、表名的，混用会报出让人摸不着头脑的错误。
- **列名打错字**: 像 `SELECT nmae` 这样的笔误会报 "no such column"。
  错误信息里提示都写全了，别慌，读一读。
- **SELECT 后漏逗号/多逗号**: `SELECT name city` 不报错，
  而是把 city 解释成 name 的**别名**，得出莫名其妙的结果。逗号一定要检查。
- **在正式查询里用 `SELECT *`**: 只在打量表时用，
  要保存下来反复使用的查询请写明列名。
