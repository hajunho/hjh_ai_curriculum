# Lecture 07 — 商业机器学习实战

> 这门课把 lecture06 学到的模型打磨成"在公司里真正跑起来的项目"。
> 从问题定义讲到特征设计、验证，一直到最后一步 — 把模型的答案变成能赚钱的决策。

## 这门课你将学到

- 数据项目在现实中推进的顺序，以及失败项目的共同模式
- 把"召回率提升 1 个百分点"翻译成"每年多少营收"的方法 — 和管理层对话的语言
- 把探索性数据分析 (EDA) 从凭感觉变成按步骤执行的工作流
- 特征工程、类别变量编码、缩放与流水线 — 比模型本身更能左右性能的准备工作
- 交叉验证与不平衡数据处理 — 让性能数字"值得信赖"的技术
- 实战三连: 销售需求预测、客户流失预测、异常交易检测
- 把模型输出的概率放进成本·收益计算，得出最优决策 (优惠券该发给谁) 的方法

## 这门课在实际工作中的应用场景

- **季度经营计划**: 把星期效应、季节效应都考虑进去，预测下周、下月的销售额，提前安排库存和人力 (level08)
- **CRM 营销活动**: 生成流失风险最高的客户名单和每位客户的推荐动作，交给市场部 (level09、11)
- **风控·审计部门**: 按照每天的告警处理能力 (预算) 设计异常交易检测的阈值 (level07、10)
- **数据团队协作·外包验收**: 面对一份写着"准确率 95%"的报告，能问出数据泄漏、单次划分陷阱的问题 (level03~06)
- **向管理层汇报**: 不摆混淆矩阵，而是说"这个模型每年能帮我们止住 4 亿韩元的流失损失" (level01、11)

## 学习建议

- 所有关卡都设计成一边运行 `main.py` 一边阅读。请核对数字是否和讲义一致 (seed 已固定)。
- 运行方式: 用仓库根目录的虚拟环境执行 `python3 main.py` (环境配置见根目录 `SETUP.md`)
- 数据全部由 `common/hjh_data.py` 合成生成 (咖啡店销售、订阅流失、银行卡交易)，金额均以韩元 (KRW) 计价。全程不需要联网。
- level00~07 是零件，level08~11 是成品。如果跳过了零件关卡，在实战关卡卡住时记得回头补课。
