# Lecture 01 · Level 01 — 文件、文件夹与路径的概念

> 计算机里的一切数据都是文件，而文件的地址就是路径 (path)。理解这一点之后，我们用 Python 的 pathlib 亲手创建并探索一棵文件夹树。

**难度** ⭐ / **先修** level00 / **预计时间** 35分钟

## 1. 为什么要学 — 从业务视角出发

学编程时遇到的报错里，相当一部分并不高深，就是"找不到文件 (FileNotFoundError)"。做数据分析要读 CSV 文件，做完报表要存到某个地方，AI 模型最终也是存成文件。可如果不会把文件"在哪里"准确地告诉计算机 — 也就是不懂**路径** — 你将寸步难行。

从实际工作的角度看，路径感直接等于钱。在共享网盘里来回问"那个文件放哪儿了?"耗掉的时间、存错文件夹导致版本混乱的事故、备份时漏掉的文件夹 — 全都源于对路径和文件夹结构缺乏感觉。学完这一关，你就能用一行地址精确表达任何文件的位置，还能用 Python 自动创建或翻查文件夹结构。

## 2. 用比喻来理解

**文件夹结构就是公司大楼的地址体系**。

想象一下公司总部大楼: "总部大楼 > 3 层 > 销售部办公室 > 王经理的文件柜 > 2024 年合同文件夹 > A公司_合同.pdf"。像这样从大到小一级级走下去，世界上任何一份文件都能被唯一确定。计算机的路径正是这个方式。

```
/Users/wang/Documents/contracts/2024/A公司_合同.pdf
```

最前面的 `/` 是"总部大楼正门 (根目录, root)"，用 `/` 分隔的每一级对应楼层、办公室、文件柜。像这样**从正门开始把完整地址写全的，叫绝对路径 (absolute path)**。

而在公司内部聊天时，大家会简说"在我们组文件柜的 2024 文件夹里"。因为说话双方都知道彼此现在在哪 (当前位置)。这就是**相对路径 (relative path)** — 像 `contracts/2024/A公司_合同.pdf` 这样以当前位置为基准的地址。相对路径有两个特殊写法: `.` 表示"就是这间屋"，`..` 表示"上一层 (父文件夹)"。

文件名末尾的 `.pdf`、`.xlsx`、`.py` 这类**扩展名 (extension)，是盖在文件袋上的文档类型印章**。它是一种约定，告诉大家里面装的是什么 (文档、表格还是代码)，操作系统就是看这个印章来决定用哪个程序打开。

## 3. 核心概念

### 3-1. 一切皆文件

计算机里的文档、照片、程序，甚至配置项，全都是文件。文件由"名字 + 内容 (0 和 1 的序列) + 位置"构成; 文件夹 (目录, directory) 是装文件的容器，也能再装别的文件夹。所以整体结构是一棵从根部长出枝杈的**树 (tree) 结构**。

### 3-2. 绝对路径 vs 相对路径

| 区别 | 绝对路径 | 相对路径 |
|---|---|---|
| 起点 | 根目录 (`/`) 或盘符 (`C:\`) | 当前工作文件夹 |
| 示例 | `/Users/wang/data/sales.csv` | `data/sales.csv` |
| 优点 | 在哪运行都指向同一个文件 | 简短，整个项目搬走后依然有效 |
| 缺点 | 换台电脑容易失效 | "当前位置"不同就会指到别处 |

这里的"当前位置"叫作**当前工作目录 (current working directory, CWD)**。你在哪个文件夹里运行程序，那里就是 CWD，所有相对路径都以它为基准解析。相对路径报错的 90% 都是因为"我以为的当前位置"和"实际的 CWD"不一致。

### 3-3. 操作系统之间的差异

macOS/Linux 的分隔符是 `/`，根目录只有一个 `/`。Windows 的分隔符是 `\`，并且有 `C:\`、`D:\` 这样按盘符划分的根。正因为这个差异，直接用字符串拼接路径的代码换个操作系统就会坏掉。Python 的 **pathlib** 库会自动处理这些差异，所以本课程从一开始就把 pathlib 作为标准用法。

### 3-4. pathlib 的核心 5 招

```python
from pathlib import Path
p = Path("data") / "sales.csv"   # 组合路径: 用 / 运算符最安全
p.exists()                        # 检查是否存在
p.mkdir(parents=True, exist_ok=True)  # 创建文件夹 (连同中间层级，已存在也不报错)
p.resolve()                       # 转成绝对路径
p.suffix, p.stem, p.parent        # 扩展名、主名、父文件夹
```

掌握这五招，后面课程里绝大多数文件操作代码你都能读懂。

## 4. 实战 — main.py

```bash
python3 main.py
```

这个脚本在一个临时文件夹里搭建并探索虚构小公司"晨光商社"的文档树。

- **[1] 创建树**: 用 pathlib 创建 `行政部/`、`销售部/合同/`、`销售部/报表/` 这些部门文件夹和示例文件。
- **[2] 画出树**: 用递归函数把文件夹结构打印成带缩进的树状图。相当于用 Python 模仿终端的 `tree` 命令。
- **[3] 绝对 vs 相对**: 用绝对路径和相对路径两种方式表示同一个文件并对比，还演示 `..` 是怎么工作的。
- **[4] 扩展名统计**: 翻遍整棵树 (`rglob`)，按扩展名统计文件数量。相当于数一数"公司档案库里各类文件各有几份"。
- **[5] 解剖路径**: 把一条路径拆成 parent / name / stem / suffix 逐个展示。

核心代码是 `draw_tree()` 函数。它打开一个文件夹、列出里面的东西，遇到子文件夹就再调用它自己 — 这种**递归 (recursion)** 结构是处理树形结构最自然的方法，以后还会经常遇到。实战结束后临时文件夹会自动删除，不会在你的电脑上留下任何痕迹。

## 6. 常见错误

- **用字符串加法拼路径**: `"data" + "/" + "sales.csv"` 在 Windows 上可能出问题。永远用 `Path("data") / "sales.csv"`。
- **搞错 CWD**: 脚本文件所在的文件夹和你运行它的文件夹可能不同。需要以脚本为基准的路径时，用 `Path(__file__).parent`。
- **删掉或乱改扩展名**: 扩展名不会改变内容。把 `report.xlsx` 改名成 `report.csv` 并不会让它变成 CSV，反而会打不开。
- **路径里带中文和空格**: 尽量养成用英文小写加下划线 (`sales_2024.csv`) 命名文件夹和文件的习惯。空格和中文在终端和代码里需要加引号等各种额外照顾。
