# 术语词典 — 写给非科班人士的 IT · AI 术语

学习中被术语卡住时就来这里查。每个词都按“比喻 → 定义”的顺序解释。

| 术语 | 比喻 | 定义 |
|---|---|---|
| 算法 (algorithm) | 一份菜谱 | 解决问题的分步骤流程 |
| 变量 (variable) | 贴了标签的盒子 | 用来存放值的存储空间 |
| 函数 (function) | 一页工作手册 | 接收输入、完成固定工作并返回结果的一段代码 |
| 库/包 (library/package) | 公司里的专业部门 | 别人做好的功能合集，拿来就能用 |
| API | 餐厅的点餐窗口 | 程序之间按约定格式进行请求和响应的窗口 |
| 终端/CLI | 用文字聊天来指挥计算机 | 不用鼠标、用命令操作计算机的界面 |
| 虚拟环境 (venv) | 项目专用的工具箱 | 每个项目相互隔离的 Python 包空间 |
| Git | 文档的时光机记录本 | 保存和恢复代码修改历史的工具 |
| 数据库 (DB) | 超大型账本保管库 | 结构化地存储和检索数据的系统 |
| SQL | 写给账房先生的申请单 | 向数据库提问的标准语言 |
| 缺失值 | 问卷上的空白格 | 值为空的数据 |
| 异常值 | 账本里可疑的数字 | 大幅偏离正常范围的值 |
| 特征 (feature) | 判断依据的项目 | 作为模型输入使用的变量 |
| 标签 (label) | 标准答案 | 模型需要猜中的答案 |
| 训练 (training) | 培训新员工 | 用数据调整模型内部数字的过程 |
| 过拟合 (overfitting) | 只会死记真题的学生 | 只擅长训练数据、面对新数据就不行的状态 |
| 准确率/精确率/召回率 | 体检中不同类型的误诊 | 从不同角度衡量分类性能的指标 |
| 梯度下降 | 在雾中下山 | 沿着误差减小的方向一点点移动的优化方法 |
| 神经网络 | 模仿神经元的计算网 | 把简单计算单元层层堆叠起来的模型 |
| 轮次 (epoch) | 把习题册刷完一遍 | 完整过一遍全部训练数据的次数 |
| 批次 (batch) | 一次批改的一摞答卷 | 一次参数更新所使用的一组数据 |
| CNN | 拿放大镜逐块扫视 | 用小窗口扫过图像来提取特征的神经网络 |
| 词元 (token) | 一张张单词卡片 | 模型处理文本的最小单位 |
| 嵌入 (embedding) | 词语的坐标 | 把语义表示成数字向量 |
| Transformer | 开会时互相察言观色 | 用注意力机制一次看全上下文的神经网络结构 |
| LLM | 超大型句子补全机器 | 用海量文本预训练的大语言模型 |
| 提示词 (prompt) | 一份工作指令单 | 给 LLM 的输入指令 |
| RAG | 开卷考试 | 让模型参考检索到的依据文档来回答的技术 |
| 向量数据库 | 按含义找书的图书馆 | 用嵌入相似度进行检索的数据库 |
| 微调 (fine-tuning) | 给老员工做岗位培训 | 让预训练模型针对特定任务追加学习 |
| SFT | 照着范文誊写 | 用“指令-回答”示例做的监督微调 |
| DPO | 两份答卷里挑更好的那份 | 用偏好对来对齐模型口味的技术 |
| 量化 (quantization) | 高清 → 适度画质压缩 | 降低模型数字的精度来换取更小体积和更快速度 |
| GPU | 专做计算的大规模临时工军团 | 专为并行计算设计的处理器 |
| 幻觉 (hallucination) | 一本正经地胡说八道 | LLM 生成看似合理的错误内容的现象 |
| MLOps | 模型的工厂化运营管理 | 模型的部署、监控与运维体系 |
