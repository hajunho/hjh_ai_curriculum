## 1. 왜 배우나 — 비즈니스 관점

엑셀 차트로도 그림은 그릴 수 있습니다. 그런데 왜 코드로 그릴까요?
첫째, **반복**입니다. 매주 갱신되는 지점별 매출 그래프 30장을 엑셀로
만들면 반나절, 코드로 만들면 실행 한 번입니다. 둘째, **재현**입니다.
"지난달 보고서의 그 그래프, 조건만 바꿔서 다시"라는 요청에 코드는 즉시
답합니다. 셋째, **확장**입니다. 이후 배울 머신러닝·A/B 테스트 결과는
결국 Matplotlib 로 확인하게 됩니다.

Matplotlib 은 파이썬 시각화의 표준 라이브러리입니다. seaborn, pandas 의
`.plot()` 등 대부분의 시각화 도구가 내부적으로 Matplotlib 을 씁니다.
그래서 Matplotlib 의 구조(figure/axes)를 한 번 제대로 이해하면 다른
도구의 문서도 술술 읽힙니다.

## 2. 비유로 이해하기

Matplotlib 의 구조는 **보고서 작성**과 같습니다.

- **figure(피겨)** 는 A4 용지 한 장입니다. 크기(figsize)를 정하고, 다 쓰면
  파일로 저장(savefig)합니다.
- **axes(액시스)** 는 용지 위의 문단(그래프 한 칸)입니다. 한 장에 문단
  하나만 둘 수도(`plt.subplots()`), 2×2로 네 문단을 둘 수도 있습니다
  (`plt.subplots(2, 2)`).
- **plot/bar/scatter** 는 문단 안의 문장입니다. 선을 긋고, 막대를 세우고,
  점을 찍습니다.
- **제목·축 이름·범례**는 문단의 소제목과 각주입니다. 이것이 없는 그래프는
  주어 없는 문장과 같아서, 그린 본인 외에는 아무도 못 읽습니다.

"종이를 꺼내고(figure) → 문단을 나누고(axes) → 문장을 쓰고(plot) →
소제목을 달고(title/label) → 제출한다(savefig)" — 이 다섯 단계가 모든
Matplotlib 코드의 뼈대입니다.

## 3. 핵심 개념

### 3.1 기본 뼈대 코드

```python
import matplotlib
matplotlib.use("Agg")            # 화면 없이 파일로 저장하는 모드
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(8, 4.5))   # 종이 + 문단 1칸
ax.plot(x, y)                              # 선 긋기
ax.set_title("월별 매출 추이")
ax.set_xlabel("월")
ax.set_ylabel("매출 (백만 원)")
fig.savefig("outputs/monthly.png", dpi=120)
plt.close(fig)                             # 종이 치우기 (메모리 정리)
```

`plt.plot(...)` 처럼 ax 없이 그리는 방식도 있지만, 이 강의에서는 항상
`fig, ax = plt.subplots()` 로 시작하는 **객체지향 스타일**을 씁니다.
그래프가 여러 개가 되는 순간 이 방식이 훨씬 덜 헷갈립니다.

### 3.2 그래프 3형제 — 언제 무엇을 쓰나

| 종류 | 함수 | 쓰는 상황 | 예 |
|---|---|---|---|
| 선그래프 | `ax.plot` | **시간에 따른 변화** | 월별 매출 추이 |
| 막대그래프 | `ax.bar` | **범주 간 비교** | 지점별 매출 비교 |
| 산점도 | `ax.scatter` | **두 수치의 관계** | 광고비 vs 매출 |

거꾸로 쓰면 바로 어색해집니다. 지점 비교를 선그래프로 그리면 "강남점에서
홍대점으로 변해가는" 듯한 착시가 생기고, 시간 추이를 막대로 그리면 추세가
잘 안 보입니다. "시간=선, 범주=막대, 관계=점" 세 글자씩만 기억하세요.

### 3.3 한글 폰트 이슈

Matplotlib 기본 폰트에는 한글 글자가 없어서, 한글 제목이 □□□(두부)로
깨지는 일이 흔합니다. 해결법은 OS 에 설치된 한글 폰트를 지정하는 것입니다.

```python
from matplotlib import font_manager
plt.rcParams["font.family"] = "AppleGothic"   # macOS
# Windows: "Malgun Gothic" / Linux: "NanumGothic" (설치 필요)
plt.rcParams["axes.unicode_minus"] = False    # 마이너스 기호 깨짐 방지
```

실습 코드의 `set_korean_font()` 는 세 OS 의 대표 폰트를 순서대로 찾아
있는 것을 쓰도록 만들어, 어떤 환경에서도 동작합니다. 이 함수를 여러분
프로젝트에 복사해 가도 좋습니다.

### 3.4 저장 규칙 — Agg 와 outputs/

서버나 자동화 스크립트에는 모니터가 없습니다. `matplotlib.use("Agg")` 는
"화면에 띄우지 말고 그림 파일만 만들라"는 선언으로, **pyplot 을 import
하기 전에** 호출해야 합니다. 저장은 `fig.savefig(경로, dpi=120)` 로 하고,
이 강의에서는 항상 레벨 폴더의 `outputs/` 아래에 저장한 뒤 경로를
print 합니다. `os.makedirs(OUT_DIR, exist_ok=True)` 로 폴더가 없으면
만들고 있으면 넘어가는 것도 표준 패턴입니다.

### 3.5 색은 정보다

색을 "예쁘게"가 아니라 "말하려는 것"에 씁니다. 모든 막대를 무지개색으로
칠하면 읽는 사람은 색마다 의미를 찾으려다 지칩니다. 기본은 차분한 한
가지 색, 강조하고 싶은 막대 하나만 다른 색 — 이것만으로 그래프의 메시지
전달력이 크게 올라갑니다. 실습 [3]의 막대그래프가 이 원칙을 그대로
구현합니다.

## 6. 자주 하는 실수

- **`matplotlib.use("Agg")` 를 pyplot import 뒤에 호출**: 경고가 나거나
  적용되지 않을 수 있습니다. 항상 import matplotlib 직후 첫 줄에 두세요.
- **`plt.close(fig)` 생략**: 그래프를 수십 장 그리는 반복문에서 메모리가
  계속 쌓입니다. 저장했으면 닫는 습관을 들이세요.
- **축 이름·단위 생략**: "매출"인지 "매출(만 원)"인지에 따라 그래프 해석이
  100배 달라집니다. 단위는 축 이름에 반드시 적으세요.
- **범주 비교에 선그래프 사용**: 지점 사이에는 '중간'이 없습니다. 선으로
  이으면 없는 연속성을 암시하게 됩니다.
- **한글 폰트 설정 없이 배포**: 내 컴퓨터에서 잘 보여도 동료 컴퓨터에서
  두부가 됩니다. 폰트 탐색 코드를 스크립트에 포함하세요.
