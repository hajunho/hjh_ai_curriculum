# Lecture 05 · Level 09 — 가설검정과 p-value

> 가설검정은 재판입니다. 데이터는 증거이고, p-value 는 "무죄인데 이런 증거가 나올 가능성"입니다.
**난이도** ⭐⭐⭐⭐ / **선행** level08 / **예상 시간** 60분

## 1. 왜 배우나 — 비즈니스 관점

"리뉴얼한 지점 매출이 8% 높습니다"라는 보고에 임원이 묻습니다. "그거
우연 아니에요?" 이 질문에 감이 아니라 절차로 답하는 도구가 가설검정
(hypothesis testing)입니다. 신약 승인, 품질 합격 판정, 논문 심사, A/B
테스트 — 세상의 수많은 공식 판정이 이 절차 위에서 돌아갑니다.

동시에, p-value 는 아마 세상에서 가장 많이 오해되는 통계 개념입니다.
"p < 0.05 니까 우리 가설이 맞을 확률 95%"라는 해석은 널리 퍼져 있고,
틀렸습니다. 이 레벨의 목표는 두 개입니다. p-value 를 **직접 손으로
(시뮬레이션으로) 만들어 보아** 그 정의를 몸에 새기는 것, 그리고 scipy
한 줄 검정과 결과가 일치함을 확인해 도구를 믿고 쓰게 되는 것.

## 2. 비유로 이해하기

형사 재판에는 무죄추정의 원칙이 있습니다. 피고인은 **유죄가 입증되기
전까지 무죄로 간주**됩니다. 검사가 할 일은 "무죄라고 보기에는 너무
이상한 증거"를 제시하는 것입니다.

가설검정이 정확히 이 구조입니다.

| 재판 | 가설검정 |
|---|---|
| 피고인은 무죄다 (기본 전제) | 귀무가설 H₀: "차이 없음, 순전히 우연" |
| 검사의 주장 | 대립가설 H₁: "진짜 차이가 있다" |
| 증거 | 관측된 데이터 (두 지점의 매출 차이) |
| "무죄인데 이런 증거가 나올 리가" | p-value: H₀ 가 참일 때 이 정도 차이가 우연히 나올 확률 |
| 합리적 의심의 여지가 없음 | p < 0.05 → H₀ 기각 (유의수준 5%) |
| 무죄 판결 ≠ 결백 증명 | 기각 실패 ≠ "차이 없음이 증명됨" |

마지막 줄이 중요합니다. 증거 불충분 무죄가 결백 증명이 아니듯,
p = 0.3 은 "차이가 없다"의 증명이 아니라 "우연으로도 설명 가능하다"일
뿐입니다.

## 3. 핵심 개념

### 3.1 검정의 4단계 절차

1. **귀무가설 H₀ 설정**: "두 지점의 진짜 평균 매출은 같다."
2. **검정통계량 계산**: 관측된 차이를 표준오차로 나눈 값 (t-통계량).
3. **p-value 계산**: H₀ 가 참인 세계에서, 이만큼 크거나 더 큰 차이가
   우연히 나올 확률.
4. **판정**: p 가 미리 정한 유의수준(보통 0.05)보다 작으면 H₀ 기각.

유의수준은 **재판 전에** 정해야 합니다. 결과를 보고 기준을 옮기는 것은
과녁을 화살 뒤에 그리는 일입니다.

### 3.2 p-value 가 "아닌 것" 목록

- ❌ H₀ 가 참일 확률 (그건 데이터가 아니라 가설에 대한 확률 — 베이지안의 영역)
- ❌ 대립가설이 맞을 확률
- ❌ 효과의 크기 (표본이 크면 하찮은 차이도 p 는 작아집니다)
- ❌ 재현될 확률
- ⭕ **"차이가 없는 세계에서, 이 정도(이상)의 차이가 우연히 관측될 확률"**

p = 0.03 의 올바른 보고: "두 지점이 정말 같다면, 이만한 차이가 우연히 날
확률은 3%입니다. 우연이라 보기 어려워 차이가 있다고 판단합니다."

### 3.3 두 가지 오류 — 오탐과 놓침

| | 실제로 차이 없음 | 실제로 차이 있음 |
|---|---|---|
| 검정: 차이 있다 | **1종 오류(α)** 오탐 | 올바른 탐지 (검정력) |
| 검정: 판단 유보 | 올바른 무죄 | **2종 오류(β)** 놓침 |

유의수준 0.05 란 "차이가 없어도 100번 중 5번은 오탐을 감수한다"는
계약입니다. 오탐이 치명적인 분야(신약)는 α 를 낮추고, 놓침이 치명적인
분야(암 선별검사)는 검정력을 높입니다. 공짜는 없습니다.

### 3.4 순열검정 — 시뮬레이션으로 만드는 p-value

t-검정 공식이 없어도 p-value 를 만들 수 있습니다. H₀ 가 "두 지점은
같다"라면, 매출 데이터에 붙은 지점 라벨은 아무 의미가 없어야 합니다.
그러니 **라벨을 마구 섞어서**(순열, permutation) 차이를 계산하는 일을
1만 번 반복하면, "우연만으로 생기는 차이"의 분포가 나옵니다. 실제 관측된
차이가 그 분포의 꼬리 어디에 있는지 세면 그것이 p-value 입니다.
공식 없이 정의 그대로 만드는 p-value — 이번 실습의 핵심입니다.

## 4. 실습 — main.py

```bash

```

두 지점의 매출 차이를 재판에 부칩니다.

- [1] `hjh_data` 매출에서 부산점과 대전점의 건당 매출 표본을 뽑고, 관측된
  평균 차이를 출력합니다.
- [2] **순열검정**: 지점 라벨을 10,000번 섞어 "우연의 차이" 분포를 만들고,
  관측 차이보다 극단적인 비율 = p-value 를 셉니다.
- [3] **scipy 검정**: `stats.ttest_ind()` (Welch's t-test) 한 줄로 같은
  질문을 검정하고, 두 p-value 가 근접함을 확인합니다.
- [4] `outputs/permutation.png`: 우연의 분포 히스토그램 위에 관측 차이
  위치를 화살표로 표시 — "p-value = 꼬리의 넓이"를 그림으로 새깁니다.
- [5] **대조 실험**: 진짜 차이가 없는 두 표본(같은 지점을 반으로 쪼갬)으로
  같은 검정을 돌려 p 가 크게 나오는 것, 그리고 1종 오류의 의미를
  확인합니다.

출력에서 순열검정 p 와 scipy p 가 소수점 두세 자리까지 비슷하게 나오는
것을 확인하세요. 공식은 시뮬레이션의 지름길일 뿐, 같은 것을 계산합니다.

## 6. 자주 하는 실수

- **p 를 "가설이 맞을 확률"로 보고**: 3.2 목록을 회의 전에 다시 읽으세요.
  잘못 말하면 통계를 아는 사람 앞에서 신뢰를 잃습니다.
- **p = 0.049 와 0.051 을 하늘과 땅 차이로 취급**: 0.05 는 절벽이 아니라
  관례적 선입니다. 효과 크기, 비용, 재현 가능성을 함께 보고하세요.
- **유의함 = 중요함**: 표본 100만 건이면 매출 차이 0.1%도 p < 0.001 이
  나옵니다. "통계적으로 유의"와 "사업적으로 의미"는 별개 질문입니다.
- **여러 번 검정하고 좋은 것만 보고**: 지표 20개를 검정하면 차이가 없어도
  평균 1개는 p < 0.05 가 나옵니다(다중비교 문제). 몇 개를 검정했는지
  숨기는 보고는 왜곡입니다. 다음 레벨의 peeking 문제와 형제지간입니다.
- **기각 실패를 "같음이 증명됨"으로 보고**: 증거 불충분과 결백 증명은
  다릅니다.
