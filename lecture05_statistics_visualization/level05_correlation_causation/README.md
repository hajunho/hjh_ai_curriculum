# Lecture 05 · Level 05 — 상관관계와 인과관계

> "같이 움직인다"와 "때문에 움직인다" 사이에는 비즈니스 의사결정 하나만큼의 거리가 있습니다.
**난이도** ⭐⭐⭐ / **선행** level03 / **예상 시간** 50분

## 1. 왜 배우나 — 비즈니스 관점

"광고비를 늘린 달에 매출이 높았습니다. 광고 예산을 두 배로 올립시다."
회의에서 흔히 듣는 논리입니다. 그런데 만약 성수기라서 광고도 늘리고
손님도 늘어난 것이라면? 광고 예산을 두 배로 올려도 비수기 매출은 꿈쩍하지
않을 것이고, 그 예산은 허공으로 사라집니다.

상관관계(correlation)는 "두 값이 같이 움직이는 경향"이고, 인과관계
(causation)는 "한쪽을 바꾸면 다른 쪽이 바뀌는 관계"입니다. 데이터 분석이
찾아내는 것은 대부분 상관까지입니다. 그런데 예산 배정, 채용, 가격 결정
같은 **행동**은 인과를 전제로 합니다. 상관을 인과로 착각하는 순간, 데이터
기반 의사결정은 데이터로 포장된 도박이 됩니다. 이 구분은 아마도 이 강의
전체에서 실무 가치가 가장 높은 한 장입니다.

## 2. 비유로 이해하기

여름 해변 도시의 통계를 보면 **아이스크림 판매량과 익사 사고**가 놀랍도록
같이 움직입니다. 아이스크림이 사람을 물에 빠뜨릴까요? 당연히 아닙니다.
**더운 날씨**라는 제3의 변수가 아이스크림 판매도 늘리고 물놀이 인구도
늘린 것입니다. 이렇게 두 변수 모두에 영향을 주어 가짜 상관을 만드는
변수를 교란변수(confounder)라고 합니다.

교란변수는 **몸통을 숨긴 문어**입니다. 우리 눈에는 물 위로 나온 다리 두
개(아이스크림, 익사)만 보입니다. 두 다리가 같이 움직이니 서로 연결된
것처럼 보이지만, 실제로는 물 밑의 몸통(날씨)이 둘 다 움직이고 있는
것입니다. 다리 하나를 잡아 흔들어도(아이스크림 판매 금지) 다른 다리는
움직이지 않습니다. 몸통이 그대로니까요.

## 3. 핵심 개념

### 3.1 상관계수 읽는 법

피어슨 상관계수(Pearson correlation coefficient) r 은 -1 ~ +1 사이의
숫자로 **직선적인** 동행 정도를 나타냅니다.

| r | 해석 |
|---|---|
| +1.0 | 완벽한 정비례 동행 |
| +0.7 ~ +0.9 | 강한 양의 상관 |
| +0.3 ~ +0.5 | 약한~중간 양의 상관 |
| 0 부근 | 직선적 관계 없음 |
| 음수 | 반대로 움직임 (예: 가격↑ 판매량↓) |

주의 둘. 첫째, r 은 직선 관계만 잡습니다. U자형 관계(적정 온도에서 매출
최대)는 r ≈ 0 으로 나올 수 있습니다. 그래서 상관계수를 보기 전에 반드시
산점도를 그립니다. 둘째, r 의 크기는 "기울기"가 아니라 "점들이 직선에
얼마나 달라붙었나"입니다.

### 3.2 상관이 생기는 네 가지 경로

X 와 Y 의 상관이 관찰될 때, 가능한 설명은 최소 넷입니다.

1. **X → Y**: 정말 X 가 Y 의 원인 (광고 → 매출)
2. **Y → X**: 거꾸로 (매출 좋은 달에 광고 예산을 늘렸다)
3. **Z → X, Z → Y**: 교란변수 (성수기가 광고와 매출 둘 다 올렸다)
4. **우연**: 데이터가 적으면 아무 관계 없는 값들도 곧잘 같이 움직입니다

분석가의 일은 상관을 발견하는 것이 아니라, 네 가지 중 무엇인지 **소거**
하는 것입니다.

### 3.3 교란변수 통제 — 층별로 나눠 보기

교란변수를 의심하는 가장 쉬운 방법은 **층화(stratification)**입니다.
교란변수 값이 비슷한 그룹 안에서만 상관을 다시 계산해 보는 것입니다.
"더운 날만 모아 보면" 아이스크림과 익사의 상관은 사라집니다. 실습에서
이것을 코드로 재현합니다. 층 안에서 상관이 사라지면 원래 상관은
교란변수의 작품이었을 가능성이 큽니다.

### 3.4 인과를 확인하는 정공법 — 실험

관찰 데이터만으로 인과를 확정하기는 매우 어렵습니다. 정공법은 **무작위
실험**입니다. 동전 던지기로 광고를 트는 지역과 안 트는 지역을 나누면,
성수기든 소득이든 모든 교란변수가 양쪽에 골고루 섞여 상쇄됩니다. 이것이
바로 level10 에서 배울 A/B 테스트이며, "상관→인과" 문제의 실무적
종착지입니다.

실습은 2부로 구성됩니다.

**1부 — 진짜 상관 관찰**: `hjh_data` 매출에서 일별 광고비와 매출의
피어슨 상관계수를 numpy(`np.corrcoef`)로 계산하고, 산점도
`outputs/ad_revenue.png` 를 저장합니다.

**2부 — 가짜 상관 제조와 해체**: 교란변수 실험을 합성 데이터로 직접
만듭니다.

- [3] "더위 지수"(교란변수 Z)를 만들고, 아이스크림 판매 X = Z + 잡음,
  물놀이 사고 Y = Z + 잡음으로 생성합니다. X 와 Y 는 서로를 전혀
  참조하지 않는데도 r ≈ 0.7 의 강한 상관이 나옵니다.
- [4] **층화 실험**: 더위 지수를 5개 구간으로 나누고, 각 구간 안에서 X·Y
  상관을 다시 계산합니다. 구간 내부에서는 상관이 0 근처로 무너지는 것을
  확인합니다.
- [5] `outputs/confounder.png`: 왼쪽은 전체 산점도(강한 상관처럼 보임),
  오른쪽은 더위 구간별로 색을 칠한 산점도(색 덩어리 안에서는 무질서함).

출력의 핵심 비교는 "전체 r = 0.7 대 구간 내 평균 r ≈ 0"입니다. 같은
데이터에서 상관이 나타났다 사라지는 이 순간이, 이 레벨이 가르치려는 전부
입니다.

## 6. 자주 하는 실수

- **r 이 크니 인과라고 결론**: r = 0.9 여도 3.2의 네 경로 중 어느 것인지는
  r 이 말해 주지 않습니다. 상관의 세기와 인과의 증거는 별개입니다.
- **산점도 없이 상관계수만 보기**: U자 관계, 극단값 하나가 만든 가짜 상관
  등은 산점도에서만 보입니다. "숫자 먼저, 그림 생략"은 금물입니다.
- **상관 없음 = 관계 없음**: r ≈ 0 은 "직선 관계가 없다"일 뿐입니다.
  곡선 관계는 얼마든지 있을 수 있습니다.
- **거꾸로 인과 무시**: "리뷰 많은 상품이 잘 팔린다"는 잘 팔려서 리뷰가
  많아진 것일 수 있습니다. 시간 순서(무엇이 먼저인가)를 따져 보세요.
- **교란변수를 하나 통제하고 안심**: 층화로 하나를 제거해도 또 다른
  교란변수가 남아 있을 수 있습니다. 관찰 데이터의 결론은 항상 잠정적
  입니다.
