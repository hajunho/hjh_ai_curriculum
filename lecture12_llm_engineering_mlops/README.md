# Lecture 12 — LLM 엔지니어링과 MLOps

> ChatGPT 같은 거대 언어모델이 "만들어지는 전 과정"을 미니어처로 직접 재현합니다.
> 토크나이저 제작부터 사전학습·SFT·DPO·양자화·서빙·모니터링까지 — 이 커리큘럼의 정점이자,
> "LLM을 쓰는 사람"에서 "만드는 과정을 이해하는 사람"으로 넘어가는 강의입니다.

## 이 강의에서 배우는 것

- 대형 언어모델(LLM)이 공장에서 제품 나오듯 만들어지는 전체 파이프라인: 사전학습 → 어닐링 → SFT → 선호정렬 → 양자화 → 배포
- BPE 토크나이저, 데이터 패킹, 중복 제거·오염 검사 등 "데이터 공장"의 실제 작업
- 2층짜리 미니 GPT를 직접 학습시키며 "다음 토큰 예측만으로 문법이 생기는" 순간을 목격하기
- 스케일링 법칙으로 "이 모델 학습에 얼마가 드는가"를 견적 내는 감각
- LoRA·SFT·DPO를 외부 라이브러리 없이 밑바닥부터 구현하며 원리 이해
- int8 양자화, HTTP 추론 서버, 드리프트 모니터링 — 모델이 서비스가 되어 운영되는 과정
- 비전공자가 AI 인재로 성장하는 현실적인 커리어 로드맵 (커리큘럼 마무리)

실제 대형 학습(수십억~수조 토큰, 수천 장의 GPU)의 각 단계를 **수만~수십만 파라미터짜리 미니 모델**로
축소 재현합니다. 모든 레벨은 노트북 CPU에서 90초 이내에 학습이 끝나도록 설계했습니다.
transformers 같은 라이브러리를 쓰지 않고 전부 직접 구현하기 때문에, 블랙박스가 아니라
"손에 잡히는 기계"로서 LLM을 이해하게 됩니다.

## 이 강의가 실무에서 쓰이는 장면

- **AI 도입 의사결정 회의**: "우리가 직접 만들까, 파인튜닝할까, API를 쓸까"를 단계별 비용 감각으로 판단 (level00, 05)
- **외부 업체·AI팀과의 협업**: "LoRA로 파인튜닝했고 int4로 서빙합니다"라는 보고를 알아듣고 올바른 질문 던지기 (level06, 09)
- **사내 데이터로 모델 맞춤화**: 우리 회사 문서·말투를 가르치는 파인튜닝 프로젝트의 데이터 준비와 품질 관리 (level02, 03, 07)
- **AI 서비스 운영**: 응답 지연·비용·품질 드리프트를 대시보드로 감시하고 이상을 조기에 잡기 (level10, 11)
- **보안·컴플라이언스 검토**: 학습 데이터 오염, 개인정보 로그, API 키 관리 같은 위험 요소를 점검 (level03, 11)
- **채용·커리어 전환**: LLM 엔지니어링 직무 공고의 용어(사전학습, RLHF/DPO, 양자화, 서빙)를 자기 언어로 설명 (전 레벨)

## 진행 팁

- 레벨 순서대로 진행하는 것을 권장합니다. 이 강의는 하나의 "모델 공장 견학" 코스로 설계되어,
  level01~03에서 재료(데이터)를 준비하고, level04에서 모델을 굽고, level06~08에서 다듬고,
  level09~11에서 포장·출하·사후관리합니다.
- 모든 레벨은 `main.py`를 직접 실행하면서 읽도록 설계되어 있습니다. 실행: 저장소 루트의 가상환경으로
  `python3 main.py` (환경 설정은 루트 `SETUP.md` 참고)
- 학습 데이터는 `common/hjh_data.py`의 미니 한국어 코퍼스를 사용하므로 인터넷 연결이 필요 없습니다.
- 미니 모델의 생성 결과는 어색한 문장이 정상입니다. 핵심은 "점점 나아지는 과정"을 관찰하는 것이지,
  ChatGPT 수준의 품질이 아닙니다. 실제 모델과의 차이는 각 레벨 노트에서 숫자로 짚어 드립니다.
