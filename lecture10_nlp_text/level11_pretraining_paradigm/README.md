# Lecture 10 · Level 11 — 사전학습 패러다임: BERT 와 GPT

> "빈칸 채우기"와 "이어쓰기" 두 과제를 미니 모델로 대비하고, 사전학습→미세조정이 왜 세상을 바꿨는지 정리합니다.
**난이도** ⭐⭐⭐⭐ / **선행** level10 / **예상 시간** 55분

## 1. 왜 배우나 — 비즈니스 관점

2018년 이전의 NLP 프로젝트는 과제마다 처음부터였습니다. 감성 분석 모델 따로,
검색 모델 따로, 각각 수만 건의 라벨 데이터를 만들어 각각 학습. 라벨링 비용이
프로젝트의 발목을 잡았습니다.

사전학습(pre-training) 패러다임이 이것을 뒤집었습니다. **라벨이 필요 없는
과제**(빈칸 채우기, 이어쓰기)로 인터넷 규모의 텍스트에서 언어 능력을 먼저
배워 두고, 각 업무에는 소량의 데이터로 미세조정(fine-tuning)만 하는 방식.
"신입을 매번 백지에서 뽑아 가르치기"에서 "언어와 상식을 갖춘 경력자를 뽑아
직무 교육만 하기"로의 전환입니다. 오늘날 LLM 도입 의사결정 — 파인튜닝을
할지, 프롬프트만으로 할지, 어떤 모델 계열을 쓸지 — 는 전부 이 패러다임 위의
선택지들입니다. 큰 그림을 알면 선택이 쉬워집니다.

## 2. 비유로 이해하기

두 가지 공부법을 비교해 봅시다.

- **BERT 의 공부법 — 빈칸 채우기 문제집**: "출장 경비는 [빈칸] 승인을 받아
  정산한다"에서 빈칸을 맞히려면 앞뒤를 **모두** 읽어야 합니다. 문장 전체를
  깊이 이해하는 독해력이 길러집니다. 대신 이 학생에게 "작문해 봐"라고 하면
  난감해합니다 — 빈칸만 채워 봤지 글을 이어 써 본 적이 없으니까요.
- **GPT 의 공부법 — 이어쓰기 훈련**: "출장 경비는 사전..." 다음을 계속 쓰는
  훈련. 앞만 보고 다음을 예측하므로 **작문(생성)이 본업**입니다. 게다가
  이어쓰기를 아주 잘하려면 결국 독해도 필요해서, 규모를 키우자 이해 능력까지
  따라왔습니다.

공통점이 본질입니다: 두 공부법 모두 **문제집을 사람이 만들 필요가 없습니다**.
아무 텍스트나 가져와 가리거나 자르면 문제가 됩니다. 그래서 인터넷 전체가
공짜 문제집이 되었고, "데이터 라벨링"이라는 병목이 사라졌습니다. 이것이
자기지도학습(self-supervised learning)입니다.

## 3. 핵심 개념

### 3-1. 두 과제의 정확한 정의

- **마스크 언어모델(MLM, BERT 방식)**: 문장의 일부 토큰(원 논문은 15%)을
  `[MASK]` 로 가리고 원래 토큰을 맞힙니다. 어텐션은 양방향 — 빈칸의 앞뒤를
  모두 봅니다 (level09 의 인코더).
- **인과 언어모델(CLM, GPT 방식)**: 각 위치에서 다음 토큰을 맞힙니다.
  인과 마스크로 앞쪽만 봅니다 (level10 에서 직접 만든 그것).

같은 트랜스포머 부품에서 마스크 방향과 과제만 다릅니다. 그 작은 차이가
"이해 특화"와 "생성 특화"라는 다른 성격을 만듭니다.

### 3-2. 사전학습 → 미세조정 → (요즘은) 프롬프트

- **1단계 사전학습**: 대규모 무라벨 텍스트로 언어 능력 획득. 비용은 크지만
  한 번만, 만든 쪽이 부담합니다.
- **2단계 미세조정**: 사전학습 모델에 소량의 라벨 데이터로 특정 업무를 가르침.
  수만 건이 필요하던 일이 수백 건으로 줄었습니다.
- **3단계 (LLM 시대) 프롬프트/문맥 학습**: 모델이 충분히 커지자 가중치를
  바꾸지 않고 지시문과 예시만으로 새 과제를 수행하는 능력이 나타났습니다.
  lecture11 에서 본격적으로 다룹니다.

### 3-3. 왜 세상이 바뀌었나 — 세 가지 이유

1. **라벨 병목 소멸**: 데이터 라벨링이 최대 비용이던 시대가 끝났습니다.
2. **전이(transfer)**: 한 번 배운 언어 능력이 번역·요약·분류·질의응답 등
   모든 과제로 이전됩니다. 과제별 모델 → 범용 기반 모델(foundation model).
3. **스케일 법칙**: 데이터·모델·계산을 키울수록 성능이 예측 가능하게 오르고,
   어느 규모부터 학습시키지 않은 능력(추론, 지시 따르기)까지 나타났습니다.
   "더 크게"가 연구 전략이 된 이유입니다.

### 3-4. 어떤 방식이 이겼나 — 그리고 남은 것

생성이 되는 쪽이 인터페이스 혁명(챗봇)을 일으키면서 GPT 방식이 대세가
됐습니다. 하지만 BERT 방식은 죽지 않았습니다 — 검색·분류·임베딩 생성처럼
"이해"가 목적인 곳에서는 양방향 인코더 계열이 여전히 표준입니다. lecture11
의 RAG 에서 문서 임베딩을 만드는 모델이 바로 그 후예들입니다. "생성은
디코더, 이해·검색은 인코더"로 기억하면 실무 지형이 대강 맞습니다.

## 4. 실습 — main.py

실행:

```bash
python3 main.py
```

같은 크기의 미니 트랜스포머 두 개를 tiny_corpus 로 각각 다른 과제에
학습시켜 성격 차이를 시연합니다. 두 학습 합쳐 CPU 30초 이내입니다.

- **[1] 문제 출제기**: 같은 문장에서 MLM 문제(15% 가림)와 CLM 문제(한 글자
  밀기)가 각각 어떻게 만들어지는지 예시를 출력합니다 — "라벨 없이 문제가
  생긴다"를 눈으로 확인합니다.
- **[2] 두 모델 학습**: 인코더(양방향)+MLM, 디코더(인과)+CLM 을 각각 300
  스텝 학습하며 loss 를 출력합니다.
- **[3] 빈칸 채우기 시험**: "어제 [MASK]이 보고서를 만들었다" 류의 문제를
  두 모델에게 풀립니다. BERT 방식이 뒤 문맥까지 활용해 잘 맞히는 것을
  확인합니다.
- **[4] 이어쓰기 시험**: "주말에 " 이어쓰기를 두 모델에게 시킵니다. GPT
  방식은 문장을 생성하지만, BERT 방식은 이어쓰기용 확률을 배운 적이 없어
  어색한 출력을 냅니다.
- **[5] 미세조정 맛보기**: 사전학습된 디코더의 표현 위에 소형 분류 헤드를
  올려 소량(60건)의 리뷰 감성 분류를 학습, 무사전학습 대비 정확도를
  비교합니다. "사전학습이 밑천"임을 숫자로 확인합니다.

## 6. 자주 하는 실수

- **BERT/GPT 를 회사 이름처럼 암기**: 본질은 "양방향+빈칸" vs "단방향+이어
  쓰기"라는 과제 설계의 차이입니다. 이름이 아니라 과제를 기억하세요.
- **미니 실험의 수치를 일반화**: 오늘 숫자는 원리 시연입니다. 실제 격차와
  능력은 수만 배 규모에서 나타납니다.
- **"사전학습 = 우리 회사도 해야 하는 것"으로 오해**: 사전학습은 모델
  제공사의 일입니다. 대부분 기업의 선택지는 프롬프트 활용 또는 미세조정입니다.
- **생성 모델에게 이해 과제, 이해 모델에게 생성 과제**: 검색 임베딩에 생성
  LLM 을, 챗봇에 인코더를 쓰는 미스매치는 비용·품질 모두 손해입니다.
