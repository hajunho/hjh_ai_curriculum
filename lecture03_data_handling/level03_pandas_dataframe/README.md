## 1. 왜 배우나 — 비즈니스 관점

실무 데이터 분석의 표준 도구는 판다스(Pandas)입니다. 매출 CSV를 열고, 필터를 걸고, 지점별로 집계하고, 보고서용 표를 만드는 일의 시작과 끝에 모두 DataFrame이 있습니다. 앞으로 이 강의의 모든 레벨(불러오기, 정제, 집계, 병합, 시계열, 피벗)은 전부 DataFrame 위에서 벌어집니다. 즉, 이번 레벨은 "앞으로 쓸 작업대를 조립하는 시간"입니다.

DataFrame을 모르는 채로 다음 레벨의 코드를 보면 `df.loc`, `df.dtypes`, `df["revenue"]` 같은 표현이 암호처럼 느껴집니다. 반대로 구조를 한 번 제대로 이해하면, 처음 보는 판다스 기능도 "아, 결국 행과 열에 이름표가 붙은 표를 다루는 거구나"라고 유추할 수 있게 됩니다. 채용 공고에서 "Pandas 활용 가능자 우대"라는 문구가 뜻하는 최소 조건이 바로 이번 레벨의 내용입니다.

## 2. 비유로 이해하기

엑셀 통합 문서를 떠올려 보세요.

- **시리즈(Series)** 는 엑셀의 **한 열**입니다. 예를 들어 "매출" 열 하나를 뚝 떼어낸 것인데, 중요한 차이가 하나 있습니다. 값마다 **행 이름표(index)** 가 함께 붙어 다닌다는 점입니다. 엑셀에서 D열을 복사하면 "3번째 행 값"이라는 위치 정보가 사라지지만, Series는 이름표를 끝까지 들고 다닙니다.
- **데이터프레임(DataFrame)** 은 여러 Series를 옆으로 나란히 붙인 **시트 한 장**입니다. 모든 열이 같은 행 이름표(index)를 공유하고, 각 열에는 열 이름(columns)이 붙어 있습니다.

또 하나의 비유는 **서류철**입니다. DataFrame은 견출지(열 이름)가 붙은 서류철 묶음이고, 각 서류(행)에는 접수 번호(index)가 찍혀 있습니다. "매출 서류철에서 접수 번호 100번을 보여줘"라고 말할 수 있는 것은 이름표 체계 덕분입니다. 엑셀은 눈으로 보고 마우스로 가리키지만, 판다스는 이름표로 말합니다. 이 차이가 자동화를 가능하게 합니다.

## 3. 핵심 개념

### 3.1 Series — 이름표 달린 1차원 값 묶음

```python
s = pd.Series([310, 250, 480], index=["강남점", "홍대점", "부산점"])
s["부산점"]   # 480
```

Series는 NumPy 배열에 index라는 이름표를 입힌 것입니다. 그래서 NumPy처럼 `s.mean()`, `s * 1.1` 같은 벡터화 연산이 그대로 되면서, 동시에 `s["부산점"]`처럼 이름으로 값을 부를 수 있습니다.

### 3.2 DataFrame — Series의 묶음

DataFrame의 3요소는 다음과 같습니다.

| 요소 | 엑셀 대응 | 확인 방법 |
|---|---|---|
| 값(values) | 셀에 적힌 내용 | `df.values` |
| 행 이름표(index) | 행 번호 1, 2, 3... | `df.index` |
| 열 이름(columns) | 머리글 행 | `df.columns` |

`df["revenue"]`처럼 열 이름으로 꺼내면 그 열이 Series로 나옵니다. 즉 "DataFrame에서 열 하나를 꺼내면 Series, Series를 여러 개 모으면 DataFrame"이라는 왕복 관계를 기억하세요.

### 3.3 dtype — 열마다 하나의 자료형

각 열은 자료형(dtype)을 하나씩 가집니다. 숫자 열은 `int64`나 `float64`, 문자 열은 최신 판다스에서는 `str`, 구버전에서는 `object`로 표시됩니다. 여기서 실무적으로 중요한 사실 하나: **숫자 열에 결측치(NaN)가 섞이면 정수여도 float64가 됩니다.** 매출액이 `758123.0`처럼 소수점을 달고 나오면 "어딘가 빈 값이 있구나"라고 의심하는 습관을 들이세요.

### 3.4 첫인사 4종 세트 — head / info / describe / shape

처음 보는 데이터를 받으면 항상 이 순서로 인사를 나눕니다.

1. `df.shape` — 몇 행 몇 열인가 (규모 파악)
2. `df.head()` — 앞 5행 미리보기 (생김새 파악)
3. `df.info()` — 열별 dtype과 결측 아닌 값의 개수 (건강 검진)
4. `df.describe()` — 숫자 열의 평균·표준편차·최소·최대 (분포 훑기)

특히 `describe()`의 min에 음수가 보이거나 max가 비정상적으로 크면 이상치(outlier)의 신호입니다.

### 3.5 새 열 만들기

```python
df["roas"] = df["revenue"] / df["ad_cost"]
```

엑셀에서 E열에 `=C2/D2`를 입력하고 아래로 드래그하던 작업이 한 줄로 끝납니다. 벡터화 연산이라 행이 10만 개여도 순식간입니다.

### 3.6 범주 세어 보기 — value_counts

문자 열의 구성비를 볼 때는 `df["store"].value_counts()`를 씁니다. 엑셀에서 COUNTIF를 지점 수만큼 반복하던 일이 한 줄입니다.

## 6. 자주 하는 실수

- **`df["revenue"]`와 `df[["revenue"]]`를 혼동** — 대괄호 한 겹은 Series, 두 겹은 열이 1개인 DataFrame입니다. 뒤에 붙일 수 있는 기능이 서로 다릅니다.
- **describe()만 보고 안심** — describe는 숫자 열만 요약합니다. 문자 열의 오타("강남점 " 같은 공백 포함)는 value_counts로 따로 확인해야 합니다.
- **dtype을 확인하지 않고 계산** — 숫자처럼 보여도 dtype이 object(문자)면 합계가 문자열 이어붙이기가 되거나 오류가 납니다. 계산 전 `df.dtypes` 확인은 필수입니다.
- **info() 결과를 변수에 담으려는 시도** — `info()`는 화면에 출력만 하고 None을 반환합니다. 값이 필요하면 `df.dtypes`, `df.isna().sum()`을 쓰세요.
