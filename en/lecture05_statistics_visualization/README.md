# Lecture 05 — Statistics and Data Visualization

This lecture is about *summarizing* numbers, using *pictures* to reveal what
those summaries hide, and finally judging whether a difference is *real or
just luck*. If you have ever clicked AVERAGE in Excel, you are already halfway
there. The other half — knowing when *not* to trust that average — is what you
will learn here.

## What you will learn

- How summary statistics (mean, median, variance) compress data, and the traps they set
- How to turn data into pictures with distributions, histograms, and Matplotlib
- An eye for telling honest charts apart from charts designed to mislead
- Correlation vs causation, probability, the normal distribution, and the Central Limit Theorem
- How to estimate a whole population from a sample: confidence intervals, hypothesis tests, p-values
- The crown jewel of business practice: designing and interpreting A/B tests, and reporting uncertainty with Bayesian thinking

## Where this lecture shows up at work

- **Monthly reporting**: behind a sentence like "average revenue up 12%" there
  may be a single extreme value hiding — you check with the median and the
  distribution (level01–02).
- **Executive decks**: you avoid inflating results with truncated bar-chart
  axes, and you see through distorted charts other people make (level03–04).
- **Marketing analysis**: you test whether "we raised ad spend and revenue
  went up" is causation, or just the peak season acting as a confounder
  (level05).
- **New product / UI redesign decisions**: you design an A/B test and
  understand why sneaking early looks at the results (peeking) is dangerous
  (level09–10).
- **Reporting uncertainty**: instead of "it works / it doesn't", you say
  "there is a 92% probability that option B is better" — language executives
  can actually decide on (level08, 11).

## How to run

Run each level from inside its folder, using the repository's virtual environment.

```bash
cd lecture05_statistics_visualization/level00_summarizing_reality
python3 main.py
```

Levels that draw charts save PNG files into an `outputs/` folder next to the
script, and the paths are printed to the screen. All data is generated by
`common/hjh_data.py` or inside the code itself, so no internet connection is
needed. (Amounts in the practice data are in Korean won, KRW.)
