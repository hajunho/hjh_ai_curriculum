# Glossary — IT and AI terms for non-technical readers

When a term stops you mid-lecture, look it up here. Each entry gives the
analogy first, then the definition.

| Term | Analogy | Definition |
|---|---|---|
| Algorithm | A cooking recipe | A step-by-step procedure for solving a problem |
| Variable | A labeled box | A storage space that holds a value |
| Function | A one-page work manual | A bundle of code that takes input, does a fixed job, and returns a result |
| Library / package | A specialist department | A collection of features someone else built; you just use it |
| API | A restaurant's order counter | The window through which programs make requests and get responses in an agreed format |
| Terminal / CLI | Steering your computer by text chat | A screen where you control the computer with typed commands instead of a mouse |
| Virtual environment | A toolbox dedicated to one project | A separate space of Python packages for each project |
| Git | A time-travel logbook for documents | A tool that records and restores the history of code changes |
| Database (DB) | A giant ledger archive | A system that stores and retrieves data in a structured way |
| SQL | A request form for the ledger clerk | The standard language for asking a database questions |
| Missing value | A blank on a survey form | A data point where the value is simply absent |
| Outlier | A suspicious number in the books | A value far outside the normal range |
| Feature | An item of evidence for a decision | A variable used as input to a model |
| Label | The answer key | The answer the model is supposed to get right |
| Training | Onboarding a new hire | The process of adjusting a model's internal numbers using data |
| Overfitting | The student who memorized only past exams | A model that nails the training data but fails on new data |
| Accuracy / precision / recall | The kinds of misdiagnosis in a health check | Metrics that measure classification performance from different angles |
| Gradient descent | Walking down a mountain in the fog | An optimization that keeps stepping in the direction where the error shrinks |
| Neural network | A calculating web that mimics neurons | A model built by stacking simple computing units in layers |
| Epoch | One full pass through the workbook | One complete run through the entire training dataset |
| Batch | A stack of answer sheets graded at once | The bundle of data used for a single model update |
| CNN | Scanning with a magnifying glass | A neural network that sweeps a small window across an image to extract features |
| Token | A word flashcard | The smallest unit of text a model works with |
| Embedding | Coordinates for a word | Meaning expressed as a vector of numbers |
| Transformer | Everyone in the meeting reading the room | A neural architecture that uses attention to see the whole context at once |
| LLM | A colossal sentence-completion machine | A large language model pre-trained on vast amounts of text |
| Prompt | A written work order | The instruction text you give to an LLM |
| RAG | An open-book exam | A technique where the model answers while looking at retrieved reference documents |
| Vector DB | A library you search by meaning | A database that retrieves by embedding similarity |
| Fine-tuning | Job training for an experienced hire | Additional training that adapts a pre-trained model to a specific task |
| SFT | Copying out model answers | Supervised fine-tuning on instruction–response examples |
| DPO | Picking the better of two answers | Aligning a model's taste using pairs of preferred and rejected responses |
| Quantization | Compressing HD video to "good enough" quality | Lowering the precision of a model's numbers to shrink it and speed it up |
| GPU | An army of part-timers who only do arithmetic | A processor specialized for massively parallel computation |
| Hallucination | Confident nonsense | An LLM generating plausible-sounding falsehoods |
| MLOps | Running the model factory | The practice of deploying, monitoring, and operating models |
