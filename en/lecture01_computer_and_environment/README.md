# Lecture 01 — Computers and the Development Environment

> Before you write a single line of code, you need a working environment — and this
> lecture is where you build it. From how a computer actually works, through the
> terminal, installing Python, Git, Docker, and cloud GPUs — every bit of base
> fitness you need for learning AI starts here.

## What you will learn in this lecture

- A working intuition for what a computer (CPU, memory, storage) actually does
- The developer's native tongue: files, folders, paths, and terminal commands
- Setting up your hands-on toolkit: Python, virtual environments, editors, Jupyter
- Keeping your work safe and collaborating with Git and GitHub
- Real-world environment sense: environment variables, secrets, Docker, cloud GPUs

## Prerequisites

None. This is the very first lecture of the curriculum. If you have ever worked
with Excel, you have all the computer experience you need.

## Fast track (if you are short on time)

1. **level02 First Steps in the Terminal** — every hands-on exercise in the rest of the curriculum starts in the terminal.
2. **level03 Installing Python and Running It for the First Time** — the moment you type `python3 main.py` yourself is the real starting line.
3. **level04 Virtual Environments and Package Management** — half of all "but it works on my machine" incidents at work are prevented right here.
4. **level06 Git basics** — the minimum safety net that keeps you from ever losing your work.
5. **level09 Environment Variables and Secrets** — the habits that prevent API-key leaks have to be built from day one.

## Where this lecture shows up at work

- **The first step toward report automation**: the colleague who finishes the weekly file-sorting-and-renaming chore with a single script is someone who understood level08 of this lecture.
- **Preventing collaboration disasters**: manage documents with Git commit history instead of "final_REALfinal_edit2.xlsx", and you can find who changed what, and when, in under a minute.
- **Passing security audits**: the habit of never hard-coding secrets into code (level09) is the very first item checked in internal security reviews and external audits.
- **AI project budget meetings**: once you know why GPU cloud costs are billed by the hour (level11), you can hold your own in budget discussions with the engineering team.

## How to do the exercises

One line in each level folder is all it takes. No internet connection and no API keys required.

```bash
python3 main.py
```
