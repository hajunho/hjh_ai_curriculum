# Environment Setup Guide (SETUP)

The entire curriculum runs on an **ordinary laptop without a GPU** (Mac or Windows).

## 1. Check that Python is installed

In your terminal (Mac: the Terminal app, Windows: PowerShell):

```bash
python3 --version   # 3.10 or newer is fine (on Windows: python --version)
```

If it is missing, install it from https://www.python.org/downloads/.
lecture01/level03 walks through the process step by step, with pictures.

## 2. Get the repository and create a virtual environment

The English edition lives in the `en/` folder, so work from there:

```bash
git clone https://github.com/hajunho/hjh_ai_curriculum.git
cd hjh_ai_curriculum/en

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r ../requirements.txt
```

When `(.venv)` appears in front of your prompt, it worked. You will learn what
a virtual environment actually is in lecture01/level04. For now, just think of
it as "a toolbox dedicated to this project".

## 3. Verify everything works

```bash
python3 common/hjh_data.py
```

If you see "All generators working correctly.", you are ready to go.

## 4. How to run the lectures

Every level works the same way.

```bash
cd lecture06_machine_learning_basics/level03_linear_regression
cat README.md      # read the lecture notes (reading them on GitHub is fine too)
python3 main.py    # run the hands-on exercise
```

## 5. Frequently asked questions

- **Do I need internet access?** Not after installation. The practice data is
  generated by the code itself.
- **Do I need a GPU?** No. Even the deep learning lectures are designed small
  enough to finish on a CPU within a few minutes.
- **Do I need an LLM API key?** A few levels in lecture11 are nicer with a key,
  but every level includes an offline mode that works without one.
- **I'm getting an error.** Check the "Common mistakes" section at the bottom
  of each level's README first.
