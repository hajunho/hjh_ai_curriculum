# hjh AI Curriculum — The Complete AI Course for Business Professionals

> **From "I only use Excel" to machine learning, deep learning, and LLM engineering.**
> A hands-on curriculum of 12 lectures and 144 levels, designed to turn business
> professionals with no IT background into people who understand AI and can
> work with it directly.

- **Author**: Junho Ha (hajunho) · ZeliDesk / Dept. of EdTech
- **License**: MIT — every lecture note and every line of code is original work,
  written from scratch for this curriculum. No external textbooks or datasets were
  copied, and all practice data is generated by code.
- **Language**: This is the **English edition**; the Korean original lives at the
  repository root. The lectures are in English, code identifiers are in English,
  and the practice data keeps its Korean-won (KRW) amounts, exactly as in the original.

---

## What makes this curriculum different

1. **Analogies first, math later** — every concept is introduced through a
   workplace or everyday analogy before any formula appears.
2. **No installation hell** — the practice data is generated by the code itself,
   so there is nothing to download, and the entire course runs on a laptop
   without a GPU.
3. **Learn through business problems** — sales forecasting, customer churn,
   fraud detection, an internal-documents chatbot: the exercises are the
   problems you actually meet at work.
4. **From-scratch implementations included** — you will build a perceptron,
   backpropagation, a tokenizer, and even a mini GPT with your own hands,
   opening up the "black box".

## Overall structure

There are 12 lectures (lecture01–12), each made up of 12 levels (level00–11).
level00 is a complete-beginner introduction (analogies and concepts);
level11 goes deep into professional practice.

## How to study

1. Set up your Python environment following `SETUP.md` (30 minutes).
2. In each level folder: read the `README.md` → run `main.py` → do the exercises.
3. One level takes 30–90 minutes. At 5 levels per week you finish in
   **about 7 months**.
4. Going in order is the standard path, but each lecture README also points out
   a "fast track".

```bash
git clone https://github.com/hajunho/hjh_ai_curriculum.git
cd hjh_ai_curriculum/en
python3 -m venv .venv && source .venv/bin/activate
pip install -r ../requirements.txt
python3 lecture01_computer_and_environment/level00_what_computers_do/main.py
```
