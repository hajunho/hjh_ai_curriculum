# Lecture 12 — LLM エンジニアリングと MLOps

> ChatGPT のような巨大言語モデルが「作られていく全工程」を、ミニチュアで自分の手で再現します。
> トークナイザーの自作から事前学習・SFT・DPO・量子化・サービング・モニタリングまで — このカリキュラムの頂点であり、
> 「LLM を使う人」から「作られ方を理解している人」へと踏み出す講義です。

## この講義で学ぶこと

- 大規模言語モデル (LLM) が工場から製品が出てくるように作られる全パイプライン: 事前学習 → アニーリング → SFT → 選好アラインメント → 量子化 → デプロイ
- BPE トークナイザー、データパッキング、重複排除・汚染チェックといった「データ工場」の実作業
- 2 層のミニ GPT を自分で学習させ、「次のトークン予測だけで文法が生まれる」瞬間を目撃する
- スケーリング則で「このモデルの学習にいくらかかるのか」を見積もる感覚
- LoRA・SFT・DPO を外部ライブラリなしでゼロから実装し、原理を理解する
- int8 量子化、HTTP 推論サーバー、ドリフト監視 — モデルがサービスになって運用される過程
- 非専攻の社会人が AI 人材へ成長していく現実的なキャリアロードマップ (カリキュラムの締め)

実際の大規模学習 (数十億〜数兆トークン、数千枚の GPU) の各段階を **数万〜数十万パラメータのミニモデル** に
縮小して再現します。すべてのレベルはノートパソコンの CPU で 90 秒以内に学習が終わるよう設計してあります。
transformers のようなライブラリを使わず全部自分で実装するので、ブラックボックスではなく
「手で触れる機械」として LLM を理解できるようになります。

## 前提となる講義

- **lecture08 — ディープラーニング基礎** (テンソル、勾配降下法、学習ループが読めること)
- **lecture10 — 自然言語処理 (NLP)** (トークン、埋め込み、アテンションの概念)
- **lecture11 — LLM 活用と RAG** (プロンプトや LLM API を使った経験があると「作る側」の話が一気に生きてきます)

level00・05・11 のようにコードより概念が中心のレベルは、前提知識が足りなくても読み進められます。

## 時短コース (時間がなければこの 5 つだけ)

1. **level00** — 全体マップ: どんな工程を経てモデルが生まれるのか、まず大枠から
2. **level04** — ミニ GPT の事前学習: この講義の心臓部。手作りのモデルが文を覚える瞬間
3. **level05** — スケーリング則: 「GPT を作るにはいくらかかるのか」に数字で答える
4. **level07** — SFT: 続きを書く機械が「秘書」に変わる決定的な工程
5. **level09** — 量子化: 会社のノートパソコンでも LLM が動く理由

## この講義が実務で活きる場面

- **AI 導入の意思決定会議**: 「自分たちで作るのか、ファインチューニングするのか、API を使うのか」を工程別のコスト感覚で判断する (level00, 05)
- **外部ベンダー・AI チームとの協業**: 「LoRA でファインチューニングして int4 でサービングしています」という報告を聞き取り、正しい質問を返す (level06, 09)
- **社内データでモデルをカスタマイズ**: 自社の文書や言い回しを教えるファインチューニング案件のデータ準備と品質管理 (level02, 03, 07)
- **AI サービスの運用**: 応答遅延・コスト・品質ドリフトをダッシュボードで監視し、異常を早期に捕まえる (level10, 11)
- **セキュリティ・コンプライアンス審査**: 学習データの汚染、個人情報のログ、API キー管理といったリスク要因を点検する (level03, 11)
- **採用・キャリアチェンジ**: LLM エンジニアリング職の求人票に並ぶ用語 (事前学習、RLHF/DPO、量子化、サービング) を自分の言葉で説明する (全レベル)

## 進め方のヒント

- レベル順に進めることをおすすめします。この講義は一つの「モデル工場見学」コースとして設計されていて、
  level01〜03 で材料 (データ) を仕込み、level04 でモデルを焼き、level06〜08 で仕上げ、
  level09〜11 で梱包・出荷・アフターケアをします。
- すべてのレベルは `main.py` を実際に走らせながら読む前提です。実行はリポジトリルートの仮想環境で
  `python3 main.py` (環境構築はルートの `SETUP.md` を参照)
- 学習データは `common/hjh_data.py` のミニ日本語コーパスを使うので、インターネット接続は不要です。
- ミニモデルの生成結果は、ぎこちない文で正常です。大事なのは「だんだん良くなっていく過程」を観察することで、
  ChatGPT 級の品質ではありません。実際のモデルとの差は各レベルのノートで数字で示します。
