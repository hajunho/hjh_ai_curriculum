# 用語集 — 非エンジニアのための IT・AI 用語

講義の途中でつまずいた用語はここで調べてください。たとえ話 → 定義の順で説明します。

| 用語 | たとえ話 | 定義 |
|---|---|---|
| アルゴリズム | 料理のレシピ | 問題を解くための段階的な手順 |
| 変数 | 名前ラベル付きの箱 | 値を入れておく保存場所 |
| 関数 | 業務マニュアル1枚 | 入力を受け取り、決まった仕事をして結果を返すコードのまとまり |
| ライブラリ/パッケージ | 専門部署 | 他の人が作ってくれた機能の詰め合わせ。借りて使えばよい |
| API | レストランの注文カウンター | プログラム同士が決まった形式でリクエストとレスポンスを交わす窓口 |
| ターミナル/CLI | 文字チャットでコンピュータを操縦 | マウスの代わりにコマンドでコンピュータを操作する画面 |
| 仮想環境 | プロジェクト専用の道具箱 | プロジェクトごとに分離された Python パッケージの空間 |
| Git | 文書のタイムトラベル記録帳 | コードの変更履歴を保存・復元するツール |
| データベース (DB) | 超大型の帳簿保管庫 | データを構造的に保存・検索するシステム |
| SQL | 帳簿係に出す依頼書 | DB に質問するための標準言語 |
| 欠損値 | アンケートの空欄 | 値が入っていないデータ |
| 外れ値 | 帳簿の怪しい数字 | 正常な範囲を大きく外れた値 |
| 特徴量 (feature) | 判断材料の項目 | モデルの入力として使う変数 |
| ラベル (label) | 模範解答 | モデルが当てるべき答え |
| 学習 (training) | 新入社員の研修 | データを使ってモデル内部の数値を調整するプロセス |
| 過学習 | 過去問だけを丸暗記した受験生 | 学習データにだけ強く、新しいデータに弱い状態 |
| 正解率/適合率/再現率 | 健康診断の誤診の種類 | 分類の性能を異なる角度から測る指標たち |
| 勾配降下法 | 霧の中で山を下りる | 誤差が減る方向へ少しずつ進む最適化 |
| ニューラルネットワーク | ニューロンを真似た計算の網 | 単純な計算ユニットを層状に積み重ねたモデル |
| エポック (epoch) | 問題集の1周目 | 学習データ全体を一巡した回数 |
| バッチ (batch) | 一度に採点する答案の束 | 1回の更新に使うデータのまとまり |
| CNN | 虫眼鏡でなぞって見る | 画像を小さな窓でなぞりながら特徴を取り出すニューラルネットワーク |
| トークン | 単語カード | モデルが扱うテキストの最小単位 |
| 埋め込み (embedding) | 単語の座標 | 意味を数値ベクトルで表現したもの |
| トランスフォーマー | 会議中にお互い顔色をうかがう | アテンションで文脈を丸ごと見るニューラルネットワーク構造 |
| LLM | 超巨大な文章補完マシン | 膨大なテキストで事前学習された大規模言語モデル |
| プロンプト | 業務指示書 | LLM に与える入力の指示文 |
| RAG | 持ち込み可の試験 | 検索してきた根拠文書を見ながら答えさせる手法 |
| ベクトル DB | 意味で探せる図書館 | 埋め込みの類似度で検索するデータベース |
| ファインチューニング | 中途採用者の職務研修 | 事前学習済みモデルを特定タスク向けに追加学習すること |
| SFT | 模範解答の書き写し | 指示と応答の例で行う教師ありファインチューニング |
| DPO | 2つの答案からより良い方を選ぶ | 選好ペアでモデルの好みをアラインメントする手法 |
| 量子化 | 高画質 → ほどほどの画質に圧縮 | モデルの数値の精度を下げてサイズと速度を改善すること |
| GPU | 計算専門の大人数アルバイト軍団 | 並列計算に特化したプロセッサ |
| ハルシネーション (幻覚) | 自信満々のでたらめ | LLM がもっともらしい嘘を生成する現象 |
| MLOps | モデルの工場運営管理 | モデルのデプロイ・モニタリング・運用の仕組み |
