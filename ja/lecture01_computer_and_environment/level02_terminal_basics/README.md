# Lecture 01 · Level 02 — ターミナルの第一歩

> マウスを使わずキーボードのコマンドだけでコンピュータに仕事をさせる、ターミナルの基本コマンド(pwd、ls、cd、mkdir、cp、mv、rm)を身につけます。

**難易度** ⭐ / **前提** level01 / **想定時間** 40分

## 1. なぜ学ぶのか — ビジネスの視点

これから、このカリキュラムのすべての実習は、ターミナルで `python3 main.py` と入力するところから始まります。開発者と協業するときも、クラウドサーバーに接続するときも、AI ツールをインストールするときも、画面に現れるのはマウスでクリックするボタンではなく、点滅するカーソルひとつです。ターミナルを怖がっていると、その前で毎回立ち止まることになります。

ターミナルが強力な理由は、**言葉で指示した仕事は記録でき、繰り返せるから**です。マウスでフォルダを100個作るには100回のクリックが必要ですが、ターミナルなら1行で済みます。そしてその1行を保存しておけば、来月も、後任者も、まったく同じように実行できます。繰り返し業務の自動化(level08)の出発点がまさにここです。

## 2. たとえ話で理解する

**GUI(グラフィック画面)は身振りで仕事を頼むこと、ターミナルは言葉で仕事を頼むこと**です。

部下に書類整理を頼むとしましょう。身振りでやるなら、自分でキャビネットの前まで歩いて行き「これを、こっちへ」とひとつひとつ指差さなければなりません(マウスのクリック・ドラッグ)。一方、言葉なら「3階のキャビネットの2023年の書類を全部倉庫に移してください」の一文で終わり、同じ指示を文書に残して毎月繰り返させることもできます。

ターミナルのコマンドの構造も、実際の指示の言葉に似ています。

```
cp  report.txt  backup/
動詞    目的語      場所
「コピーして、report.txt を、backup フォルダへ」
```

コマンドが動詞、その後ろに続くものが目的語と修飾語(オプション)です。`ls -l` の `-l` のように `-` で始まるものは、「詳しく」「全部」といった副詞の役割を持つ**オプション(option)**です。

もうひとつ。ターミナルには常に「自分がいま立っている場所」、つまり level01 で学んだ**カレントワーキングディレクトリ(CWD)**があります。すべてのコマンドは、いま立っている部屋を基準に実行されます。だからターミナル作業の第一の習慣は、「自分はいまどこにいる?」を確認することです。

## 3. 核心となる概念

### 3-1. サバイバルコマンド7つ

| コマンド | 意味 | たとえ |
|---|---|---|
| `pwd` | 現在位置を表示 (print working directory) | 「ここは何階の何の部屋?」 |
| `ls` | 現在のフォルダの中身を一覧 (list) | 「この部屋には何がある?」 |
| `cd フォルダ` | 場所を移動 (change directory) | 「その部屋へ移動」 |
| `mkdir フォルダ` | フォルダを作成 (make directory) | 「新しいキャビネットを設置」 |
| `cp 元 先` | コピー (copy) | 「コピーを取ってあちらへ」 |
| `mv 元 先` | 移動または名前の変更 (move) | 「移して。同じ部屋の中なら名札だけ交換」 |
| `rm ファイル` | 削除 (remove) | 「シュレッダーへ。**ごみ箱を経由せず即時**」 |

よく使う組み合わせ: `cd ..`(ひとつ上の階へ)、`cd ~`(自分のホームフォルダへ)、`ls -l`(詳細一覧)、`mkdir -p a/b/c`(途中のフォルダごと一度に)。

### 3-2. Mac と Windows の違い

- **Mac(macOS)**: 標準アプリの「ターミナル」を開くだけです。Linux と同じ系統(Unix)なので、上のコマンドがそのまま通じます。開発サーバーの大半は Linux なので、Mac ユーザーは覚えたことをサーバーでもそのまま使えます。
- **Windows**: 伝統的な「コマンドプロンプト(cmd)」はコマンドが異なります(`ls` の代わりに `dir`、`cp` の代わりに `copy`)。最近は **PowerShell** が `ls`、`cd` など多くをサポートしており、開発用途では **WSL(Windows Subsystem for Linux)** をインストールして Windows の中で Linux のターミナルを使うのが標準的な選択です。このカリキュラムのコマンドは Mac/Linux(WSL 含む)基準です。

| 用途 | Mac/Linux/WSL | Windows cmd |
|---|---|---|
| 一覧 | `ls` | `dir` |
| コピー | `cp` | `copy` |
| 移動 | `mv` | `move` |
| 削除 | `rm` | `del` |
| パスの区切り | `/` | `\` |

### 3-3. シェルという通訳者

ターミナルのウィンドウの中で、実際にコマンドを解釈して実行するプログラムを**シェル(shell)**と呼びます。Mac の標準シェルは zsh、Linux は主に bash です。「ターミナルは窓、シェルはその中で指示を聞き取る通訳者」と覚えておけば大丈夫です。のちに `.sh` ファイル(シェルスクリプト)に出会ったら、それはこの通訳者に渡す指示書の束です。

### 3-4. 危険なコマンドへの警告

`rm` はごみ箱を経由せず、即座に削除します。特に `rm -rf フォルダ` は、フォルダとその中のすべてを取り返しがつかない形で消します。実務では、削除の前に `ls` で対象を先に確認する習慣、そしてワイルドカード(`*.txt` のようなパターン)を使うときにもう一度読み直す習慣が事故を防ぎます。

## 4. 実習 — main.py

```bash
python3 main.py
```

本物のターミナルを操作する前に、Python で作った**ミニシェルシミュレータ**で安全に練習します。スクリプトは一時フォルダの中に小さな練習用オフィスを作り、あらかじめ用意されたシナリオのコマンドを1行ずつ「入力 → 実行 → 結果」で見せてくれます。

- **[1] 練習場の準備**: 一時フォルダにサンプルファイルをいくつか置きます。失敗しても皆さんのコンピュータには一切影響がありません。
- **[2] シナリオの実行**: `pwd → ls → mkdir backup → cp → cd → mv(名前変更) → rm` の順で、実際の業務(報告書のバックアップ・整理)をコマンドで処理します。各コマンドに「何をしたのか」の日本語解説が付きます。
- **[3] 最終状態の確認**: 整理が終わったフォルダ構造を見せ、同じ作業をマウスでやったら何回のクリックだったかを比較します。

核心となるコードは `MiniShell` クラスです。`cwd`(現在位置)を状態として持ちながら、`cmd_ls`、`cmd_cd` のようなメソッドが各コマンドを pathlib で実装しています。つまり、**シェルの仕事とは結局「現在位置を記憶しながらファイルシステムの関数を呼ぶこと」**だと、コードで確認できるわけです。シミュレータで流れをつかんだら、本物のターミナルを開いて同じコマンドを自分で打ってみてください。

## 5. やってみよう

1. **(易しい)** 本物のターミナルを開いて `pwd`、`ls`、`cd Documents`(または存在するフォルダならどこでも)、`cd ..` を順番に打ってみましょう。各コマンドの後に `pwd` で位置がどう変わるか確認してください。*(ヒント: 迷子になったら `cd ~` でホームに戻れます。)*
2. **(普通)** main.py の `SCENARIO` リストに `mkdir archive` と `mv 議事録.txt archive` の2つのコマンドを追加して、議事録が archive フォルダに移動するようにしてみましょう。*(ヒント: 既存のシナリオ項目の形式をそのまま真似れば OK です。)*
3. **(挑戦)** `MiniShell` に `cat ファイル` コマンド(ファイル内容の出力)を追加してみましょう。*(ヒント: `cmd_cat` メソッドを作り `read_text()` を使います。他の `cmd_` メソッドが登録される仕組みを観察してください。)*

## 6. よくあるつまずき

- **現在位置を確認せずにコマンドを実行**: 見当違いのフォルダにファイルを作ったり消したりする事故の主犯です。習慣として `pwd` と `ls` を先に打ちましょう。
- **空白を含む名前をそのまま入力**: `cd My Documents` は「My」と「Documents」という2つの目的語として解釈されます。`cd "My Documents"` のように引用符で囲む必要があります。
- **`rm` をごみ箱と勘違い**: ターミナルの削除は即時かつ永久です。重要なフォルダでは、`rm` の代わりにひとまず `mv` で別の場所へ退避させるのも安全なコツです。
- **コマンドが効かないと慌てる**: 大半は打ち間違い(コマンドはスペルに厳格です)か、Windows の cmd で Mac/Linux のコマンドを打った場合です。エラーメッセージをそのまま読んでみる習慣が、最高の先生です。
