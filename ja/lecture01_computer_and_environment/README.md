# Lecture 01 — コンピュータと開発環境

> コーディングを始める前に必ず整えておくべき「作業環境」を理解し、セットアップする講義です。
> コンピュータが働く仕組みから、ターミナル、Python のインストール、Git、Docker、クラウド GPU まで —
> AI を学ぶためのすべての基礎体力をここで作ります。

## この講義で学ぶこと

- コンピュータ(CPU・メモリ・ストレージ)が実際に何をしているのかの感覚をつかむ
- ファイル・フォルダ・パス、ターミナルコマンドといった開発者の基本言語
- Python のインストール、仮想環境、エディタ・Jupyter など実習ツールのセットアップ
- Git/GitHub で成果物を安全に管理し、共同作業する方法
- 環境変数・シークレットキー・Docker・クラウド GPU など実務環境の感覚

## 前提となる講義

なし。このカリキュラムの最初の講義です。Excel を触ったことがある程度のコンピュータ経験があれば十分です。

## 最短ルート(時間がなければこれだけ)

1. **level02 ターミナルの第一歩** — 以降すべての講義の実習がターミナルから始まります。
2. **level03 Python のインストールと初めての実行** — `python3 main.py` を自分の手で打つ瞬間が出発点です。
3. **level04 仮想環境とパッケージ管理** — 実務での「自分のパソコンでは動くんですけど」というトラブルの半分は、ここで予防できます。
4. **level06 Git の基礎** — 成果物を失わないための最低限の安全装置です。
5. **level09 環境変数とシークレットキー** — API キー流出事故を防ぐ習慣は、最初から身につけるべきです。

## この講義が実務で活きる場面

- **レポート自動化の第一歩**: 毎週繰り返すファイル整理・名前変更をスクリプト1本で終わらせるメンバーは、この講義の level08 を理解した人です。
- **共同作業の事故防止**: 「最終_本当に最終_修正2.xlsx」の代わりに Git のコミット履歴で文書を管理すれば、誰がいつ何を変えたのか1分以内に突き止められます。
- **セキュリティ監査の通過**: コードにシークレットキーをハードコーディングしない習慣(level09)は、社内のセキュリティ点検や外部監査で真っ先に確認される項目です。
- **AI プロジェクトの見積もり会議**: GPU クラウドの費用がなぜ時間単位で請求されるのか(level11)を知っていれば、開発チームとの予算会議で話が通じます。

## 実習のやり方

各レベルのフォルダで、以下の1行だけで動きます。インターネット接続や API キーは一切不要です。

```bash
python3 main.py
```
