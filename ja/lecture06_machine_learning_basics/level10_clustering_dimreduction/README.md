# Lecture 06 · Level 10 — クラスタリングと次元削減

> 正解表なしに顧客を似た者同士のグループに分け (k-means)、複数の変数を 2 次元の地図に圧縮して (PCA) 目で確かめる、教師なし学習の実習です。
**難易度** ⭐⭐⭐⭐ / **前提** level01, level04 / **想定時間** 50分

## 1. なぜ学ぶのか — ビジネスの視点

「うちの顧客はどんな層で構成されているのか?」という質問には、正解ラベルがありません。解約予測のように過去の正解 (解約記録) がある問題ではなく、**構造そのものを発見しなければならない**問題だからです。顧客セグメンテーション (segmentation) はマーケティングの古くからの宿題です — 全顧客に同じ SMS を送る会社と、「価格に敏感な層には割引クーポン、VIP には専用特典、休眠リスク層にはリマインド」を送り分ける会社では、成果が違います。

クラスタリング (clustering) はこのセグメンテーションをデータにやらせる道具であり、次元削減 (dimensionality reduction) は変数が数十個あるデータを、人の目が見られる 2 次元の地図に押しつぶしてくれる道具です。2 つはセットでよく使われます: クラスタリングでグループを作り、次元削減の地図の上に色を塗って「グループが本当に分かれているか」を目で検証する、という使い方です。

## 2. 比喩で理解する

**k-means はフードコートのテーブル配置問題**です。広いホールに客 (データ点) が散らばって座っていて、移動式の案内デスク (中心点) を k 台どこに置くかを決めなければなりません。良い配置とは、すべての客が最寄りのデスクまで歩く距離が全体として短い配置です。k-means のアルゴリズムは単純な反復です。(1) デスクを適当に置く → (2) 各客を最寄りのデスクに割り当てる → (3) 各デスクを自分の客たちの真ん中へ動かす → (2) と (3) を、動かなくなるまで繰り返す。この単純な往復が、客を k 個の自然なまとまりに分けます。

**PCA は影の角度選び**です。手に持った複雑な針金のオブジェ (高次元データ) を、壁に影 (2 次元) として映すとしましょう。角度を選び間違えるとオブジェは 1 本の線に潰れて見え、うまく選べば構造が生きた影が落ちます。PCA (主成分分析) は、**データが最も広く散らばって見える角度** — 情報損失が最も少ない射影の方向 — を数学で見つけてくれる道具です。「第 1 主成分」が最も広く散らばる軸、「第 2 主成分」がその次の軸です。

## 3. 核心概念

### 3.1 k-means を使うときに知っておくこと

- **k は人が決める**: 何グループが「正解」かをデータは教えてくれません。参考の道具としてエルボー (elbow) 法 — k を増やしながら総移動距離 (inertia) を描き、減少が急に折れる地点を探す方法 — を使いますが、最終決定は「そのグループ数でマーケティングのアクションを分けられるか」という業務判断です。
- **標準化は必須**: 距離ベースなので、単位の大きい変数 (年間購入額、数百万ウォン) が単位の小さい変数 (訪問回数) を圧倒します。
- **初期位置の運**: 開始時の配置によって結果が変わり得るため、何度も試して最善を取ります (`n_init`)。
- **限界**: 丸いまとまりを仮定するので、細長い形やドーナツ形のまとまりには弱いです。すべての点をどこかに必ず割り当てるので、外れ値もどこかのグループに入り込みます。

### 3.2 クラスタの解釈 — 機械にはできない残り半分

k-means がくれるのは「0 番、1 番、2 番、3 番グループ」という番号だけです。**各グループの平均プロフィールを見て「節約志向の新規型」「VIP 常連型」のような名前を付けるのは人間の仕事**であり、名前が付いて初めてアクションが生まれます。level01 で述べた「教師なし学習の解釈コスト」が、まさにこの段階です。プロフィールが解釈できなければ、k や変数の選択を変えてもう一度 — この往復が正常なプロセスです。

### 3.3 PCA を使うときに知っておくこと

- **説明分散比率**: 各主成分が元の情報 (分散) の何 % を担っているかが出ます。PC1+PC2 で 70% なら「2 次元の影に元の 70% が収まった」という意味 — 地図をどれだけ信じるかの根拠です。
- **軸の解釈**: 各主成分は元の変数の加重和です。重み (loading) を見れば「PC1 はだいたい『消費規模』の軸、PC2 は『割引への敏感さ』の軸」のように読めます。
- **用途**: 可視化のほかにも、変数が多すぎるときにモデルの入力を圧縮する前処理として使います (ノイズ除去の効果もあります)。
- **やはり標準化が必須**: 分散基準なので、単位の大きい変数が軸を独占します。

### 3.4 教師なし学習の評価はなぜ曖昧か

正解がないので、正解率のような指標がありません。シルエットスコア (自分のクラスタに近く、他のクラスタから遠い度合い) のような内部指標はありますが補助手段であり、究極の評価は**「このセグメンテーションに基づくキャンペーンが成果を出したか」**というダウンストリームの検証です。

## 6. よくある間違い

- **標準化の省略**: クラスタリングも PCA も、単位の大きい変数に支配されてしまいます。このレベル最大の罠です。
- **k-means の結果を「発見された真実」に格上げすること**: k-means はどんなデータでも**必ず** k 個に分けます。構造がなくても分けます。シルエット・エルボー・可視化で構造の実在をクロスチェックしましょう。
- **クラスタ番号をそのまま報告書に書くこと**: 「クラスタ 2 の解約率が高いです」では伝わりません。プロフィールに基づいた名前を付けましょう。またクラスタ番号は、再実行すると入れ替わり得る任意の番号です。
- **PCA の軸を物理的実体として解釈すること**: 主成分は数学的な方向であって「顧客の本性」ではありません。loading を見て慎重に名前を付け、説明分散が低ければ地図そのものを過信しないでください。
- **セグメンテーション後のアクション設計の省略**: グループを分けただけで終わるセグメンテーションプロジェクトは山ほどあります。level02 の定義書の原則 (アクションのない分析は飾り物) は、教師なし学習にもそのまま当てはまります。
