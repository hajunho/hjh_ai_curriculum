# Lecture 06 · Level 09 — 過学習・正則化・ハイパーパラメータ

> 多項式の次数を上げながら train/valid の誤差が分かれていく瞬間をグラフで目撃し、正則化 (L1/L2) というブレーキで複雑なモデルを律する方法を学びます。
**難易度** ⭐⭐⭐⭐ / **前提** level04 / **想定時間** 50分

## 1. なぜ学ぶのか — ビジネスの視点

この講義で過学習 (overfitting) はすでに 3 回登場しました。level04 の楽観バイアス、level07 の深さ無制限の木、level08 の不安定性 — すべて同じ病気の別の症状です。このレベルでは、その病気を正面から扱います。

実務でこれが重要な理由は、これが**モデル選択の言語**だからです。「次数を上げますか、下げますか」「アルファをいくつにしますか」「なぜ検証成績がこれ以上伸びないんでしょう?」 — データチームの日常会話の大半は、過学習と過小適合の間のどこかで起きています。この軸を理解すれば、「モデルをもっと複雑にすれば良くなりますか?」という質問に「訓練成績は必ず良くなり、実戦成績はある地点までしか良くなりません」と答えられるようになります。その「ある地点」を探す手続きがハイパーパラメータチューニングであり、地点を通り過ぎたときに引き戻すブレーキが正則化です。

## 2. 比喩で理解する

**スーツの仕立て**で考えてみましょう。客 (データ) の体には、本質的な体型 (パターン) と、その日の偶然 — 厚手の下着、さっき食べた昼食 (ノイズ) — が混ざっています。

- **過小適合 (underfitting)**: フリーサイズのビニール製レインコート。誰にでもだいたい合い、誰にもよく合いません。モデルが単純すぎて体型すら捉えられない状態 — 1 次の直線で曲線パターンを描こうとするようなものです。
- **適正な適合**: 体型には沿いつつ、その日の偶然は無視する良い仕立て服。明日着てもよく合います。
- **過学習**: 今日この瞬間の体に寸分の狂いなく密着させた服。昼食を食べたお腹の形まで反映したので、**今日は完璧、明日は着られません。** 15 次の曲線が訓練の点をすべて通過するのが、まさにこの状態です。

**正則化 (regularization) は仕立て屋への指示**です: 「体には沿わせるが、凹凸の一つひとつに過敏に反応しないこと」。数学的には、モデルの係数が大きくなることに罰金を科し、データへの当てはまりを少し犠牲にしてでも曲線を滑らかに保たせます。罰金の強さ (アルファ) を調節するのがハイパーパラメータチューニングです。

## 3. 核心概念

### 3.1 パラメータ vs ハイパーパラメータ

- **パラメータ**: 学習がデータから見つけ出す値 (回帰係数、木の分岐点)。機械の担当。
- **ハイパーパラメータ (hyperparameter)**: 学習を始める前に人が決めるつまみ (多項式の次数、木の深さ、正則化の強さアルファ、フォレストの木の数)。人の担当 — ただし勘ではなく**検証セットの成績**で選びます (level04 の模擬試験がまさにこの用途でした)。

### 3.2 検証曲線 — 分かれていく 2 本の線

複雑さ (例: 多項式の次数) を x 軸、誤差を y 軸に取り、訓練誤差と検証誤差を一緒に描いたものが検証曲線 (validation curve) です。典型的な形:

- 訓練誤差: 複雑さが上がるほど**単調に減少** (暗記する余力が増えるので)
- 検証誤差: 下がっていき (パターンをよりよく捉える)、ある地点から**再び上昇** (ノイズまで暗記し始める)

2 本の線が分かれ始める地点が過学習の始まりで、検証誤差の最小点が選ぶべき地点です。今日の実習の PNG が、まさにこの図です。

### 3.3 L2 と L1 — 2 種類の罰金

正則化は、損失関数に「係数の大きさへの罰金」を加えます。

- **L2 (Ridge)**: 罰金 = α × (係数の 2 乗の和)。すべての係数を**均等に縮ませます**。係数を 0 にはしません。デフォルトの選択肢。
- **L1 (Lasso)**: 罰金 = α × (係数の絶対値の和)。重要度の低い係数を**まるごと 0 に**して、特徴量を自動選別します。「数百個の特徴量のうちどれが本物かを絞り込みたいとき」に使います。

α (アルファ) が 0 なら正則化なし (元の回帰)、大きすぎるとすべての係数が押しつぶされて過小適合。α もハイパーパラメータなので検証で選びます。実務のルールを 1 つ: **正則化を使うときは特徴量の標準化が事実上必須**です。単位の大きい特徴量ほど係数が小さくて罰金を払わずに済む、という不公平が生じるからです。

### 3.4 過学習への他の処方箋

正則化は処方箋の 1 つにすぎません。データを増やす (最も確実)、特徴量を減らす、モデルを単純化する (次数・深さを下げる)、アンサンブル (level08)、早期終了 — 共通する哲学は 1 つです。**モデルの自由は、データが支えられる分だけ許す。**

## 4. 実習 — main.py

実行:

```bash
python3 main.py
```

合成した曲線データ (本物のパターン + ノイズ、訓練 30 点) で、過学習の全過程を実演します。

- **[1]** 本物のパターンが曲線であるデータを作り、訓練/検証に分けます。標本をわざと 30 点だけにして、過学習がよく見えるようにしました。
- **[2] 検証曲線の実験**: 多項式次数 1〜15 を回しながら、訓練/検証の RMSE を表で出力します。訓練誤差は減り続け、検証誤差は U 字に折れること、そして高次で係数が数万〜数十万の単位に暴走することを確認してください。
- **[3]** 次数別の曲線 3 本 (過小適合の 1 次、適正な次数、過学習の 15 次) と検証曲線を `outputs/overfitting.png` に保存します。この図 1 枚がこのレベルのすべてです。
- **[4] Ridge 正則化の効果**: 暴走していた 15 次モデルに α を 0→0.001→0.1→10 と上げながら、検証 RMSE と係数の大きさがどう鎮まるかを表で見ます。「複雑なモデル + 適切な罰金 ≈ 適正なモデル」を確認してください。
- **[5] L1 (Lasso) の味見**: 15 次の特徴量のうちいくつの係数がちょうど 0 になるかを数え、自動特徴量選別を確認します。

コードの心臓部: `PolynomialFeatures(degree)` で x, x², … の特徴量を作り、`Pipeline` で標準化した後 `LinearRegression`/`Ridge`/`Lasso` に入れる構造です。次数と α という 2 つのハイパーパラメータが、コードのどこで「人の決定」として入っているか、目を凝らして見てください。

## 6. よくある間違い

- **訓練誤差が減ったから良くなっている最中だと錯覚すること**: 訓練誤差は複雑さを上げれば**必ず**減ります。情報量ゼロのシグナルです。検証誤差だけが答えてくれます。
- **検証誤差が上がり始めたのに「もっと複雑に」と押し切ること**: 分かれた後の投資 (次数、パラメータ、学習時間) は、すべてノイズの暗記に使われます。
- **標準化なしで正則化を適用すること**: 単位の大きい特徴量が罰金を回避します。Pipeline で標準化を束ねましょう。
- **α をテストセットで選ぶこと**: level04 の試験問題の盗み見が、正則化でもまったく同じように成立します。α は検証 (または交差検証) で。
- **過小適合を過学習と誤診すること**: 訓練誤差すら大きい状態で正則化をさらに強くかけると悪化します。訓練/検証の誤差を**両方**見て診断しましょう。
