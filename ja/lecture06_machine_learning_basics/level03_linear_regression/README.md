## 1. なぜ学ぶのか — ビジネスの視点

マーケティング予算会議で「広告費をあと 1,000万ウォン使ったら、売上はどれだけ伸びますか?」という質問が出たとき、「まあ、増えるでしょうね」と「過去データでは広告費 1万ウォンあたり売上が約 1.5万ウォン増えていました」では天と地の差があります。線形回帰 (linear regression) は、こうした「どれくらい?」に数字で答える、最も歴史が長く、最も広く使われ、最も説明しやすい道具です。

もう 1 つの理由: 線形回帰はこの講義全体の基礎文法です。ロジスティック回帰 (level05) は線形回帰に確率変換をかぶせたものですし、正則化 (level09) は線形回帰の係数を律する技術で、ニューラルネットワークでさえ線形回帰を何層にも積み上げた構造です。ここで「係数」「切片」「誤差の最小化」をしっかり押さえておけば、この先がすべて楽になります。

## 2. 比喩で理解する

**散らばった点の間に定規を当てる作業**を想像してみてください。日別の (広告費, 売上) の点が 1,800 個あまり打たれた散布図の上に透明な定規を置いて、「すべての点を代表する直線」を引くとしたら、どこに当てますか? ある点は定規の上に、ある点は下にあるでしょう。良い直線とは、**点と定規の間の縦方向の隙間 (誤差) が全体として最も小さい直線**です。

最小二乗法 (least squares) は、この「全体として最も小さい」を正確に定義したものです。各点と直線の縦の距離を 2 乗して全部足した値 (二乗和) が最小になる直線を選びます。2 乗する理由は 2 つ — 上下の誤差が打ち消し合わないようにするためと、大きな誤差により大きなペナルティを与えるためです。驚くべきは、この最適な直線が試行錯誤なしに**公式 1 行でそのまま計算できる**ことです。level00 の「しきい値をすべて試す探索」と違い、線形回帰は数学が探索を代わりに終わらせてくれているケースです。

## 3. 核心概念

### 3.1 モデルの形: y = a·x + b

- **x**: 入力の特徴量 (広告費)、**y**: 予測対象 (売上)
- **a (傾き、係数 coefficient)**: x が 1 増えたときに y が増える量。**ビジネス解釈の核心**です。「広告費 1万ウォンあたり売上 +a万ウォン」。
- **b (切片 intercept)**: x=0 のときの y。「広告をまったくしなくても出る基礎売上」と読めますが、データの範囲外への外挿なので慎重に解釈します。

### 3.2 最小二乗法の公式

傾きと切片は、平均・分散・共分散から閉形式 (closed-form) で計算できます。

```
a = Cov(x, y) / Var(x)      (x と y が一緒に動く度合い ÷ x の散らばり具合)
b = mean(y) − a · mean(x)   (直線は必ず (x̄, ȳ) の点を通る)
```

今日の実習ではこの 2 行を numpy で直接計算し、sklearn の `LinearRegression` が出す答えと小数点まで一致することを確認します。ライブラリは魔法ではなく、この公式の包み紙にすぎない — それを目で見るのが目的です。

### 3.3 どれくらい当たっているか: R²

決定係数 R² (R-squared) は「y の変動のうちモデルが説明している割合」です。0 なら平均値で答えるのと同じ、1 なら完璧。実務データでは R² 0.3〜0.7 がよくある水準です。R² が低いから無価値というわけでも、高いから因果関係が証明されたわけでもありません。

### 3.4 解釈の落とし穴: 相関 ≠ 因果

回帰係数は「広告費が高い日には売上も高かった」という**同伴関係**を要約しているだけです。広告が売上を押し上げたのかもしれませんが、繁忙期だから広告も売上も一緒に増えただけかもしれません。「広告費を増やせば売上が増える」と断定するには、実験 (A/B テスト) や追加の分析が必要です。報告書には「広告費 1万ウォンあたり売上 +1.5万ウォンの**関連**が観察された」のように書くのが安全です。

### 3.5 特徴量を複数使うと: 重回帰

y = a₁x₁ + a₂x₂ + … + b の形で特徴量を複数入れられます (重回帰、多変量線形回帰)。このとき各係数の解釈は「他の特徴量が同じだとしたときの」効果に変わり、特徴量間の単位の違いのせいで係数の大きさ比べには標準化が必要になります。今日は単回帰に集中し、重回帰は level05 以降の分類モデルで自然に使うことになります。

## 6. よくある間違い

- **クレンジングせずに回帰から回すこと**: 欠損や負の値の汚染が混ざったまま回すと係数が歪みます。今日のコードの [1] が無駄に長いわけではないのです。
- **切片を額面どおりに解釈すること**: 「広告費 0 ウォンのとき売上 b ウォン」は、データに広告費 0 ウォンの日がなければ外挿です。
- **R² が低いから即ボツ / 高いから即確信**: 低くても係数の方向・大きさは意思決定に役立つことがありますし、高くてもリークや偶然かもしれません。
- **係数を因果として報告すること**: 「関連が観察された」と「増やせば増える」を区別してください。3.4 を読み直しましょう。
- **訓練データ全体で性能を語ること**: 今回もわざと全データで R² を出しました。この成績の問題点が、まさに次のレベルのテーマです。
