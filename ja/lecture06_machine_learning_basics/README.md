# Lecture 06 — 機械学習入門

> ルールをハードコーディングする代わりに、データからパターンを学習させる方法を最初から最後まで学びます。
> 回帰・分類・クラスタリングの代表的なモデルを実際に動かし、「モデルをどう信じるか」(評価・過学習・解釈) まで扱います。

## この講義で学ぶこと

- 機械学習 (Machine Learning) が従来のプログラミングと何が違うのか、いつ使い、いつ使うべきでないのか
- ビジネスの質問 (「解約を減らしたい」) を ML の問題定義書に変換する方法
- 線形回帰・ロジスティック回帰・決定木・ランダムフォレスト・勾配ブースティングの原理と使い方
- 学習/検証/テストの分割、評価指標、過学習と正則化 — モデルを「正しく信じる」ための技術
- クラスタリング・次元削減で、正解のないデータから構造を見つけ出す方法
- 変数の重要度と個別予測の説明で、モデルを非専門家に説明する方法

## 前提となる講義

- **lecture02 — Python プログラミング基礎** (関数・リスト・辞書が読めること)
- **lecture03 — データハンドリング** (NumPy 配列、Pandas DataFrame、欠損値処理)

数学は高校レベルの直感 (直線の傾き、確率) があれば十分です。数式よりも比喩と実験で説明します。

## 最短コース (時間がなければこの 5 つだけ)

1. **level00** — ルール vs 学習: 機械学習とは何かを体で理解する
2. **level03** — 線形回帰: 初めての予測モデル
3. **level04** — データの分割: 「自己採点の罠」を知らないと、すべての結果が嘘になります
4. **level05** — ロジスティック回帰: 実務の分類問題の出発点
5. **level06** — 評価指標: 「正解率 98.5%」にだまされない方法

## この講義が実務で活きる場面

- **サブスク/会員サービスの運営**: 来月解約しそうな顧客を先回りして見つけ、クーポンやフォロー連絡を集中的に投入する (level05, 07, 11)
- **マーケティング予算会議**: 「広告費を 1,000万ウォン増やしたら売上はどれだけ伸びるのか?」に根拠のある数字で答える (level03)
- **不正取引・不正利用の監視**: 不正比率 1.5% のデータで、正解率ではなく再現率・適合率で語る (level06)
- **顧客セグメンテーション**: 正解ラベルなしに購買パターンだけで顧客をグループ分けし、グループ別の施策を立てる (level10)
- **外部ベンダーやデータチームとの協業**: 「AUC 0.85 です」という報告を自分で検証できる質問を投げる (level04, 06, 09)
- **経営層への報告**: 「モデルはなぜこの顧客を危険と判断したのか」を変数重要度と個別の説明で伝える (level11)
