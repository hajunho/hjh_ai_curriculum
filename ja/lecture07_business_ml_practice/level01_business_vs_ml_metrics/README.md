# Lecture 07 · Level 01 — ビジネス指標と ML 指標をつなぐ

> 混同行列の 4 つのマスをウォン建ての金額に換算し、「再現率 1%pt の改善はいくらなのか」に数字で答えます。
**難易度** ⭐⭐ / **前提** level00、lecture06 level06 (評価指標) / **想定時間** 35分

## 1. なぜ学ぶのか — ビジネスの視点

データチームが「再現率を 62% から 71% に上げました」と報告しても、経営層の反応はたいてい沈黙です。ところが「同じ改善を金額に換算すると、年間の解約防止利益が約 2 倍になります」と言えば、会議の空気が変わります。同じ事実、違う言語です。

ML 指標 (再現率、適合率、AUC) とビジネス指標 (売上、コスト、解約率) は互いに翻訳が可能なのですが、この翻訳ができる人は組織に意外なほど少ないものです。翻訳機の核心はたったひとつ、**混同行列 (confusion matrix) の各マスに単価を付けること**です。このレベルを終えると、皆さんはどんな分類モデルに対しても「で、いくらの価値があるモデルなのか」を計算できるようになります。モデル導入の稟議書、外注の検収、目標設定はすべてこの計算の上に成り立ちます。

## 2. たとえ話で理解する

空港の保安検査場を考えてみてください。検査員の成果を「判定精度 99%」とだけ言っても何の情報にもなりません。重要なのは、4 種類の出来事それぞれの**値札**です。

- 危険物をきちんと見つける (TP): 事故の予防 — 大きな利益
- 危険物を見逃す (FN): 最悪のコスト — たった 1 件が会社を揺るがしかねない
- 問題のないカバンを開けて調べる (FP): 乗客の不満と検査の人件費 — 小さいが積み重なるコスト
- 問題のないカバンを通す (TN): 通常運用 — コストなし

4 マスの値段がまったく違うのですから、「何回当てたか」(精度) ではなく「いくら儲けて、いくら失ったか」(期待損益) で評価すべきです。サブスクサービスの解約予測も同じです。解約する顧客を見逃すこと (FN) と、問題のない顧客にクーポンを配ること (FP) では値段が違うからです。

## 3. 核心となる概念

### 3.1 混同行列の復習と 2 つの指標

解約予測で陽性 (positive) = 解約とすると:

- **再現率 (recall)** = TP / (TP+FN): 実際の解約者のうちモデルが事前に見つけ出した割合。「見逃さない能力」
- **適合率 (precision)** = TP / (TP+FP): モデルが危険と判定した顧客のうち本当の解約者の割合。「空振りしない能力」

### 3.2 マスごとに単価を付ける

翻訳に必要なビジネスの数字は、たいてい 3 つで足ります。

| 項目 | 例の値 | 出どころ |
|---|---|---|
| 顧客残存価値 V (守れば得られる売上) | 月額料金 × 残存月数 | 財務/CRM |
| 介入コスト C (クーポン+相談の原価) | 12,000ウォン/人 | マーケティング |
| 介入成功率 s (クーポンを受け取れば残留する確率) | 30% | 過去のキャンペーン |

すると各マスの損益は:

- TP: `+V×s − C` (一部を救い出し、コストは確実に使う)
- FP: `−C` (問題のない顧客に使ったコスト)
- FN: `0` (介入自体をしていないので追加コストはないが、救うチャンスを失う — 機会費用)
- TN: `0`

モデルの総期待利益 = `TP×(V×s−C) − FP×C`。この式がこのレベルと level11 の全体を貫きます。

### 3.3 「再現率 1%pt = いくら」の公式

顧客総数 N、解約率 r のとき、実際の解約者は N×r 人です。再現率が 1%pt 上がると追加で捕捉できる解約者は `N × r × 0.01` 人。1 人を捕捉したときの純利益が `V×s − C` なので:

**再現率 1%pt の価値 ≈ N × r × 0.01 × (V×s − C)**

例: 顧客 10 万人、解約率 18%、V=179,000ウォン、s=30%、C=12,000ウォンなら → 100,000 × 0.18 × 0.01 × (53,700−12,000) ≈ **約 750 万ウォン**。「再現率 1%pt」が突然、具体的な予算の言葉になります。

注意: 適合率が下がると FP のコストが増えるため、再現率だけを際限なく上げることが常に得とは限りません。どこで止めるべきかは level11 (最適しきい値) で計算します。

### 3.4 組織に「指標辞書」を作ろう

この翻訳は一度やって終わりの計算ではなく、組織の共通言語になるべきものです。実務のコツ: プロジェクトの Wiki に「再現率 1%pt = 約 750 万ウォン/年、適合率 1%pt 低下 = FP 約 N 件増 = 約 M ウォン」のような換算表を貼っておきましょう。以後のすべての性能報告と目標交渉がこの表の上で行われ、データチームと事業チームが初めて同じ単位で話せるようになります。

## 4. 実習 — main.py

```bash
python3 main.py
```

- [1] `churn_table` の 2,000 人を学習/テストに分け、ロジスティック回帰を訓練します。
- [2] テストの混同行列 (TP/FP/FN/TN) を出力します。
- [3] ビジネス単価 (V, C, s) を定義して 4 マスを金額に換算し、モデルの期待利益を計算します。
- [4] 比較対象 2 つ (「何もしない」「全員にクーポン」) と利益を並べ、モデルの存在価値を確認します。
- [5] 再現率 1%pt の価値を公式で計算し、顧客 10 万人規模に拡張した年間金額を出力します。

コードの核心部は `profit_of()` 関数です。混同行列の数字と 3 つの単価を受け取り、1 行の算数で利益を返します。モデル評価は結局のところ算数である — それがこのレベルのメッセージです。

## 5. やってみよう

1. **(易しい)** 介入コスト `COST_C` を 12,000ウォンから 40,000ウォンに上げて実行してみましょう。「全員クーポン」戦略とモデル戦略の差はどう変わるでしょうか?
2. **(中くらい)** 介入成功率 `SUCCESS_S` を 10% に下げると、モデルを使っても利益がマイナスになることがあります。損益分岐となる成功率 (利益=0 になる s) を手計算してみてください。ヒント: TP×(V×s−C) = FP×C を s について解けば求まります。
3. **(挑戦)** 自分の業務の分類問題を 1 つ (例: 不良品検出、延滞予測) 選び、3.2 の表を実際の値で埋めてみましょう。値が分からなければ「誰に聞けばいいか」を書き出すだけでも、実務では半分成功です。

## 6. よくある間違い

- **FN のコストを 0 のままにして安心する**: 会計上の支出はありませんが、機会費用 (失った売上) が最も大きいマスです。レポートには「見逃した解約者 × V×s」を機会損失として併記しましょう。
- **単価が分からないからと翻訳をあきらめる**: V, C, s は推定値で十分です。保守的/楽観的の 2 シナリオで幅を持たせて報告すればよいのです。
- **精度で報告する**: 解約率 18% なら「全員残留」と予測するだけで精度 82% です。精度が高いという言葉には何の情報もありません。
- **テストデータの利益をそのまま年間見通しとして使う**: サンプルサイズと期間を、実際の顧客数・年単位に換算するスケーリングを忘れないでください (main.py の [5] を参照)。
