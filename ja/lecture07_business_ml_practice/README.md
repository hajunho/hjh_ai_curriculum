# Lecture 07 — ビジネス機械学習実践

> lecture06 で学んだモデルを「会社で実際に動くプロジェクト」に仕上げる講義です。
> 問題定義から特徴量設計、検証、そしてモデルの答えをお金になる意思決定へ変える最後のステップまでを扱います。

## この講義で学ぶこと

- データプロジェクトが実際に進む順序と、失敗するプロジェクトに共通するパターン
- 「再現率 1%pt の改善」を「年間売上いくら」に翻訳する方法 — 経営層と会話するための言語
- 探索的データ分析 (EDA) を勘ではなく手順として実行するワークフロー
- 特徴量エンジニアリング、カテゴリ変数のエンコーディング、スケーリングとパイプライン — モデルよりも性能を左右する準備作業
- 交差検証と不均衡データの処理 — 性能の数字を「信頼できるもの」にする技術
- 実践 3 本セット: 売上・需要予測、顧客チャーン予測、不正取引検知
- モデルの確率をコスト・収益の計算に組み込み、最適な意思決定 (誰にクーポンを配るか) を導く方法

## 前提となる講義

- **lecture03 — データハンドリング** (Pandas DataFrame、欠損値処理)
- **lecture05 — 統計と可視化** (分布、相関、グラフの読み方)
- **lecture06 — 機械学習入門** (回帰/分類、学習・検証分割、評価指標) — 特に level04 と level06 は必ず先に見ておいてください。

## 最短コース (時間がなければこの 5 つだけ)

1. **level00** — プロジェクト全体の地図を先に見ておくと、残りの内容が頭の中で整理されます
2. **level01** — ML 指標をお金に翻訳する方法: この講義の心臓部です
3. **level06** — 交差検証: 性能の数字にだまされないための最低限の防御策
4. **level09** — チャーン予測の完結プロジェクト: これまでのすべての部品が組み上がる場所
5. **level11** — 確率を意思決定へ: 実務で最も目に見えて役立つ技術

## この講義が実務で使われる場面

- **四半期の事業計画**: 来週・来月の売上を曜日・季節効果まで織り込んで予測し、在庫と人員を準備する (level08)
- **CRM キャンペーン**: 解約リスク上位の顧客リストと顧客ごとの推奨アクションを抽出してマーケティング部門に渡す (level09, 11)
- **リスク・監査部門**: 1 日のアラート処理量 (予算) に合わせて不正取引検知のしきい値を設計する (level07, 10)
- **データチームとの協業・外注の検収**: 「精度 95%」というレポートからデータリーケージや単一分割の落とし穴を見抜く質問力 (level03〜06)
- **経営層への報告**: 混同行列の代わりに「このモデルで年間 4 億ウォンの解約損失を防げます」と語る (level01, 11)

## 進め方のヒント

- すべてのレベルは `main.py` を自分で実行しながら読むように設計されています。数字がノートと一致するか確認してみてください (seed 固定)。
- 実行方法: リポジトリルートの仮想環境で `python3 main.py` (環境構築はルートの `SETUP.md` を参照)
- データはすべて `common/hjh_data.py` が合成生成します (カフェの売上、サブスクの解約、カード取引)。インターネット接続は不要です。
- level00〜07 が部品、level08〜11 が完成品です。部品のレベルを飛ばした場合は、実践レベルで詰まったときに戻ってきてください。
