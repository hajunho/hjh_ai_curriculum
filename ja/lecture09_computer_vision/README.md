# Lecture 09 — コンピュータビジョン

> コンピュータが画像を「数字の格子」として読み込む瞬間から、CNN で図形を分類し、
> 物体検出・セグメンテーション・ビジョントランスフォーマーまで — 目がやっている仕事をコードで再現する旅です。

## この講義で学ぶこと

- 画像がコンピュータの中でどのように数字として表現されるのか (ピクセル・チャンネル・解像度)
- 畳み込み (Convolution) がなぜ画像に特化した演算なのか — 自分で実装して確かめます
- CNN (畳み込みニューラルネットワーク) の構造を層ごとに設計し、パラメータ数を計算する方法
- 図形画像の分類を学習→評価→誤り分析まで完走する一連のプロセス
- データ拡張・転移学習で「データが足りないとき」に性能を引き上げる技術
- 物体検出 (バウンディングボックス・IoU)、セグメンテーション、OCR が産業現場で使われる仕組み
- ビジョントランスフォーマー (ViT) と CLIP 式の画像・テキスト整合 — 最新ビジョン AI の文法

すべての実習はインターネットからのダウンロードなしに、リポジトリの中で numpy が直接描いた図形画像
(`common/hjh_data.py` の `shape_images`) だけで進めます。有名なデータセットがなくても、
CNN の原理はすべて証明できます。

## 前提となる講義

- **lecture03 — データハンドリング** (NumPy 配列のインデックス・スライスが読めることが必要です)
- **lecture06 — 機械学習入門** (学習・評価の分離、正解率と誤差の概念)
- **lecture08 — ディープラーニング基礎** (PyTorch テンソル、学習ループ、MLP — level03 から必要になります)

level00〜02 は numpy だけを使うので、lecture08 を飛ばして先に味見しても大丈夫です。

## 最短コース (時間がなければこの 5 つだけ)

1. **level00** — 画像 = 数字の格子。この一文を体で理解できないと、この後のすべてが魔法のように見えてしまいます
2. **level02** — 畳み込みを numpy で自分で実装: CNN の心臓を開いてみます
3. **level05** — 図形分類の完走: 学習→評価→誤分類分析という一周のサイクル
4. **level07** — 転移学習: 実務の画像タスクの 9 割はこの方法で解決します
5. **level09** — 物体検出: 「何がどこに」まで答える仕組み

## この講義が実務で使われる場面

- **製造の品質検査**: 生産ラインのカメラで不良 (傷・汚れ・欠品) を自動検出 (level05, 08, 10)
- **書類の自動化**: 契約書・領収書のスキャン画像から文字領域を見つけてテキストに変換する OCR パイプライン (level09, 10)
- **小売・物流**: 棚の写真から商品位置や欠品を確認し、倉庫内の物品をカウントする (level09)
- **医療・安全**: 読影の補助、防犯カメラの異常検知 — 「検出結果をどこまで信じるか」を判断する基準 (level08, 09)
- **外注・ソリューションの検収**: 「正解率 99%」というビジョンソリューションの提案書を受け取ったとき、データ分割・誤り分析・拡張の有無を問い返せる力 (level06, 08)
- **最新技術の理解**: 「自社サービスにマルチモーダル AI をつけよう」という議論で、ViT や CLIP が何なのかを分かって会話する (level11)

## 進め方のヒント

- すべてのレベルは `main.py` を自分で実行しながら読むように設計されています。特にこの講義は
  PNG の図が中心的な成果物なので、各レベルの `outputs/` フォルダに生成された画像を必ず開いてみてください。
- 実行方法: リポジトリルートの仮想環境で `python3 main.py` (環境構築はルートの `SETUP.md` を参照)
- torch の学習が入るレベル (level03〜09, 11) も、すべて CPU で数十秒以内に終わる小型サイズで設計しています。
- データはすべてコードがその場で描き出すので、インターネット接続は不要です。
