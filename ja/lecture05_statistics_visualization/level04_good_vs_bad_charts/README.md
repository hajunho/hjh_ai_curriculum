# Lecture 05 · Level 04 — 良いグラフ vs 悪いグラフ

> グラフは嘘をつきませんが、グラフを描く人は嘘をつけます。
**難易度** ⭐⭐ / **前提** level03 / **想定時間** 45分

## 1. なぜ学ぶのか — ビジネスの視点

数字を改ざんすれば監査に引っかかりますが、グラフを「演出」することは何の規定にも
引っかかりません。だから会議室には、軸を切り詰めた棒グラフ、傾いた 3D
円グラフ、大きさを誇張した絵文字が飛び交っています。問題は両方向で
起こります。他人の歪んだチャートにだまされて間違った決定を下すこと、そして
自分がうっかり歪んだチャートを作って信頼を失うこと。

このレベルの目標は 2 つです。第一に、代表的な歪曲テクニックを自分の手で作って
みることで**見抜く目**を得ること。第二に、同じデータの誠実なバージョンを並べて
描いてみることで**誠実に描く手**を得ること。だます方法を学ぶのは、
だますためではなく、だまされないためです。

## 2. たとえ話で理解する

歪曲グラフは**証明写真のレタッチ**と同じです。写真の人物は実在していて
合成でもありませんが、照明と角度と補正で実物と違う印象を作ることが
できます。軸を切ることは顔だけ拡大して撮ることで、3D 効果は顔が
小さく見える角度で撮ることです。「写真は偽物か」と問われれば、偽物では
ありません。しかしその写真だけで人を判断すれば、判断を誤ります。

良いグラフの基準はシンプルです。**グラフが与える第一印象が、データを丁寧に
読み込んだときの結論と同じか?** 第一印象と精読の結論が違うように設計された
グラフが、悪いグラフです。

## 3. 核心となる考え方

### 3.1 罪状 1 — 軸の切り詰め (truncated axis)

棒グラフの y 軸を 0 ではない値 (例: 90) から始めると、92 と 95 の差
(実際は 3%) が視覚的には 2〜3 倍の差のように見えます。棒の**長さ**が
値に比例するという約束を破っているからです。

- ルール: **棒グラフの y 軸は 0 から始めます**。棒は長さで語る
  グラフだからです。
- 例外: 折れ線グラフは変化の「形」を見るグラフなので、軸を切ってよい場合が
  あります。ただし、切ったことを示す表示 (軸ラベル、波線マーク) を明確にする必要があります。

### 3.2 罪状 2 — 3D と円グラフの合わせ技

円グラフはもともと角度の比較が難しいグラフなのに、3D に傾けると**手前の
一切れが実際より大きく**見えます。遠近法のせいで、同じ 25% でも手前にあれば
膨らみ、奥にあれば縮んで見えます。自社シェアを手前に配置した 3D 円グラフは
古典的な演出テクニックです。一切れが 4 つを超えたり比率が似たり寄ったりなら、
円グラフの代わりに並べ替えた棒グラフが正解です。

### 3.3 罪状 3 — 絵文字の面積による誇張

「売上 2 倍」を表現しようとコインの絵の縦横を両方 2 倍にすると、面積は
4 倍になります。目は面積で読むため、2 倍が 4 倍に誇張されます。アイコンの
大きさで値を表現するときは、個数で表現するか (コイン 2 枚)、一辺だけを
伸ばすべきです。

### 3.4 インクの比率 — データインク (data-ink)

良いグラフの実用的な基準として、「図に使われたインクのうち、データを表現する
インクの割合を高めよ」という原則があります。グリッド線の乱発、背景のグラデーション、
影、枠線、3D 効果は、データではなく装飾に使われたインクです。
装飾を消すほどデータがよく見えます。実務のコツ: グラフを完成させた後、
「この要素を消したら情報が消えるか?」を要素ごとに問いかけ、答えが
「いいえ」なら消します。

### 3.5 チェックリスト — 他人のグラフを受け取ったとき

1. 棒グラフの y 軸は 0 から始まっているか?
2. 軸の目盛りの間隔は一定か? (途中で飛んでいないか)
3. 3D 効果はあるか? あるならなぜ?
4. 比較対象の期間・単位・集計方法は同じか?
5. 「n = 何人/何件」が書かれているか? 標本 3 件の平均かもしれません。

### 3.6 歪曲の多くは悪意ではない

現場で出会う歪んだチャートの多くは、だます意図ではなく、ツールの既定値の
せいで生まれます。表計算ソフトが「見栄えよく」y 軸を自動で切り詰め、
チャートウィザードが 3D を勧めてきます。そのため作った本人でさえ、自分のチャートが
誇張していることに気づいていません。コードでグラフを描けば、軸の範囲・色・形が
すべて明示的になるため、無意識の歪曲が入り込む余地が減ります。これが
アナリストがコードで図を描く、もう 1 つの理由です。

## 6. よくある間違い

- **折れ線グラフまで必ず 0 から始める**: 為替や株価のように絶対的な 0 が無意味な
  データは、0 から描くとかえって変化が見えません。「棒は 0 から、線は
  文脈に合わせて + 切った表示」と覚えましょう。
- **歪曲を指摘するときに人を攻撃する**: 「このグラフは改ざんですね」ではなく「y 軸を
  0 からに変えたらどう見えるでしょう?」のほうが、会議室でははるかによく通ります。
- **強調そのものを罪悪視する**: 色の強調、結論形のタイトル、注釈は歪曲ではなく
  良い編集です。歪曲は「データが語っていないこと」を語らせることで、
  編集は「データが語っていること」をよく聞こえるようにすることです。
- **円グラフの全面禁止**: 一切れが 2〜3 個で比率の差がはっきりしていれば円グラフでも
  構いません。問題なのは、一切れの多い円グラフと 3D 円グラフです。

## 次のレベルの予告

グラフの歪曲を学んだので、次は解釈の歪曲です。「広告費と売上が
一緒に動いている」という発見が「広告が売上を伸ばした」という結論になるには何が
さらに必要なのか — 相関と因果の違いを扱います。
