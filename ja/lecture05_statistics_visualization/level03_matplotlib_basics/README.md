## 1. なぜ学ぶのか — ビジネスの視点

Excel のチャートでもグラフは描けます。それなのに、なぜコードで描くのでしょう?
第一に、**繰り返し**です。毎週更新される店舗別売上グラフ 30 枚を Excel で
作れば半日、コードで作れば実行 1 回です。第二に、**再現**です。
「先月の報告書のあのグラフ、条件だけ変えてもう一度」という依頼に、コードは即座に
応えます。第三に、**拡張**です。この後学ぶ機械学習や A/B テストの結果は、
結局 Matplotlib で確認することになります。

Matplotlib は Python 可視化の標準ライブラリです。seaborn や pandas の
`.plot()` など、ほとんどの可視化ツールが内部で Matplotlib を使っています。
そのため Matplotlib の構造 (figure/axes) を一度きちんと理解すれば、ほかの
ツールのドキュメントもすらすら読めるようになります。

## 2. たとえ話で理解する

Matplotlib の構造は**報告書の作成**と同じです。

- **figure (フィギュア)** は A4 用紙 1 枚です。サイズ (figsize) を決め、書き終えたら
  ファイルに保存 (savefig) します。
- **axes (アクシーズ)** は用紙の上の段落 (グラフの 1 枠) です。1 枚に段落を
  1 つだけ置くことも (`plt.subplots()`)、2×2 で 4 つの段落を置くこともできます
  (`plt.subplots(2, 2)`)。
- **plot/bar/scatter** は段落の中の文章です。線を引き、棒を立て、
  点を打ちます。
- **タイトル・軸ラベル・凡例**は段落の小見出しと脚注です。これがないグラフは
  主語のない文章と同じで、描いた本人以外は誰も読めません。

「用紙を取り出し (figure) → 段落を分け (axes) → 文章を書き (plot) →
小見出しを付け (title/label) → 提出する (savefig)」 — この 5 段階が、あらゆる
Matplotlib コードの骨格です。

## 3. 核心となる考え方

### 3.1 基本の骨格コード

```python
import matplotlib
matplotlib.use("Agg")            # 画面なしでファイルに保存するモード
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(8, 4.5))   # 用紙 + 段落 1 枠
ax.plot(x, y)                              # 線を引く
ax.set_title("Monthly Revenue Trend")
ax.set_xlabel("Month")
ax.set_ylabel("Revenue (million KRW)")
fig.savefig("outputs/monthly.png", dpi=120)
plt.close(fig)                             # 用紙を片付ける (メモリ整理)
```

`plt.plot(...)` のように ax なしで描く方式もありますが、この講義では常に
`fig, ax = plt.subplots()` から始める**オブジェクト指向スタイル**を使います。
グラフが複数になった瞬間、この方式のほうがずっと混乱しにくいのです。

### 3.2 グラフ三兄弟 — いつ何を使うか

| 種類 | 関数 | 使う場面 | 例 |
|---|---|---|---|
| 折れ線グラフ | `ax.plot` | **時間による変化** | 月別売上の推移 |
| 棒グラフ | `ax.bar` | **カテゴリ間の比較** | 店舗別売上の比較 |
| 散布図 | `ax.scatter` | **2 つの数値の関係** | 広告費 vs 売上 |

逆に使うと途端に不自然になります。店舗の比較を折れ線で描くと「渋谷店から
新宿店へ変化していく」ような錯覚が生まれ、時間の推移を棒で描くとトレンドが
見えにくくなります。「時間=線、カテゴリ=棒、関係=点」とだけ覚えてください。

### 3.3 日本語フォントの問題

Matplotlib の既定フォントには日本語の字形が含まれていないため、日本語のタイトルが
□□□ (豆腐) に化けることがよくあります。解決策は、OS にインストールされた日本語
フォントを指定することです。

```python
plt.rcParams["font.family"] = "Hiragino Sans"   # macOS
# Windows: "Yu Gothic" / Linux: "Noto Sans CJK JP" (インストールが必要)
plt.rcParams["axes.unicode_minus"] = False      # マイナス記号の文字化け防止
```

なお、この講義の実習コードでは、どの OS・どの環境でも図が崩れないように、
**図の中のテキストは英語で統一**しています (ターミナル出力は日本語です)。
実習コードの `set_japanese_font()` は、3 つの OS の代表的な日本語フォントを順に探して
あれば登録する関数で、図中に日本語を書きたくなったときにそのまま
あなたのプロジェクトへコピーして使えます。

### 3.4 保存のルール — Agg と outputs/

サーバーや自動化スクリプトにはモニターがありません。`matplotlib.use("Agg")` は
「画面に表示せず、画像ファイルだけ作れ」という宣言で、**pyplot を import
する前に**呼ぶ必要があります。保存は `fig.savefig(パス, dpi=120)` で行い、
この講義では常にレベルフォルダの `outputs/` 以下に保存してからパスを
print します。`os.makedirs(OUT_DIR, exist_ok=True)` でフォルダがなければ
作り、あればスキップするのも定番パターンです。

### 3.5 色は情報である

色は「きれいに」ではなく「伝えたいこと」のために使います。すべての棒を虹色に
塗ると、読み手は色ごとに意味を探そうとして疲れてしまいます。基本は落ち着いた
1 色、強調したい棒 1 本だけ別の色 — これだけでグラフのメッセージの
伝達力が大きく上がります。実習 [3] の棒グラフが、この原則をそのまま
実装しています。

## 6. よくある間違い

- **`matplotlib.use("Agg")` を pyplot の import 後に呼ぶ**: 警告が出たり、
  適用されないことがあります。常に import matplotlib の直後、先頭に置きましょう。
- **`plt.close(fig)` の省略**: グラフを数十枚描くループでメモリが
  積み上がっていきます。保存したら閉じる習慣をつけましょう。
- **軸ラベル・単位の省略**: 「売上」なのか「売上 (万ウォン)」なのかで、グラフの解釈は
  100 倍変わります。単位は軸ラベルに必ず書きましょう。
- **カテゴリ比較に折れ線グラフを使う**: 店舗と店舗の間に「中間」はありません。線で
  つなぐと、存在しない連続性を暗示してしまいます。
- **フォント設定なしで日本語ラベルのまま配布**: 自分のパソコンで見えても、同僚の
  パソコンでは豆腐になります。フォント探索コードをスクリプトに含めるか、
  図中のテキストを英語にそろえましょう。
