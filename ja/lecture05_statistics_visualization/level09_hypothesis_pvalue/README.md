# Lecture 05 · Level 09 — 仮説検定と p 値

> 仮説検定は裁判です。データは証拠であり、p 値は「無罪なのにこんな証拠が出てくる可能性」です。
**難易度** ⭐⭐⭐⭐ / **前提** level08 / **想定時間** 60分

## 1. なぜ学ぶのか — ビジネスの視点

「リニューアルした店舗の売上が 8% 高いです」という報告に、役員が尋ねます。「それ、
偶然じゃないの?」この質問に、勘ではなく手続きで答える道具が仮説検定
(hypothesis testing) です。新薬の承認、品質の合格判定、論文の審査、A/B
テスト — 世の中の数多くの公式な判定が、この手続きの上で回っています。

同時に、p 値はおそらく世界で最も誤解されている統計概念です。
「p < 0.05 だから、我々の仮説が正しい確率は 95%」という解釈は広く出回っていて、
間違っています。このレベルの目標は 2 つです。p 値を**自分の手で
(シミュレーションで) 作ってみて**、その定義を体に刻むこと。そして scipy の
1 行検定と結果が一致することを確かめ、道具を信じて使えるようになることです。

## 2. たとえ話で理解する

刑事裁判には推定無罪の原則があります。被告人は**有罪が立証される
までは無罪とみなされます**。検察官の仕事は、「無罪だとするにはあまりに
不自然な証拠」を提示することです。

仮説検定は、まさにこの構造です。

| 裁判 | 仮説検定 |
|---|---|
| 被告人は無罪だ (基本前提) | 帰無仮説 H₀: 「差はない、純粋に偶然」 |
| 検察官の主張 | 対立仮説 H₁: 「本物の差がある」 |
| 証拠 | 観測されたデータ (2 店舗の売上の差) |
| 「無罪なのにこんな証拠が出るはずが」 | p 値: H₀ が真のとき、これほどの差が偶然出る確率 |
| 合理的な疑いの余地がない | p < 0.05 → H₀ を棄却 (有意水準 5%) |
| 無罪判決 ≠ 潔白の証明 | 棄却の失敗 ≠ 「差がないことの証明」 |

最後の行が重要です。証拠不十分の無罪が潔白の証明ではないように、
p = 0.3 は「差がない」ことの証明ではなく、「偶然でも説明できる」という
だけです。

## 3. 核心となる考え方

### 3.1 検定の 4 段階の手続き

1. **帰無仮説 H₀ の設定**: 「2 つの店舗の本当の平均売上は同じだ。」
2. **検定統計量の計算**: 観測された差を標準誤差で割った値 (t 統計量)。
3. **p 値の計算**: H₀ が真である世界で、これ以上に大きい差が
   偶然出る確率。
4. **判定**: p があらかじめ決めた有意水準 (ふつう 0.05) より小さければ H₀ を棄却。

有意水準は**裁判の前に**決めなければなりません。結果を見てから基準を動かすのは、
矢の後ろに的を描くことです。

### 3.2 p 値が「意味しないもの」リスト

- ❌ H₀ が真である確率 (それはデータではなく仮説に対する確率 — ベイズの領域)
- ❌ 対立仮説が正しい確率
- ❌ 効果の大きさ (標本が大きければ、取るに足らない差でも p は小さくなります)
- ❌ 再現される確率
- ⭕ **「差のない世界で、これほど (以上) の差が偶然観測される確率」**

p = 0.03 の正しい報告: 「2 つの店舗が本当に同じなら、これほどの差が偶然生じる
確率は 3% です。偶然とは考えにくいため、差があると判断します。」

### 3.3 2 種類の誤り — 誤検知と見逃し

| | 実際には差なし | 実際には差あり |
|---|---|---|
| 検定: 差あり | **第一種の過誤 (α)** 誤検知 | 正しい検出 (検出力) |
| 検定: 判断保留 | 正しい無罪 | **第二種の過誤 (β)** 見逃し |

有意水準 0.05 とは、「差がなくても 100 回中 5 回は誤検知を受け入れる」という
契約です。誤検知が致命的な分野 (新薬) は α を下げ、見逃しが致命的な
分野 (がん検診) は検出力を高めます。タダのものはありません。

### 3.4 並べ替え検定 — シミュレーションで作る p 値

t 検定の公式がなくても p 値は作れます。H₀ が「2 つの店舗は
同じ」なら、売上データに付いた店舗ラベルには何の意味もないはずです。
それなら**ラベルをめちゃくちゃに混ぜて** (並べ替え、permutation) 差を計算することを
1 万回繰り返せば、「偶然だけで生じる差」の分布が得られます。実際に観測された
差がその分布の裾のどこにあるかを数えれば、それが p 値です。
公式なしで定義そのままに作る p 値 — 今回の実習の核心です。

## 4. 実習 — main.py

```bash
python3 main.py
```

2 つの店舗の売上の差を裁判にかけます。(図中のラベルは英語です。)

- [1] `hjh_data` の売上から大阪店と名古屋店の 1 件あたり売上の標本を抜き取り、観測された
  平均の差を出力します。
- [2] **並べ替え検定**: 店舗ラベルを 10,000 回混ぜて「偶然の差」の分布を作り、
  観測された差より極端な比率 = p 値を数えます。
- [3] **scipy の検定**: `stats.ttest_ind()` (Welch の t 検定) 1 行で同じ
  質問を検定し、2 つの p 値が近いことを確かめます。
- [4] `outputs/permutation.png`: 偶然の分布のヒストグラムの上に、観測された差の
  位置を線で表示 — 「p 値 = 裾の面積」を絵として刻みます。
- [5] **対照実験**: 本当の差がない 2 つの標本 (同じ店舗を半分に割ったもの) で
  同じ検定を回し、p が大きく出ること、そして第一種の過誤の意味を
  確かめます。

出力で、並べ替え検定の p と scipy の p が小数点以下 2〜3 桁まで近い値になる
ことを確かめてください。公式はシミュレーションの近道にすぎず、同じものを計算しています。

## 6. よくある間違い

- **p を「仮説が正しい確率」として報告する**: 3.2 のリストを会議の前に読み直しましょう。
  言い間違えると、統計の分かる人の前で信頼を失います。
- **p = 0.049 と 0.051 を天と地の差のように扱う**: 0.05 は崖ではなく
  慣例的な線です。効果の大きさ、コスト、再現可能性を併せて報告しましょう。
- **有意 = 重要**: 標本が 100 万件あれば、売上の差 0.1% でも p < 0.001 に
  なります。「統計的に有意」と「ビジネス的に意味がある」は別の質問です。
- **何度も検定して良いものだけ報告する**: 指標を 20 個検定すれば、差がなくても
  平均 1 個は p < 0.05 が出ます (多重比較の問題)。いくつ検定したのかを
  隠す報告は歪曲です。次のレベルの peeking 問題と兄弟の関係にあります。
- **棄却の失敗を「同じであることの証明」として報告する**: 証拠不十分と潔白の証明は
  別物です。

## 次のレベルの予告

仮説検定をビジネスのプロダクト開発に移植したものが A/B テストです。コンバージョン率の
比較、標本サイズの設計、そして「結果を先にのぞき見してはいけない理由」を
シミュレーターで直接確かめます。
