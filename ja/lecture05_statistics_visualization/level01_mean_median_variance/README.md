# Lecture 05 · Level 01 — 平均・中央値・分散・標準偏差

> 代表値はデータのスポークスパーソンです。誰を立てるかで、語られる物語が変わります。
**難易度** ⭐ / **前提** level00 / **想定時間** 40分

## 1. なぜ学ぶのか — ビジネスの視点

「うちのチームの平均年収は 6,800 万ウォンです。」この言葉を聞いて入社したのに、実は
チームメンバー 9 人は 4,000 万ウォン台で、チーム長 1 人が 3 億ウォンをもらっている
チームだったらどうでしょう? 嘘ではありません。平均は正確に計算されています。しかし
**間違った代表値**を選んだせいで、聞き手はまったく違う絵を思い描いてしまいます。

実務では、代表値の選択が毎日発生します。顧客 1 人あたりの購入額を報告するとき、
配送所要日数を告知するとき、店舗の業績を比較するとき。平均 (mean) を使うか
中央値 (median) を使うか、そして散らばり — 分散 (variance) と
標準偏差 (standard deviation) — を併記するかどうかで、意思決定が
変わります。このレベルを終えれば、「いつどの代表値を使うのか」に自分で答えられる
ようになります。

## 2. たとえ話で理解する

代表値は**会議に代わりに送り込むスポークスパーソン**です。数千件のデータが全員
会議室に入るわけにはいかないので、1 人を選んで送り込みます。

- **平均**は「全員の意見を少しずつ混ぜた」代弁者です。全員の立場が
  反映されますが、声の大きい極端な値 1 人にひどく振り回されます。
- **中央値**は「一列に並ばせたとき、ちょうど真ん中に立つ」代弁者です。両端の極端な
  人がどれだけ叫んでも、立ち位置はほとんど変わりません。
- **標準偏差**は代弁者ではなく**注釈**です。「ただし、メンバー間の意見の開きは
  これくらい大きいです」と付け加える役割です。この注釈がなければ、代弁者の言葉が
  全体の意見だと錯覚してしまいます。

年収、住宅価格、売上のように大きい値の側に裾が長いデータでは、平均という代弁者は
一部の富裕層の声に引きずられます。だからこそ統計当局が世帯所得を発表するとき、
中央値を併記するのです。

## 3. 核心となる考え方

### 3.1 平均 — 重心

平均はすべての値を足して個数で割った値です。数式では
x̄ = (x₁ + x₂ + … + xₙ) / n。物理的には、データをシーソーの上に載せたときに
釣り合いが取れる**重心**です。重心であるがゆえに、はるか遠くに置かれた
値 1 つ (極端な値、outlier) がてこのように平均を自分の側へ引き寄せます。

### 3.2 中央値 — 整列の真ん中

値を小さい順に並べたとき、ちょうど真ん中にくる値です (偶数個なら真ん中の 2 つの
値の平均)。極端な値の**大きさ**は中央値に影響しません。3 億だろうと
30 億だろうと、「いちばん大きい 1 人」であることに変わりないからです。この性質を
**頑健 (robust)** と呼びます。

### 3.3 分散と標準偏差 — 散らばりの大きさ

各値が平均からどれだけ離れているか (偏差) を 2 乗して平均したものが
分散です。2 乗したせいで単位がおかしくなるため (ウォン² のような)、平方根を取って
元の単位に戻したものが標準偏差です。

| 概念 | 計算 | 単位 | 直感 |
|---|---|---|---|
| 分散 | 偏差の 2 乗の平均 | ウォン² | 数学的に扱いやすい |
| 標準偏差 | 分散の平方根 | ウォン | 「平均からだいたいこれくらい外れる」 |

標準偏差 0 は全員が同じ値という意味で、標準偏差が平均と同じくらいの
水準なら「平均は代表値の役目をほとんど果たせていない」という警告です。

### 3.4 いつ何を使うか

- 値が左右対称に集まっている → 平均 (標準偏差を添えて)
- 裾が長い / 極端な値がある (年収・住宅価格・売上) → 中央値を優先、平均は参考
- 報告書にはできれば**両方**書き、2 つが大きく違うならその理由 (極端な値、
  偏り) を一行添えるのが良い習慣です。

### 3.5 ボーナス — 変動係数

店舗 A は平均売上 1,000 万ウォンで標準偏差 100 万ウォン、店舗 B は平均 100 万
ウォンで標準偏差 50 万ウォンです。どちらがより「揺れの大きい」店でしょう? 絶対値
では A (100 万) が大きいですが、平均に対する比率では B (50%) のほうがはるかに不安定です。
このように標準偏差を平均で割った値を変動係数 (coefficient of variation)
と呼び、規模の違う対象のばらつきを比較するときに使います。実習の [3] で
店舗ごとに合わせて計算してみます。

## 6. よくある間違い

- **平均と中央値が違うのに理由を問わない**: 2 つの差はエラーではなく
  「偏りがある」という情報です。差そのものに報告の価値があります。
- **標準偏差なしで平均だけ報告する**: 「平均 5 日で配送」でも標準偏差が
  3 日なら、8 日以上かかる顧客が珍しくないという意味です。クレームは平均
  ではなく裾から発生します。
- **分散の単位を忘れる**: 分散が 2,500 万というのは「ウォン²」の単位です。
  報告書には平方根である標準偏差 (5,000 ウォン) で書かないと誤解を招きます。
- **クレンジング前に統計を取る**: 欠損を 0 で埋めると平均が歪みます。None と
  0 は別物です。計算の前に、欠損・外れ値の処理方針から決めましょう。
