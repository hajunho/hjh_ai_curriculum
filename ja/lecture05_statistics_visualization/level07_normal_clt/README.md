# Lecture 05 · Level 07 — 正規分布と中心極限定理

> 個々のデータがどんな形でも、「平均たち」は鐘の形に集まります。統計学の万有引力です。
**難易度** ⭐⭐⭐ / **前提** level06 / **想定時間** 55分

## 1. なぜ学ぶのか — ビジネスの視点

世論調査の誤差範囲、品質管理の管理限界線、A/B テストの有意性判定 —
これらすべての実務ツールの底には、1 つの事実が敷かれています。**標本
平均は正規分布に従う**ということ。元のデータが売上のように右の裾が
長かろうと、コイン投げのように 2 値しかなかろうと関係なく、「複数個を集めて平均した
値」の分布は鐘の形になります。これが中心極限定理 (Central Limit
Theorem, CLT) です。

この定理のおかげで、私たちは元の分布を知らなくても平均について確率的な陳述が
できます。「今月の標本平均がこの範囲を外れる確率は 5% 未満」
のような文が可能なのは、すべて CLT のおかげです。次のレベルの信頼区間、
その次の p 値がすべてこの上に立っているので、ここが推測統計の
礎石です。

## 2. たとえ話で理解する

食堂の**一杯の汁物の味**を考えてみましょう。寸胴鍋の中には、しょっぱい場所も薄い
場所もあります (元の分布はばらばら)。しかし、お玉で何度もすくって混ぜた一
杯の味はどうでしょう? どの器を受け取っても、味は似たり寄ったりです。複数の
場所を混ぜる過程 (平均) が極端を相殺するからです。器数百杯分の
味を記録すれば、「器の味」の分布は、鍋の中のでこぼこと無関係に狭い鐘の
形になります。お玉が大きいほど (標本が大きいほど)、器ごとの差はさらに縮まります。

正規分布が世の中にありふれている理由も同じです。身長は無数の遺伝子と環境要因の
合計で、測定誤差は無数の小さな揺らぎの合計です。**「多数の独立した小さな
要因の合計」は鐘の形になる** — これが CLT の日常バージョンです。

## 3. 核心となる考え方

### 3.1 正規分布 — 2 つのつまみ

正規分布 (normal distribution) は、平均 μ と標準偏差 σ、たった 2 つの
つまみで完全に決まる左右対称の鐘型分布です。有名な 68-95-99.7
ルール:

| 範囲 | 含まれる比率 |
|---|---|
| μ ± 1σ | 約 68% |
| μ ± 2σ | 約 95% |
| μ ± 3σ | 約 99.7% |

「品質管理で ±3σ を外れたら工程の異常」という慣例も、「±2σ ≈ 95%」が
信頼区間の 1.96 につながることも、すべてこの表から来ています。

### 3.2 中心極限定理 — 正確な陳述

平均 μ、標準偏差 σ のどんな分布からでも (裾が病的に重くなければ)、
サイズ n の標本を抜き取って平均を出すことを繰り返すと:

1. 標本平均たちの平均は μ に近づき、
2. 標本平均たちの標準偏差は **σ/√n** になり (これを標準誤差、standard
   error と呼びます)、
3. 標本平均たちの分布の形は、n が大きくなるほど**正規分布**に近づきます。

3 番目が驚くべき部分です。元が一様分布でも、左に寄った指数分布でも、
n=30 程度になれば平均の分布はすでにかなり鐘の形をしています。

### 3.3 √n の経済学

標準誤差が σ/√n だということは、実務的には「精度を 2 倍にするには標本を
4 倍集めなければならない」という意味です。アンケートの回答者を 1,000 人から 2,000 人に
増やしても、誤差は 1.4 倍しか縮まりません。データ収集コストは線形に増え、
精度は平方根でしか良くならないため、「標本をどれだけ集めるか」は常に
コストと精度のバランス問題です (level10 の標本サイズ設計につながります)。

### 3.4 CLT が通用しない場所

CLT は万能ではありません。極端な値が支配する分布 — たとえば大当たり 1 件が
年商の半分を占める事業、保険の巨大災害損失 — では、平均そのものが
不安定で、収束が非常に遅いか成立しません。「平均が意味を持つ
データなのか」を先に問うべき理由です (level01 の教訓とつながります)。

## 6. よくある間違い

- **「データが多ければデータが正規分布になる」という誤解**: CLT は元の
  データではなく、**標本平均の分布**についての定理です。売上データは
  100 万件集めても、依然として右の裾の長い分布です。
- **σ と σ/√n の混同**: 標準偏差は個々の値の散らばり、標準誤差は標本平均の
  散らばりです。報告書で「±」の後ろの数字がどちらなのか、必ず明示しましょう。
- **n=30 を魔法の数字として暗記する**: 30 は慣例にすぎません。元の偏りが
  激しいほど、より大きな n が必要です。疑わしければ、今日のようにシミュレーションで
  確かめるのが正解です。
- **すべてを正規分布と仮定する**: 金融のリターン、バイラル再生数のように裾の
  厚いデータに正規分布を仮定すると、「千年に一度」のはずの出来事が 10 年に
  3 回起こります。
