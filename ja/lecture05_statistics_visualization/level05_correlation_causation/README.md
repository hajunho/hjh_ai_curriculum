# Lecture 05 · Level 05 — 相関関係と因果関係

> 「一緒に動く」と「そのせいで動く」の間には、ビジネスの意思決定 1 つ分の距離があります。
**難易度** ⭐⭐⭐ / **前提** level03 / **想定時間** 50分

## 1. なぜ学ぶのか — ビジネスの視点

「広告費を増やした月に売上が高かったです。広告予算を 2 倍にしましょう。」
会議でよく聞く論理です。ところが、もし繁忙期だから広告も増やし、
客も増えたのだとしたら? 広告予算を 2 倍にしても閑散期の売上はびくとも
せず、その予算は空中に消えます。

相関関係 (correlation) は「2 つの値が一緒に動く傾向」で、因果関係
(causation) は「片方を変えるともう片方が変わる関係」です。データ分析が
見つけ出すのは、ほとんどの場合、相関までです。ところが予算配分、採用、価格決定
のような**行動**は、因果を前提とします。相関を因果と錯覚した瞬間、データ
ドリブンな意思決定は、データで包装されたギャンブルになります。この区別は、おそらくこの講義
全体の中で実務価値が最も高い 1 章です。

## 2. たとえ話で理解する

夏のビーチタウンの統計を見ると、**アイスクリームの販売量と水難事故**が驚くほど
一緒に動きます。アイスクリームが人を水に沈めるのでしょうか? もちろん違います。
**暑い天気**という第 3 の変数が、アイスクリームの販売も増やし、水遊びをする人も
増やしたのです。このように 2 つの変数の両方に影響を与えて偽物の相関を作る
変数を、交絡因子 (confounder) と呼びます。

交絡因子は**胴体を隠したタコ**です。私たちの目には、水面から出た 2 本の
足 (アイスクリーム、水難事故) しか見えません。2 本の足が一緒に動くので互いにつながっている
ように見えますが、実際には水面下の胴体 (天気) が両方を動かしている
のです。片方の足をつかんで揺すっても (アイスクリーム販売の禁止)、もう片方の足は
動きません。胴体はそのままだからです。

## 3. 核心となる考え方

### 3.1 相関係数の読み方

ピアソンの相関係数 (Pearson correlation coefficient) r は -1 〜 +1 の間の
数字で、**直線的な**連動の度合いを表します。

| r | 解釈 |
|---|---|
| +1.0 | 完璧な正比例の連動 |
| +0.7 〜 +0.9 | 強い正の相関 |
| +0.3 〜 +0.5 | 弱い〜中程度の正の相関 |
| 0 付近 | 直線的な関係なし |
| 負の値 | 逆方向に動く (例: 価格↑ 販売量↓) |

注意が 2 つ。第一に、r は直線関係しか捉えません。U 字型の関係 (適温で売上が
最大) は r ≈ 0 と出ることがあります。だから相関係数を見る前に、必ず
散布図を描きます。第二に、r の大きさは「傾き」ではなく「点がどれだけ直線に
張り付いているか」です。

### 3.2 相関が生まれる 4 つの経路

X と Y の相関が観察されたとき、可能な説明は少なくとも 4 つあります。

1. **X → Y**: 本当に X が Y の原因 (広告 → 売上)
2. **Y → X**: 逆方向 (売上の良い月に広告予算を増やした)
3. **Z → X, Z → Y**: 交絡因子 (繁忙期が広告と売上の両方を押し上げた)
4. **偶然**: データが少ないと、何の関係もない値どうしも案外一緒に動きます

アナリストの仕事は相関を発見することではなく、4 つのうちどれなのかを**消去法で
絞り込む**ことです。

### 3.3 交絡因子の統制 — 層に分けて見る

交絡因子を疑う最も簡単な方法は**層化 (stratification)** です。
交絡因子の値が近いグループの中だけで、相関を計算し直してみるのです。
「暑い日だけを集めて見れば」アイスクリームと水難事故の相関は消えます。実習で
これをコードで再現します。層の中で相関が消えるなら、元の相関は
交絡因子の仕業だった可能性が高いのです。

### 3.4 因果を確かめる王道 — 実験

観察データだけで因果を確定するのは非常に困難です。王道は**ランダム化
実験**です。コイン投げで広告を流す地域と流さない地域を分ければ、
繁忙期だろうと所得だろうと、あらゆる交絡因子が両側に均等に混ざって相殺されます。これが
まさに level10 で学ぶ A/B テストであり、「相関→因果」問題の実務的な
終着点です。

## 4. 実習 — main.py

```bash
python3 main.py
```

実習は 2 部構成です。(図中のラベルは英語です。)

**第 1 部 — 本物の相関の観察**: `hjh_data` の売上から、日別の広告費と売上の
ピアソン相関係数を numpy (`np.corrcoef`) で計算し、散布図
`outputs/ad_revenue.png` を保存します。

**第 2 部 — 偽物の相関の製造と解体**: 交絡因子の実験を合成データで直接
作ります。

- [3] 「暑さ指数」(交絡因子 Z) を作り、アイスクリーム販売 X = Z + ノイズ、
  水難事故 Y = Z + ノイズとして生成します。X と Y は互いをまったく
  参照していないのに、r ≈ 0.7 の強い相関が出ます。
- [4] **層化の実験**: 暑さ指数を 5 つの区間に分け、各区間の中で X・Y の
  相関を計算し直します。区間の内側では相関が 0 の近くまで崩れることを
  確かめます。
- [5] `outputs/confounder.png`: 左は全体の散布図 (強い相関に見える)、
  右は暑さの区間ごとに色を塗った散布図 (色のかたまりの中は無秩序)。

出力の核心となる比較は「全体の r = 0.7 対 区間内の平均 r ≈ 0」です。同じ
データで相関が現れては消えるこの瞬間こそ、このレベルが教えたいことのすべて
です。

## 6. よくある間違い

- **r が大きいから因果だと結論づける**: r = 0.9 でも、3.2 の 4 つの経路のどれなのかは
  r は教えてくれません。相関の強さと因果の証拠は別物です。
- **散布図なしで相関係数だけ見る**: U 字の関係、極端な値 1 つが作った偽の相関
  などは、散布図でしか見えません。「数字が先、図は省略」は禁物です。
- **相関なし = 関係なし**: r ≈ 0 は「直線的な関係がない」というだけです。
  曲線的な関係はいくらでもあり得ます。
- **逆向きの因果を無視する**: 「レビューの多い商品はよく売れる」は、よく売れたからレビューが
  増えたのかもしれません。時間の順序 (どちらが先か) を確かめましょう。
- **交絡因子を 1 つ統制して安心する**: 層化で 1 つ取り除いても、別の
  交絡因子が残っているかもしれません。観察データの結論は、常に暫定的
  です。
