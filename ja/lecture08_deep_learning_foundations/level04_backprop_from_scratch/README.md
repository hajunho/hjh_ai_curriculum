## 2. たとえ話で理解する

**不良品の責任所在の追跡。** 工場で完成品の不良が出たとしましょう (= 損失が大きい)。品質チームはこう逆追跡します。

1. 最終検収段階: 「不良の何 % が組み立て工程のせいか?」
2. 組み立て工程: 「その責任のうち何 % が部品 A のせいで、何 % が部品 B のせいか?」
3. 部品工程: 「その責任のうち何 % が原材料のせいか?」

各段階は**自分のすぐ前の段階にだけ**責任を分配すればよいのです。全工程を知る必要はありません。このように責任 (誤差) を出力から入力の方向へ逆向きに流すのが誤差逆伝播であり、「責任の配分比率」を計算する数学の道具が連鎖律 (chain rule) です: 全体の影響 = 各段階の影響の積。

順伝播 (forward) は「原材料 → 部品 → 組み立て → 完成品」と値が流れること、逆伝播 (backward) は同じ道を逆向きに「責任」が流れることです。道が同じなので、順伝播のときに中間値をメモしておけば、逆伝播はほぼタダ同然で計算できます。

## 3. 核心となる概念

### 3-1. 作るニューラルネットワーク: 2-8-1

- 入力 2 個 (XOR の 2 座標) → 隠れニューロン 8 個 (tanh) → 出力 1 個 (sigmoid、0〜1 の確率)
- 損失は二値クロスエントロピー (BCE)。level03 の採点表そのままです。

### 3-2. 順伝播 — 4 行がすべて

```
z1 = X @ W1 + b1      # 1 層目の加重和
h  = tanh(z1)         # 非線形 (level02 で学んだ理由により必須)
z2 = h @ W2 + b2      # 2 層目の加重和
p  = sigmoid(z2)      # 確率へ変換
```

### 3-3. 誤差逆伝播 — 責任を逆向きに配分

連鎖律を層ごとに書くと次のようになります。導出は付録と考えて、「出力から入力へ掛けながら降りてくる」という構造さえつかめば十分です。

| 段階 | 数式 | たとえ |
|---|---|---|
| 出力層の誤差 | dz2 = (p − y) / n | 完成品の不良の大きさ。BCE+sigmoid の組み合わせはこうきれいに整理されます |
| W2 の責任 | dW2 = hᵀ @ dz2 | 「隠れニューロンが多く寄与したほど責任も大きい」 |
| 隠れ層へ伝達 | dh = dz2 @ W2ᵀ | 責任を結合強度の比率で前の段階に配分 |
| tanh 通過 | dz1 = dh × (1 − h²) | tanh が飽和したニューロンには責任がほとんど流れない (勾配消失の正体) |
| W1 の責任 | dW1 = Xᵀ @ dz1 | 入力が寄与した分だけ責任を配分 |

最後は level03 のとおり、すべての重みを `W -= 学習率 × dW` で更新します。

### 3-4. 数値微分による検証 — 誤差逆伝播のユニットテスト

誤差逆伝播の実装は、符号ひとつ、転置 (transpose) ひとつを間違えやすいものです。検算法は単純です。重みをひとつ ±0.000001 動かして loss の変化量を直接測り (中央差分)、逆伝播が計算した値と比較します。相対誤差が 1e-4 未満なら合格です。遅いけれど確実で、実際のフレームワーク開発者たちも同じ方式で自動微分をテストしています。

## 5. やってみよう

1. **(易しい)** 隠れニューロン数を 8 から 2 に減らしてみましょう (`init_params` の 8 を 2 に)。XOR はまだ解けますか? 3 では? *ヒント: XOR は理論上、隠れニューロン 2 個で十分ですが、初期値の運によって失敗することがあります。シードを変えながら観察してみてください。*
2. **(普通)** `dz1 = dh * (1.0 - h ** 2)` から `(1.0 - h ** 2)` を消して (つまり tanh の微分を抜かして) 実行してみましょう。[2] の検証がどう失敗するか確認してください。数値微分の検算がなぜ「ユニットテスト」なのかを体感できます。
3. **(挑戦)** 隠れ層をもう 1 つ入れて 2-8-8-1 に拡張してみましょう。*ヒント: forward に z2/h2 を追加し、backward で dh2 → dz2 の配分ステップをもう一度繰り返せばよいのです。パターンが同じだと感じた瞬間、100 層のネットワークも原理は同じだと理解したことになります。*

## 6. よくある間違い

- **転置・形 (shape) のミス。** `h.T @ dz2` を `dz2 @ h.T` と書くたぐいのミスが最も多いです。各配列の shape をコメントに書きながら組むと、たいてい予防できます。
- **順伝播の中間値を保存しないこと。** 逆伝播は h, p のような中間値を再利用します。保存せずに再計算すると遅くなり、別の入力で再計算すると微分が狂います。
- **数値微分の h (間隔) を小さくしすぎること。** 1e-12 のように取ると、浮動小数点の丸め誤差が微分値を飲み込みます。1e-5〜1e-6 が適当です。
- **loss が 0.6931 で止まること。** ln 2 ≈ 0.693 は「コイン投げレベル」という意味です。学習率が小さすぎるか、初期の重みがすべて 0 でニューロンが同じ動きをするケース (対称性の問題) です。初期化は必ず小さな乱数で行います。
