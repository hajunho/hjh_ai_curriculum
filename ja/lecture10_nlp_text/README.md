# Lecture 10 — 自然言語処理 (NLP)

> コンピュータが人間の言葉を扱う技術を、土台からひとつずつ積み上げていきます。
> 文字列のクリーニングと正規表現から始めて、TF-IDF・感情分析・埋め込みを経て、
> アテンションとミニトランスフォーマーを自分の手で実装し、GPT/BERT の事前学習パラダイムまで到達します。

## この講義で学ぶこと

- なぜ言語はコンピュータにとってこれほど難しいのか — 曖昧性、文脈、そして「単語の切れ目がない」日本語の特性
- 散らかったテキストを分析可能な形に整える前処理パイプラインと正規表現
- テキストを数値に変える 3 つの世代: BoW/TF-IDF → 単語埋め込み → 文脈埋め込み
- レビュー感情分析器を自作し、モデルがどの単語を根拠に判断したのかを解釈する
- RNN・アテンション・トランスフォーマーの仕組みを numpy と torch で部品単位から組み立てる
- GPT (続きを書く) と BERT (穴埋め) が世界を変えた事前学習パラダイムの核心

この講義では MeCab、nltk、transformers のような NLP 専用パッケージを **あえて使いません**。
トークナイザー、TF-IDF、アテンションをすべて自分で実装してみて初めて「ライブラリが中で
何をしているのか」が分かり、次の講義 (lecture11 — LLM 活用と RAG) でツールを使うとき、
ブラックボックスではなくガラス張りの箱になります。

## 時短コース (時間がなければこの 5 つだけ)

1. **level01 テキスト前処理** — あらゆるテキスト業務の出発点。実務での利用頻度 No.1。
2. **level04 BoW・TF-IDF** — 「テキストを数値に」の定番。検索・分類・キーワード抽出の土台。
3. **level05 テキスト分類** — レビュー感情分析のパイプライン全体を一気に体験。
4. **level08 アテンション** — いまの AI を理解する鍵を 1 つだけ選ぶならこれ。
5. **level11 事前学習パラダイム** — GPT/BERT がなぜすごいのか、LLM 時代の全体像。

## この講義が実務で活きる場面

- **VOC (お客様の声) 分析**: 1 日に何千件も届くレビューや問い合わせをポジティブ/ネガティブに
  自動分類し、不満キーワードを抽出して週次レポートにまとめます。(level01, 04, 05)
- **文書からの情報抽出**: 契約書や見積書の山から金額、日付、連絡先を正規表現で
  一括抽出し、Excel に整理します。(level02)
- **社内文書検索・要約の土台**: 「休暇規定ってどこだっけ?」に答える社内検索や
  RAG チャットボットは、すべてこの講義のトークン化・TF-IDF・埋め込みの上に成り立っています。(level03, 04, 06)
- **LLM を正しく使う目**: トークン単位の課金がなぜそうなのか、コンテキスト長の制限がなぜあるのか、
  プロンプトがなぜあのように動くのか — トランスフォーマーの構造を知ればすべて説明がつきます。(level08〜11)

## 実行方法

```bash
cd lecture10_nlp_text/level00_why_language_is_hard
python3 main.py
```

すべての実習はインターネット接続なしで動作し、データは `common/hjh_data.py` がその場で
生成します。torch を使うレベル (07, 10, 11) も CPU で 90 秒以内に終わるよう、ごく小さく
設計してあります。
