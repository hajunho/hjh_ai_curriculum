# Lecture 02 — Python プログラミング基礎

Excel は使えるけれどコーディングは初めて、というビジネスパーソンのための Python (パイソン) 入門講義です。
「プログラミングとはいったい何なのか」という問いから出発し、12のレベルを終える頃には、
データファイルを読み込み、ルールに従って判断・集計し、結果レポートを自動で作り出す
小さな業務自動化プログラムを自分の手で書けるようになります。

## この講義で学ぶこと

- プログラムが動く3つの原理 — 順次・分岐・繰り返し
- 変数、データ型、条件分岐、繰り返し、コレクション、関数といった Python の骨格となる文法
- ファイル入出力、例外処理、モジュール化など「実務で壊れないコード」の基本
- クラスとオブジェクト指向、内包表記・ジェネレーターのような Python らしい表現
- 型ヒントとテストでコード品質を守る習慣

## 前提となる講義

- lecture01 (コンピュータと開発環境) — ターミナルで `python3 main.py` を実行できれば十分です。

## 最短ルート (時間がない方へ)

要点だけを素早く押さえたい場合は、次の5つのレベルを順番に学習してください。

1. **level01 変数とデータ型** — すべてのコードの材料
2. **level02 条件分岐** — 判断の自動化はここから始まる
3. **level03 繰り返し** — 自動化の効果を最も実感できる文法
4. **level05 関数** — コードを業務マニュアルのように整理する方法
5. **level06 ファイルの読み書き** — 実際のデータとつながる入り口

その後、必要になったタイミングで level04 (データ構造) と level07 (例外処理) を補えば、
lecture03 (データハンドリング) へ進む準備は完了です。

## この講義が実務で活きる場面

- 毎朝届く取引明細の CSV を開き、項目別の合計・異常値サマリーレポートを自動生成するとき (level03·04·06)
- 「出張経費15万ウォン以下は自動承認」のような社内規定をコードに置き換え、繰り返しの決裁をなくすとき (level02)
- 税金・割引の計算ロジックが部署ごとにバラバラなとき、関数一つに統一してミスを防ぐとき (level05)
- 壊れたデータ1行のせいで夜通し走っていたバッチが落ちる事故を、例外処理で防ぐとき (level07)
- 一般社員・マネージャーのように「似ているが少しだけ違う」ルールを、クラスの継承ですっきり管理するとき (level09)
- 他人が (あるいは未来の自分が) 見ても安心して使えるように、型ヒントとテストを付けるとき (level11)

すべての実習は標準ライブラリだけを使い、インターネット接続なしで
`python3 main.py` の一行で実行できます。
