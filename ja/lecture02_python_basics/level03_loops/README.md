# Lecture 02 · Level 03 — 繰り返し: 退屈な仕事を任せる

> for/while の繰り返しは「リストのすべての件に同じ手順を実行せよ」という指示であり、自動化の効果を最も実感できる文法です。
**難易度** ⭐ / **前提** level02 / **目安時間** 45分

## 1. なぜ学ぶのか — ビジネスの視点

顧客100人の購入額を合計し、平均を出し、優良顧客を選び出す仕事を想像してみてください。
Excel なら SUM・AVERAGE 関数を使うところですが、毎日新しいファイルが届き、形式が少しずつ違い、
集計基準が複雑になってくると手作業が増えていきます。人間が100件を処理すると、途中で電話が鳴り、
集中が切れ、どこかで1件を見落とします。

繰り返し (loop) は「この手順をリストのすべての項目に適用せよ」という1行の指示です。
100件でも100万件でもコードは同じで、品質も同じです。プログラミングを学んで得られる
実務上のメリットの大部分 — 繰り返し業務の自動化 — が、まさにこの文法から生まれます。
今回の実習では、顧客100人のデータを「手計算方式」と「繰り返し方式」で並べて集計し、
その差を自分の目で確かめます。

## 2. たとえ話で理解する

**郵送作業のたとえ。** 新製品の案内状を顧客100人に送る仕事をアルバイトに
任せるとしましょう。指示書をこうは書きませんよね。

> 「佐藤様の住所を封筒に書き、案内状を入れよ。鈴木様の住所を封筒に書き、案内状を入れよ。…」(100行)

こう書くはずです。

> 「**名簿の各顧客について**: 住所を封筒に書き、案内状を入れ、切手を貼れ。」

この1行が `for` 文です。「名簿の各顧客について」 = `for customer in customers:`、
その下にインデントされた手順が、毎回実行される本体です。

`while` 文は少し違う指示です。「切手がなくなるまで貼り続けよ」のように、
**何回かは分からないが、条件が保たれている間は繰り返せ** という指示です。
回数が決まっているなら for、条件で終わりが決まるなら while — この感覚さえあれば十分です。

## 3. 核心となる考え方

### 3.1 for 文 — リストを巡回する

```python
purchases = [120000, 45000, 230000]
total = 0
for amount in purchases:      # リストから1件ずつ取り出して amount に入れる
    total = total + amount    # 毎回実行される本体
print(total)                  # 395000
```

`amount` は1周ごとに次の項目へ入れ替わる **ループ変数** です。
合計を入れる `total` のように、繰り返しの前に0から始めて毎周積み上げていく変数を
**累積変数 (accumulator)** と呼びます。集計の基本パターンなので、必ず手になじませてください。

### 3.2 range — 回数で繰り返す

```python
for i in range(5):        # 0, 1, 2, 3, 4  (5 は含まれない!)
for i in range(1, 6):     # 1, 2, 3, 4, 5
for i in range(0, 10, 2): # 0, 2, 4, 6, 8  (2つ飛ばし)
```

`range(開始, 終わり, 間隔)` の **終わりの値は含まれません**。「0から始めて終わりの直前まで」が
Python 全般の慣例です。項目と連番の両方が必要なら `for i, item in enumerate(items):` を使います。

### 3.3 while 文 — 条件が真の間

```python
budget = 1000000
day = 0
while budget > 0:          # 予算が残っている間は繰り返す
    budget -= 87000        # 1日の支出
    day += 1
```

while は必ず、**いつか条件が偽になるように** 本体の中で状態を変えなければなりません。
変えないと無限ループ (infinite loop) に陥ります。(ターミナルでは Ctrl+C で強制終了します。)

### 3.4 break と continue — 流れの制御

- `break` : 繰り返しを即座に終了して抜けます。「見つかったら、もう見る必要はない。」
- `continue` : 今回の周回だけスキップして次の項目へ進みます。「欠損値は飛ばして続行。」

```python
for row in rows:
    if row is None:
        continue          # 壊れたデータはスキップ
    if row == target:
        break             # 見つかったので繰り返しを終了
```

実務のデータには必ず空の値や汚れた値が混ざっているので、continue でふるい落とすパターンをよく使います。

### 3.5 ネストした繰り返し

繰り返しの中に繰り返しを入れると「すべての店舗 x すべての月」のような格子状の巡回になります。
外側のループが1周するたびに内側のループが全部回るので、100 x 100 なら本体が1万回実行されます。
便利ですが、データが大きくなると遅くなるポイントでもあります (lecture03 でベクトル演算により改善します)。

顧客100人の購入データを集計する例題です。乱数は seed を固定してあるので、

- **[2] for 集計**: 繰り返し4行で100人の合計・平均・最高購入額の顧客を求めます。

- **[4] while シミュレーション**: マーケティング予算100万ウォンが尽きるまで1日の支出を引きながら
  「何日持つか」を計算します。`break` で60日の上限も設けてあります。
- **[5] range と enumerate**: 購入額の上位5人を順位番号付きで出力します。

出力の最後にある「コード行数の比較」が、このレベルの結論です。100人の集計に、
手計算方式は100行以上、繰り返しは4行です。

## 6. よくある間違い

- **累積変数の初期化を繰り返しの中に書く** — `total = 0` が for の中に入ると
  毎周0にリセットされ、最後の1件しか残りません。初期化は必ず繰り返しの **前** に。
- **range の終わり値の勘違い** — `range(1, 100)` は99までです。100人回すなら
  `range(1, 101)` または `range(100)`。
- **無限ループ** — while の本体で条件の変数を更新しないと永遠に回り続けます。
  while を使うときは「この条件はいつ偽になる?」と先に自問しましょう。
- **繰り返し中のリストを変更する** — 巡回しながらそのリストから項目を削除すると、飛ばされる項目が
  出てきます。結果を新しいリストに集める方式 (level04、level10) を使いましょう。
- **インデントによる所属の勘違い** — 繰り返しの中にあるべき print が外にあると、最後の値だけが
  1回出力されます。「この行は毎周実行されるのか?」をインデントで確認してください。
