# Lecture 02 · Level 01 — 変数とデータ型

> 変数はデータに名札を付けて保管しておく箱であり、データ型はその箱に入っているデータの種類 (整数・浮動小数点数・文字列・ブール値) です。
**難易度** ⭐ / **前提** level00 / **目安時間** 40分

## 1. なぜ学ぶのか — ビジネスの視点

Excel で `=B2*C2` という数式を書くとき、B2 と C2 は「単価」と「数量」が入っているセルの番地です。
ところが時間が経つと、B2 が何だったのか忘れてしまいますよね。Python ではセル番地の代わりに
`unit_price`、`quantity` のように **意味のある名前** を付けられます。これが変数です。

変数とデータ型は、すべてのコードの材料です。売上計算、顧客名簿の整理、AI モデルの学習まで、
すべて「値を変数に入れ → 加工し → 結果を別の変数に入れる」ことの連続です。
特にデータ型を正確に理解しておけば、実務でよくある事故 — 数値の「1000」と文字の「1000」を
取り違えて合計がおかしくなる事故 — を予防できます。

なお、この教材の金額データは韓国ウォン (₩, KRW) 建てです。数値の桁感が円と少し違いますが、
計算の考え方はまったく同じです。

## 2. たとえ話で理解する

**名札付きの箱のたとえ。** オフィスの倉庫に箱がいくつも並んでいると想像してください。
箱にはそれぞれ名札が付いています:「3月売上」「顧客名簿」「消費税率」。
必要なときは名札で箱を探して中身を取り出して使い、新しい中身に入れ替えることもできます。

- `march_sales = 12000000` → 「3月売上」の名札が付いた箱に 1200万を入れる。
- `print(march_sales)` → その箱を開けて中身を確認する。
- `march_sales = 13000000` → 中身を新しい値に入れ替える。(だから「変わりうる数」、変数なのです)

**データ型は箱の中身の種類**です。箱に現金が入っているのか、書類が入っているのか、
判子 (「承認」/「差し戻し」) が入っているのかによって、できることが違います。現金同士は足せますが、
現金と書類を足せと言われたら意味が通りませんよね。Python も同じで、「数値 + 文字」をさせると
エラーを出します。

## 3. 核心となる考え方

### 3.1 変数を作る — 代入

```python
unit_price = 4500      # 「unit_price の箱に 4500 を入れよ」
```

`=` は数学の「等しい」ではなく、**「右側の値を左側の名前の箱に入れよ」** という命令です。
だからこそ `count = count + 1` (今の値に1を足して入れ直す) が成立します。

名前のルール: 英小文字とアンダースコアで、意味が伝わるように付けます。`a` や `x1` より
`total_revenue`、`vat_rate` のほうが良い名前です。コードは書く時間より読む時間のほうが長いのです。

### 3.2 4つの基本データ型

| データ型 | 名前 | 例 | 実務での用途 |
|---|---|---|---|
| `int` | 整数 (integer) | `120`, `-3` | 数量、人数、件数 |
| `float` | 浮動小数点数 (floating point) | `0.1`, `4500.0` | 比率、単価、平均 |
| `str` | 文字列 (string) | `"アメリカーノ"` | 名前、住所、メモ |
| `bool` | ブール値 (boolean) | `True`, `False` | 承認の有無、会員かどうか |

`type(値)` でデータ型を確認できます。迷ったらいつでも聞いてみましょう。

### 3.3 データ型の変換

CSV ファイルやユーザー入力から読み込んだ値は、すべて文字列です。計算するには変換が必要です。

```python
int("1000")      # 文字列 -> 整数 1000
float("3.3")     # 文字列 -> 浮動小数点数 3.3
str(4500)        # 整数 -> 文字列 "4500"
```

`"1000" + "500"` は `"1000500"` (文字列の連結) になります。実務事故のワースト1なので、
「この値は今、数値なのか文字なのか」を常に意識してください。

### 3.4 f-string — レポートの文章を作る

文字列の前に `f` を付けると、波かっこの中に変数を埋め込めます。

```python
name = "アメリカーノ"
total = 9000
print(f"{name}の売上は{total}ウォンです")    # アメリカーノの売上は9000ウォンです
print(f"{total:,}ウォン")                    # 9,000ウォン  (3桁区切りのカンマ)
print(f"{0.0525:.1%}")                       # 5.2%     (パーセント表示、小数1桁)
```

`{変数:書式}` という書式指定は、数値レポートを作るときにずっと使い続けることになります。
`,` (3桁区切り)、`.2f` (小数第2位)、`.1%` (パーセント) の3つをまず覚えてください。

### 3.5 算術演算子を一望する

計算に使う記号は Excel とほぼ同じで、新しく覚えるのは2つだけです。

| 演算子 | 意味 | 例 | 結果 |
|---|---|---|---|
| `+` `-` `*` `/` | 四則演算 | `7 / 2` | `3.5` |
| `//` | 商 (切り捨て除算) | `7 // 2` | `3` |
| `%` | 余り | `7 % 2` | `1` |
| `**` | べき乗 | `2 ** 10` | `1024` |

`//` と `%` は「5人乗りの車で17人を運ぶには何台必要で何人余るか」のような
配分の問題でよく使います。`/` の結果は常に float になる点も覚えておきましょう。

### 3.6 浮動小数点数 (float) の微小な誤差

コンピュータは小数を2進法で保存するため、`0.1 + 0.2` は正確に 0.3 ではなく
`0.30000000000000004` になります。故障ではなく、保存方式の限界です。
金額の比較では四捨五入 (`round`) を活用し、厳密な会計処理なら整数 (ウォン単位) で
計算するのが安全です。

## 6. よくある間違い

- **`=` と `==` の混同** — `=` は代入 (入れる)、`==` は比較 (等しいか?) です。level02 で
  比較が出てきたら、もう一度確認してください。
- **文字列の数字をそのまま計算** — `"100" * 2` は 200 ではなく `"100100"` です。
  外部から入ってきた値は `int()`/`float()` の変換から。
- **変数名のタイプミス** — `total_revenue` を `total_revenu` と書くと
  `NameError: name 'total_revenu' is not defined` が出ます。エラーメッセージにタイプミスした名前が
  そのまま表示されるので、よく読めばすぐに直せます。
- **意味のない名前** — `a`、`b`、`data2` は一週間後の自分にとって暗号です。
  長くても意味が見える名前を使いましょう。
